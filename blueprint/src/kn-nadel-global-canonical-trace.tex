\section{The original canonical trace across the adapted-cover unit extension}

Let $X$ be smooth of pure dimension $n$ over the original field $k$.
The original canonical module means $\omega_X=\bigwedge^n\Omega^1_{X/k}$.
All comparisons below use the actual canonical differential, the original
scalar maps, and every factor of the original simultaneous root algebra.

\begin{lemma}[Canonical affine sections after an actual etale map]
\label{lem:kn-global-trace-canonical-affine-basechange}

\[
 \Gamma(Z,\mathcal O_Z)\otimes_{\Gamma(X,\mathcal O_X)}
       \Gamma(X,\omega_X)\;\xrightarrow{\sim}\;
       \Gamma(Z,\omega_Z).
\]
Its underlying map is the original affine pullback-sections comparison
followed by the entire original canonical differential.  No global basis
of $\Omega^1_{X/k}$ is an input.
\end{lemma}
\begin{proof}
Smoothness makes $\omega_X$ invertible and hence quasicoherent.  The actual
affine pullback-sections isomorphism identifies the displayed tensor
product with $\Gamma(Z,g^*\omega_X)$.  The whole original canonical
differential $g^*\omega_X\to\omega_Z$ is an isomorphism by the cited
smooth-etale theorem.  Applying the section functor and composing the two
isomorphisms proves the assertion.  The composition is the stated
underlying map by the definitions of these two functors.
\end{proof}

\begin{theorem}[Canonical trace on the same original global adapted cover]
\label{thm:kn-global-trace-original-adapted-cover}
\notready

auxiliary sections satisfy the proved SNC and empty-row conditions,
with positive original root degrees.  For the actual entire normalized
projection $\tau:W\to Y$ constructed from those sections, produce
\[
 T_\tau:\tau_*\omega_{W/k}\longrightarrow\omega_{Y/k}.
\]
The map has the intrinsic finite-locally-free trace normalization on every
open, for every original coefficient $b$ and every original top form $w$:
\[
 T_\tau(b\,d\tau(w))=\operatorname{tr}_\tau(b)w.
\]
Here $\operatorname{tr}_\tau:\tau_*\mathcal O_W\to\mathcal O_Y$ is the
actual sheaf trace, agreeing with the native finite-free algebra trace
on each original adapted chart.  In particular
$T_\tau d\tau=D\,\mathrm{id}$, where $D$ is the product of all actual
original root degrees.  No canonical trace, overlap square, global
cotangent basis, duality comparison, or retraction is an input.
\end{theorem}
\begin{proof}
The original sections produce the genuine adapted affine neighborhoods.
Use the canonical root-preserving normalized chart and its proved
triangle over the original base, rather than choosing a comparison
isomorphism as input.  Each whole ratio algebra is its actual mixed
root algebra.  The preceding mixed descent theorem constructs its
actual linear canonical trace on the same canonical sheaf sections.
The native affine quasicoherent equivalence turns this into a morphism
on the corresponding original affine open.

On an affine refinement of an intersection of two such base opens,
restrict both original whole finite-free algebras by their actual
coefficient base change.  The two native algebra traces agree: each is
the trace of multiplication in the same entire original restricted
algebra, and the proved trace formulas commute with these coefficient
changes and the actual original algebra identifications.  The two
canonical maps have the same intrinsic normalization on every pulled
base top form.  Adjoin the same whole unit-root cover used by either
one of the presentations.  The original branch denominator is regular
on this flat refinement.  Whole-pure uniqueness therefore equates the
two canonical maps there.  Faithfulness and the original invertible
canonical target give equality before that extension.  Affine
refinements detect the entire overlap equality.  Native module-Hom
sheaf gluing now constructs $T_\tau$ on the same entire $W\to Y$.

For completeness, the normalization on arbitrary opens uses a sheaf
trace, not a claim that every affine finite-projective section algebra
has a global free basis.  Apply the actual line projection formula to
form the genuine morphism
\[
 (\tau_*\mathcal O_W)\otimes\omega_Y
 \simeq\tau_*\tau^*\omega_Y\xrightarrow{\tau_*d\tau}
 \tau_*\omega_W\xrightarrow{T_\tau}\omega_Y.
\]
Cancel the original invertible $\omega_Y$ to obtain
$\operatorname{tr}_\tau:\tau_*\mathcal O_W\to\mathcal O_Y$.
On each adapted chart the already proved formula on every original
coefficient and every original top form identifies it with the native
finite-free trace of multiplication.  Thus it is the intrinsic
finite-locally-free sheaf trace.  The same tensor identity gives the
stated formula on all opens.  Taking $b=1$ and using the actual whole
monic basis gives the constant degree $D$; the auxiliary unit-cover
rank never occurs.
\uses{thm:kn-global-trace-mixed-descent,lem:kn-nadel-global-normalized-geometric-properties,lem:kn-nadel-whole-cover-trace-degree}
\end{proof}
