\subsection{A genuine local maximum of the original finite unit maximum at a Gauss vertex}

\begin{theorem}[An actual local maximum forces every constructed outgoing slope to vanish]
\label{analytic:actual-original-unit-max-local-maximum-slopes}

\lean{EnvelopeProperty.Berkovich.RelativeSpectrum.RationalUnitFamily.maxSlope_nonpos_of_isLocalMax,

\uses{analytic:actual-original-finite-unit-maxima-slopes,analytic:actual-original-rational-unit-gauss-balancing,analytic:actual-original-rational-unit-branch-slopes,analytic:actual-polynomial-gauss-inflation,spectrum:centered-gauss-whole-ray,spectrum:gauss-joint-continuity}
Suppose the SAME original real function $U$ has a genuine local maximum at
$\eta_r$: an actual neighborhood of $\eta_r$ satisfies $U(x)\le U(\eta_r)$
for EVERY whole point $x$ in it. Then EVERY actual constructed outgoing
maximum slope $\sigma_d$ is nonpositive and in fact zero. No sign,
vanishing, ray comparison, profile or harmonicity certificate is input.
\end{theorem}
\begin{proof}
Intersect that actual maximum neighborhood with the TRUE open
$N_*\ni\eta_r$ constructed by the preceding finite-max producer.
For an original listed branch direction choose an ORIGINAL
inside-product-root center $b$ representing its actual branch SET. Such a
center is furnished by the actual image description of that finite family.
The genuine whole-point map $t\mapsto\zeta_{b,t}$ is continuous, and its
entire value at $t=r$ is $\eta_r$ because $v(b)\le r$.
The actual positive interval $(0,r)$ has $r$ in its closure. Therefore
some ACTUAL $0<t<r$ has its whole centered Gauss point in BOTH original
neighborhoods. Its true coordinate formula puts it in the original
strict branch, with positive actual length $\ell=\log r-\log t$.
The already PROVED all-point maximum collar identity reads
$U(\zeta_{b,t})=U(\eta_r)+\sigma_d\ell$.
The genuine local-maximum inequality and $\ell>0$ imply $\sigma_d\le0$.

For the actual outer direction, the true original Gauss map
$t\mapsto\eta_t$ is continuous and takes $r$ to $\eta_r$.
The actual interval $(r,\infty)$ has $r$ in its closure, so some original
$t>r$ has its whole Gauss point in both neighborhoods. Its real length
$\log t-\log r$ is positive; the PROVED outer all-point collar formula
and the SAME maximum inequality give $\sigma_{\mathrm{out}}\le0$.
This uses genuine real radii, with no assumption that they belong to the
original field's value group.

The preceding original-unit count and active-max argument genuinely
DERIVES $\sum_d\sigma_d\ge0$. Every summand is now nonpositive, so
the true finite sum is zero and each actual summand is zero. The finite
direction family includes the actual outer direction even when there are
no original unit roots. No generic line classification or assumed
harmonic maximum principle is used.
\end{proof}

\begin{theorem}[The same original finite maximum is constant on a genuine open neighborhood]
\label{analytic:actual-original-unit-max-gauss-local-constancy}
\leanok
\lean{EnvelopeProperty.Berkovich.RelativeSpectrum.RationalUnitFamily.maxValue_eq_of_isLocalMax_on_maxNeighborhood,
EnvelopeProperty.Berkovich.RelativeSpectrum.RationalUnitFamily.exists_open_maxValue_constant_of_isLocalMax}
\uses{analytic:actual-original-unit-max-local-maximum-slopes,analytic:actual-original-finite-unit-maxima-slopes,analytic:actual-algclosed-disc-branch-cover}

EVERY original point of the constructed open $N_*$. Consequently the SAME
original function is constant on an ACTUAL open neighborhood of $\eta_r$

\end{theorem}
\begin{proof}
Let $x\in N_*$ be an arbitrary WHOLE original point. If $|T(x)|>r$,
the proved outer formula and the actual zero outgoing slope give equality.
Otherwise $x$ is an original point of the closed disc. If it is the actual
Gauss point, equality is literal. If it is different, the genuine
algebraically closed strict-branch cover supplies an original center $a$
with $x\in B_a$. If that ACTUAL branch SET is listed, its literal
product-root image description supplies an ORIGINAL root center $b$
with $B_a=B_b$. The original all-point listed formula on $N_*$ and its
actual zero slope give equality. If it is unlisted, the genuine whole-branch
constancy theorem already gives equality at EVERY point of that branch.
Thus EVERY whole point of the SAME actual $N_*$ has the original Gauss
value. Its openness, actual Gauss membership and all-original-unit
nonvanishing were genuinely proved before using the maximum hypothesis.
\end{proof}
