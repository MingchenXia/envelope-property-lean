\section{Native affine coefficient isomorphisms}
\label{sec:scheme-affine-coefficient-equivalences}

\begin{theorem}[The actual affine and open-section isomorphisms preserve original coefficients]
\label{thm:scheme-affine-coefficient-equivalences}
\lean{EnvelopeProperty.SchemeAffineCoefficientEquivalences.specSections, EnvelopeProperty.SchemeAffineCoefficientEquivalences.isoSections, EnvelopeProperty.SchemeAffineCoefficientEquivalences.openSections}
\leanok
\uses{thm:scheme-function-field-pullback-coefficients}
\source{bj22-trivval:sec:tc}
For every original $k$-algebra $A$, the actual canonical
isomorphism $A\simeq\Gamma(\operatorname{Spec}A,\mathcal O)$
is a $k$-algebra isomorphism for the original structure
morphism $\operatorname{Spec}A\to\operatorname{Spec}k$.
If an actual original scheme isomorphism identifies $Y$
with this spectrum, its unchanged section-ring isomorphism
is a $k$-algebra isomorphism for the resulting original
coefficient projection. For every open $U\subset X$ over
$k$, the actual isomorphism
$\Gamma(U,\mathcal O_U)\simeq\Gamma(X,U)$ also preserves
the original coefficient actions.
\end{theorem}

\begin{proof}
Naturality of the canonical spectrum/global-section
isomorphism with respect to the original coefficient ring
map identifies the image of every $a\in k$ with the native
structure-map action on the spectrum's sections. This proves
the first coefficient assertion. Pullback along an actual
scheme isomorphism is the same ring isomorphism on global
sections; the preceding original section-pullback coefficient
theorem makes it a $k$-algebra homomorphism. Its underlying
map is bijective, so it is a $k$-algebra isomorphism.
Finally, pullback along $U\hookrightarrow X$ followed by the
actual open top-section identification is exactly the
original restriction to $U$. Apply this identity to the
original scalar section from $\operatorname{Spec}k$.
It gives equality of the two original coefficient actions,
so the actual top-section ring isomorphism is a
$k$-algebra isomorphism as claimed.
\end{proof}
