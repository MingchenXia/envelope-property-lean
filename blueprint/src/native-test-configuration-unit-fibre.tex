\label{sec:native-test-configuration-unit-fibre}

\begin{theorem}[The original fibre one is the actual unit fibre {\cite[\S1.2]{BJ22}}]
\label{thm:native-test-configuration-unit-fibre}
\lean{EnvelopeProperty.NativeTestConfiguration.TestConfiguration.fibreOneInclusion, EnvelopeProperty.NativeTestConfiguration.TestConfiguration.fibreOneGroupLift, EnvelopeProperty.NativeTestConfiguration.TestConfiguration.fibreOneGroupLift_projection, EnvelopeProperty.NativeTestConfiguration.TestConfiguration.fibreOneGroupLift_parameter, EnvelopeProperty.NativeTestConfiguration.TestConfiguration.fibreOneGroupSquare, EnvelopeProperty.NativeTestConfiguration.TestConfiguration.groupPullbackFibreIso, EnvelopeProperty.NativeTestConfiguration.TestConfiguration.groupPullbackFibreIso_fst, EnvelopeProperty.NativeTestConfiguration.TestConfiguration.unitOpenFibreIso, EnvelopeProperty.NativeTestConfiguration.TestConfiguration.unitOpenFibreIso_fst, EnvelopeProperty.NativeTestConfiguration.TestConfiguration.unitOpenIso, EnvelopeProperty.NativeTestConfiguration.TestConfiguration.unitOpenIso_parameter, EnvelopeProperty.NativeTestConfiguration.TestConfiguration.unitOpenIso_structure}
\leanok
\uses{thm:native-test-configuration-unit-open, thm:equivariant-group-fibre-trivialization}
Every literal original test configuration has an internally
constructed isomorphism of its \emph{entire} original
noncentral open with the same original $X\times\mathbf G_m$,
from only the actual source data (i)--(iii).
Its whole parameter map and original parameter-line
structure diagram are retained. The intermediate fibre is
literally the same original native fibre over polynomial
parameter one, not a supplied generic-fibre comparison.
No normality, irreducibility or desired trivialization is assumed.
\end{theorem}

\begin{proof}
Write $P=\mathcal X\times_{\mathbf A^1}\mathbf G_m$ for the
same actual Laurent pullback, and $F=\mathcal X_1$ for the
same actual original fibre over polynomial evaluation at one.
The actual group inclusion preserves units, and the parameter
line unit was proved literally equal to this original
polynomial evaluation map. Thus the original whole inclusion
$F\to\mathcal X$ and constant group-unit map $F\to\mathbf G_m$
give an internally constructed whole lift $F\to P$.
Both complete projection equations follow from the original
Cartesian universal property.

The original outer fibre square for $F\to\mathcal X$ and
original right Cartesian square for $P\to\mathcal X$ imply,
by cancellation of Cartesian squares, that this same $F\to P$
is the actual unit fibre of the whole original parameter
$P\to\mathbf G_m$. This is a derived Cartesian square on
the same original native objects; no unit-fibre comparison
certificate is supplied. The latter parameter is genuinely
equivariant for the actual regular group action, by the
preceding Laurent-pullback construction.
The full equivariant-map-to-group theorem now constructs
$P\simeq\mathbf G_m\times F$ by the actual inverse-parameter
action and proves its whole original parameter equation.
Combine it with the actual isomorphism of $P$ with the
entire original noncentral open. Finally use the source
identification $F\simeq X$ and the actual product symmetry
to obtain the whole original $X\times\mathbf G_m$.
The parameter projection is exactly the original Laurent
parameter; composing with the actual original unit-group
inclusion, the original Cartesian equation and the two
whole open-inclusion diagrams recover exactly the original
parameter-line structure map. Full equivariance with the
standard product action is provided by the separate true
product-action theorem and its native transport consumer.
\end{proof}
