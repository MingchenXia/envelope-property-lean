\section{Original native analytic chart comparisons agree on actual overlaps}
\label{sec:projective-fixed-native-analytic-overlap}

\begin{theorem}[Whole fixed-model chart maps agree on every original native overlap]
\label{thm:projective-fixed-native-analytic-overlap}
\lean{EnvelopeProperty.ProjectiveFixedNativeAnalyticOverlap.nativeChartHomeomorph_eq_on_overlap}
\leanok
\uses{lem:native-generic-section-value-relations,thm:projective-fixed-native-analytic-support,thm:projective-fixed-native-analytic-values}
\source{bj22-trivval:sec:tc}
Let an original integral scheme have an actual closed embedding into finite
projective space over the original field. Fix one nonempty original
coordinate chart and reconstruct the actual whole-native-function-field
homogeneous model from it. At every original native valued point belonging
to two actual coordinate charts, the two original analytic chart
homeomorphisms give exactly the same point of this one fixed model.
\end{theorem}
\begin{proof}
The already proved exact support comparison puts both image points in the
first model chart. Test equality there on an arbitrary element $a$ of its
whole chart algebra. Write $a=g/D_j$ with $g$ an actual original homogeneous
piece of the fixed model and $D_j$ its chart denominator. In the second chart,
the actual elements $b=g/D_k$ and $r=D_j/D_k$ belong to the whole second chart
algebra. They satisfy the literal native field identity $ar=b$.
The inverse original section-algebra equivalences therefore give an actual
native generic-germ product identity for the three original sections.
Restricting to the actual original intersection and using generic-germ
injectivity gives the same identity of whole original regular sections.
Native evaluation gives $|a|\,|r|=|b|$ at the original point, even when its
support is nongeneric. Exact native chart value identities identify these
with the corresponding second-chart values. The fixed-model chart formulas
also give $|a|\,|r|=|b|$ for the second image viewed in the first chart.
Both chart denominators have nonzero values on the actual overlap; hence
$|r|\ne0$ and cancellation proves equality on every element of the first
whole chart algebra. Valuation extensionality and injectivity of the genuine
model chart homeomorphism prove equality of the whole model points.
No chart compatibility, support matching, or section-value certificate is
assumed: each comes from the actual original sections and fixed-model formulas.
\end{proof}
