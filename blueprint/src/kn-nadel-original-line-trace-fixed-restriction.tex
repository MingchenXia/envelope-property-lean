\begin{lemma}[The original line trace under a specified native line comparison]
\label{lem:kn-original-line-trace-native-fixed-restriction}
\lean{EnvelopeProperty.Vanishing.NadelGlobalCanonicalTrace.originalLineTrace_nativeFixedLineRestriction}
\uses{lem:kn-original-line-trace-native-open-restriction,lem:kn-original-line-trace-naturality,lem:scheme-pullback-congruence-reverse-hom}
\leanok
The exact original line trace restricts through the original cartesian
comparison and any specified line isomorphism on the base chart. The source
comparison is the native restriction--pullback isomorphism followed by the
inverse original pullback-composition word and pullback of that same specified
line isomorphism.
\end{lemma}
\begin{proof}
The original open restriction theorem gives the line trace with coefficients
in the pulled original base line. Naturality of the original line trace moves
the specified base line isomorphism to the source. The original pullback
congruence for the reverse equality is exactly the inverse of the original
forward congruence. Combining the three actual functor maps gives precisely
the stated source comparison, with all original data retained.
\end{proof}
