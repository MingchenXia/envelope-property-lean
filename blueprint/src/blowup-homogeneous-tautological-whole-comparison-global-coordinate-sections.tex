\begin{proposition}[Original global coordinate basis]
\label{prop:whole-original-global-coordinate-fraction-basis}
\lean{EnvelopeProperty.BlowupHomogeneousTautologicalLine.originalGlobalFractionCoordinateSection_isIso}
\leanok
\uses{prop:whole-original-fraction-projective-pivot-basis}
On each actual native prescribed nonzero-generator fraction spectrum $W$, the
pullback of the same original projective pivot coordinate along $vq$ is a basis.
\end{proposition}
\begin{proof}
The actual native global chart identity identifies $kq$ with the original affine
Rees map with the original coefficient map. Associativity therefore identifies
$vq$ with the original affine fraction restriction. Transport its established
original pivot basis through this equality of the actual scheme maps.
\end{proof}
