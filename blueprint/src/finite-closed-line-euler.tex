\section{True finite closed-ideal degree under original line tensoring}

\begin{definition}[The actual whole line-twisted finite quotient]
\label{def:fc-finite-closed-line-twisted-quotient}
\leanok
\lean{EnvelopeProperty.FiniteClosedLineEuler.twistedQuotientIso}
\uses{thm:fc-original-scheme-line-projection-formula, thm:fc-finite-closed-line-degree}
For the same actual finite closed immersion $g:D\hookrightarrow X$ and
any actual original invertible sheaf $L$, its true whole tensor quotient
$g_*\mathcal O_D\otimes L$ is identified with the same original
$g_*\mathcal O_D$. The actual whole projection formula reduces this to
the actual pulled-back line on the same finite closed scheme, where its
genuine derived global trivialization supplies the isomorphism.
\end{definition}

\begin{theorem}[Actual finite ideal tensor degree additivity]
\label{thm:fc-finite-closed-line-euler}
\leanok
\lean{EnvelopeProperty.FiniteClosedLineEuler.eulerCharacteristic_tensor_idealModule, EnvelopeProperty.FiniteClosedLineEuler.normalizedEulerCharacteristic_tensor_idealModule, EnvelopeProperty.FiniteClosedLineEuler.normalizedEulerCharacteristic_tensorObj_idealModule, EnvelopeProperty.FiniteClosedLineEuler.normalizedEulerCharacteristic_dual_idealModule, EnvelopeProperty.FiniteClosedLineEuler.normalizedEulerCharacteristic_tensor_dual_idealModule, EnvelopeProperty.FiniteClosedLineEuler.normalizedEulerCharacteristic_idealRatio}
\uses{def:fc-finite-closed-line-twisted-quotient, thm:fc-scheme-coherent-euler-characteristic-exact, thm:fc-finite-closed-ideal-euler}
On the original projective scheme, the full Euler characteristic satisfies
$\chi(\mathcal I_D\otimes L)=\chi(L)-\dim_k\Gamma(D,\mathcal O_D)$ for
any actual finite closed subscheme and any original invertible sheaf $L$.
Consequently its intrinsic normalized full Euler degree satisfies
$\deg_\chi(\mathcal I_D\otimes L)=\deg_\chi(\mathcal I_D)+\deg_\chi(L)$.
Both the actual native monoidal tensor and the original explicit sheafified
tensor satisfy this same formula. If the actual finite closed ideal is
invertible, its genuine dual has the opposite degree and tensoring by that
dual subtracts its original degree. Thus the original explicit tensor-dual
ratio of two actual finite closed ideals has their true degree difference.
No cohomological vanishing, global frame,
rank, or tensor-degree certificate is assumed.
\end{theorem}
\begin{proof}
Tensor the actual original finite closed-ideal short exact sequence by the
same invertible line. Genuine tensor equivalence preserves the entire
original short exact sequence. Its middle object is the same line, and its
third object is the actual whole twisted quotient from the preceding
construction. Quasicoherence follows from the true original line-tensor
comparison. Finite type of the middle and third terms follows from genuine
whole isomorphisms with the original coherent line and quotient; finite type
of the first follows from its actual kernel identification over the original
locally Noetherian projective scheme. Apply the unconditional genuine full
coherent Euler additivity. The actual affine finite closed structure scheme
computes the original quotient Euler characteristic as its true original
section dimension. Subtract the original structure-sheaf Euler characteristic
and use the already proved original finite ideal degree. Finally the genuine
whole comparison to the original explicit sheafified tensor preserves full
Euler characteristic, giving the same original-object formula. Apply the
true original evaluation isomorphism of an actual invertible ideal and its
genuine dual to get opposite degrees. Tensor the same evaluation with the
original line to obtain the inverse-ideal formula and hence the original
explicit ideal-ratio degree difference.
\end{proof}
