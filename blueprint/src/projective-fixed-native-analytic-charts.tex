\section{Whole original native analytic charts and one fixed reconstructed model}
\label{sec:projective-fixed-native-analytic-charts}

\begin{theorem}[Actual native point-space chart homeomorphisms {\cite[\S1.2]{BJ22}}]
\label{thm:projective-fixed-native-analytic-charts}
\lean{EnvelopeProperty.ProjectiveFixedNativeAnalyticCharts.nativeAffineChartHomeomorph, EnvelopeProperty.ProjectiveFixedNativeAnalyticCharts.nativeChartHomeomorph, EnvelopeProperty.ProjectiveFixedNativeAnalyticCharts.nativeChartHomeomorph_affine}
\leanok
\uses{thm:projective-fixed-native-model-charts,thm:projective-chart-generic-transitions}
For an actual original integral closed projective embedding and one
fixed original homogeneous model reconstructed over the entire native
$K(X)$, every nonempty original coordinate chart has a whole native
analytic homeomorphism onto the corresponding analytic coordinate
domain of that same fixed model. Its domain is exactly the original
native valued points over the trivial original field valuation whose
native scheme support belongs to that original open. The entire
homeomorphism commutes with the genuine model affine-chart map and the
actual original native affine spectrum comparison; it is not merely a
coordinate-value correspondence. No point-space or topology matching
certificate is supplied.
\end{theorem}
\begin{proof}
Native open restriction identifies the original support-open valued
points with valued points of the actual original open subscheme.
The proved whole original scheme isomorphism identifies this subscheme
with the spectrum of the corresponding fixed-model chart algebra.
Its proved literal coefficient triangle ensures that the entire
prescribed original base-point equation is preserved in both directions.
The canonical actual affine native-point comparison then identifies
this space with the Berkovich spectrum of the same original model
chart algebra.

The original alternative pivot is nonzero by the genuine generic
transition theorem. Thus the established homogeneous-model chart
homeomorphism applies to this same chart. Compose the original native
affine comparison with its inverse to obtain the claimed whole
homeomorphism into the fixed model coordinate domain. Applying the
original model affine-chart map to this composite gives the entire
original affine native comparison by the homeomorphism inverse law.
All maps are constructed from actual native open/scheme/spectrum maps;
the fixed original model is unchanged throughout. Compatibility of
different chart maps on overlaps and their global analytic gluing are
separate remaining producers.
\end{proof}
