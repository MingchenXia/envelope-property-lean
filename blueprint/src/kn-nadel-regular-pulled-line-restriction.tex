\section{The actual regular pulled-canonical trace has the original rational restriction}

\begin{theorem}[Rational restriction of the original regular pulled-line trace]
\label{thm:kn-original-regular-pulled-canonical-rational-restriction}
\lean{EnvelopeProperty.Vanishing.NadelGlobalCanonicalTrace.regularPulledCanonicalTrace_rational_restriction}
\uses{lem:kn-native-line-trace-square-from-structure}
\leanok
For the same original normalized SNC cover $\pi:Y\to X$ and the
original base canonical line, the actual regular pulled-canonical trace
$R$ followed by the SAME generic canonical inclusion equals the SAME
original whole-generic pulled-canonical rational trace. The assumptions
are only the original geometric cover data and their original SNC,
smoothness, positivity and tameness conditions. There is no extra
projection, scalar-square, frame, generic-field-model or rational
matching hypothesis.
\end{theorem}
\begin{proof}
The finite flat smooth cover theorem supplies finiteness internally.
The original global structure trace factors through the original whole
generic structure trace, already proved on the full generic fiber.
Its defining native structural square supplies the scalar equation of
the preceding line-square theorem. Specialize that theorem to the
original canonical line and the same two structure traces. The actual
generic canonical inclusion is its already proved native adjunction
unit. The exact stored-body readback of the original pulled rational
trace identifies the other endpoint with its unchanged compiled
construction. Thus the preceding whole native line-square equality is
exactly the required equation.
\end{proof}
