\section{The actual central generic section has the internally constructed line order}

All schemes, residue spectra, line modules and morphisms below are the
original ones. For $i:C\to Y$ and an original module $L$ on $Y$, put
$L_C=i^*L$ using the actual native pullback functor. The coefficient and
order are exactly the existing intrinsic original generic-section APIs;
no coordinate class, substitute generic stalk, or scalar identification is
introduced.

\begin{lemma}[The actual restricted frame has generator coefficient one]
\label{lem:intrinsic-numerical-central-generator-original-coefficient}
\lean{EnvelopeProperty.NumericalGaussCurveSectionOrders.genericCoefficient_closedGenerator}
\leanok
\uses{def:central-generic-original-local-section-value,def:curve-generic-section-original-coefficient,lem:fc-original-section-pullback-frame,alggeom:actual-original-frame-pullback-composition,lem:actual-line-frame-via-factor-composition,def:actual-line-frame-via-factor,lem:fc-original-line-section-fibre,lem:actual-generic-residue-field-equivalence}
Let $C$ be integral, $i:C\to Y$ the actual morphism, $V\subset Y$
contain $i(\eta_C)$, and $\varepsilon:O_V\simeq L|_V$ an actual frame.
Use the actual original frame
\[
 e_C=\operatorname{localPullbackFrame}(i,V,\varepsilon^{-1})
\]
on the actual $C$-open $i^{-1}V$. The existing original
$\operatorname{closedGenericSection}(i,L,V,\varepsilon)$ has intrinsic
coefficient exactly $1$ in this SAME $e_C$. No fibre or frame comparison
is a premise.
\end{lemma}
\begin{proof}
The actual generic residue morphism of $C$ factors through $i^{-1}V$.
Its composition with the actual restriction of $i$ to $V$ is the original
closed-generic open factor: both maps have the SAME composite with the
monomorphism $V\hookrightarrow Y$. The original whole frame-pullback
composition theorem, followed by the original whole factor-composition
theorem, identifies the intrinsic generic frame of $e_C$ with the native
pullback-composition comparison followed by the transported inverse of
$\varepsilon$. These are the actual maps in the old closed-generic section
definition. Applying this inverse frame to that actual generator cancels
the actual comparisons and $\varepsilon$ against its inverse, leaving
the original unit section. The actual $\Gamma\operatorname{Spec}$ map and
inverse generic-residue field equivalence send this unit to $1$. This is
a coefficient identity on the original generic residue pullback module.
\end{proof}

\begin{theorem}[The same original central coefficient is the intrinsic section order]
\label{thm:intrinsic-numerical-central-section-original-order-and-norm}
\lean{EnvelopeProperty.NumericalGaussCurveSectionOrders.exists_twoFrame_intrinsicOrder}
\leanok
\uses{lem:intrinsic-numerical-central-generator-original-coefficient,thm:intrinsic-numerical-original-two-frame-model-norm,def:curve-generic-section-original-coefficient,lem:curve-generic-section-scalar-tensor-order,def:curve-generic-section-original-order,def:central-generic-original-local-section-value,cor:central-generic-prescribed-section-same-rational-lift}
Assume $Y,C$ integral, $C$ locally Noetherian, and $Y$ proper over the
actual bounded base valuation. Let $L$ be actual invertible, and fix ONE
actual frame $\delta$ near $i(\eta_C)$, with its SAME original generic
sections $\rho,\sigma_C$. The latter is nonzero by its actual frame
construction. For every original $x$, internally choose the SAME actual
$V,\delta_x,W,r,u,f,b$ as in the genuine two-frame norm theorem. Retain
its original regular-unit/germ representation, both raw fibre equations
and its norm formula for EVERY original generic-support native point with
TRUE center $i(x)$, without requiring $i(x)\in W$.

In the actual central frame
$e_x=\operatorname{localPullbackFrame}(i,V,\delta_x^{-1})$ on $i^{-1}V$,
the SAME prescribed original $\sigma_C$ has intrinsic coefficient $b$.
Consequently its actual intrinsic order is
\[
 \operatorname{order}(L_C,\sigma_C,x)=C.\operatorname{ord}(b,x).
\]
The coefficient and order identities are derived internally. Neither a
scalar-matching equation nor an order, slope, norm or degree certificate
is an incoming hypothesis.
\end{theorem}
\begin{proof}
The original pullback of $L$ is invertible. The first lemma applied to
the actual old frame $\delta$ gives coefficient one for $\sigma_C$ in
that actual central frame. If $\sigma_C=0$, linearity of these same native
maps would give coefficient zero, contradicting $1\ne0$. This proves its
actual nonvanishing without an additional section premise.

Apply the frozen two-frame norm producer internally, retaining all its
actual data. Its already proved central fibre equation says
$\sigma_C=b\sigma_x$ using the genuine generic-residue scalar map. This
is exactly the existing original scalar-section operation. The intrinsic
scalar-coefficient formula therefore gives the coefficient of $\sigma_C$
in $e_x$ as $b$ times the coefficient of $\sigma_x$. The first lemma gives
that latter coefficient as one, so it is exactly $b$. Apply the existing
intrinsic order formula in ANY actual frame containing the original $x$,
with the just proved actual nonvanishing and the actual central inverse-
image open. Substituting the coefficient identity proves the displayed
order formula. All previously proved true-center norm and regular-unit
identities remain unchanged.
\end{proof}

The later fixed-Gauss specialization must combine this intrinsic order
with the SAME actual weighted point, its independently proved true center,
its original section evaluation, and the actual vertical-unit leading
order theorem. The final full Euler-degree argument uses the SAME one
original generic section and its intrinsic whole-curve order family;
the varying local functions $f_x$ are never separately treated as one
global principal divisor.
