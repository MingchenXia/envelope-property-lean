\section{The same whole explicit tensor inclusion under original native pullback}
\label{sec:scheme-tensor-ideal-pullback}

\begin{definition}[The genuine original explicit tensor pullback isomorphism]
\label{sc0-scheme-tensor-ideal-pullback:actual-iso}
\lean{EnvelopeProperty.SchemeTensorIdealPullback.tensorObjPullbackIso}
\leanok
For ANY original scheme morphism, the SAME native monoidal pullback and
SAME original explicit sheaf-tensor comparisons give a genuine isomorphism
from the pullback of the original explicit tensor to the explicit tensor
of the SAME original pullbacks.
\end{definition}
\begin{proof}
First use the inverse of the actual monoidal tensor comparison followed
by the mapped original monoidal-to-explicit tensor isomorphism. Then use
the actual original target monoidal-to-explicit comparison. Every constituent
is a genuine original isomorphism, so their stated composite is an actual
whole isomorphism, without a tensor comparison premise.
\end{proof}

\begin{theorem}[The entire same original tensor inclusion square]
\label{sc0-scheme-tensor-ideal-pullback:whole-inclusion}
\lean{EnvelopeProperty.SchemeTensorIdealPullback.tensorObjIdealMap_pullback}
\leanok
Pullback of the entire original explicit tensor-to-structure inclusion is
exactly the actual preceding tensor isomorphism followed by the SAME
original target tensor inclusion of the pulled original morphism, with
the TRUE native structure-module pullback unit. This holds for EVERY
original map to the structure module; no invertibility, open immersion,
flatness, affine or compatibility premise is needed.
\end{theorem}
\begin{proof}
The original explicit tensor ideal map is proved equal to its SAME native
monoidal right-unit expression. Genuine native monoidal functor tensor
naturality and right-unit coherence show that this ENTIRE expression pulls
back with the actual monoidal unit comparison. The actual AINT native
pullback-unit theorem identifies that comparison with the SAME original
structure-module pullback isomorphism, via the SAME original sheafification
unit comparisons. Thus no unit-matching equation is supplied. Cancel the
genuine source tensor comparison to obtain the claimed equality of the
ENTIRE original explicit morphisms. This supplies the actual rounded
canonical inclusion pullback comparison; native ideal-comap and original
open differential isomorphisms are then applied by the geometric consumer.
\end{proof}

\begin{theorem}[Same whole original geometric ideal under an actual open map]
\label{sc0-scheme-tensor-ideal-pullback:original-open-ideal}
\lean{EnvelopeProperty.SchemeTensorIdealPullback.idealTensorOpenPullbackIso,EnvelopeProperty.SchemeTensorIdealPullback.idealTensorOpenPullbackIso_inclusion}
\leanok
For an actual original open immersion and ANY original ideal sheaf, the
preceding comparison and the SAME native ideal-comap module isomorphism
give a genuine whole tensor-ideal pullback isomorphism. Its entire original
inclusion square commutes with the SAME pulled original tensor inclusion.
No Cartier, flatness, chosen generators or ideal-matching premise is supplied.
\end{theorem}
\begin{proof}
Compose the proved original tensor pullback isomorphism with tensoring
the genuine original ideal-module open-pullback isomorphism. The native
ideal-comap comparison commutes with BOTH original ideal inclusions and
the TRUE original structure-module pullback map. Explicit tensor-map
naturality and the original right-unit expression show that postcomposing
the tensor of an original map with an ideal inclusion is exactly tensoring
their original composite. Substitute the native ideal-comap square into
that whole-map identity and apply the preceding original pullback theorem.
This proves the ENTIRE original inclusion square, rather than an assumed
agreement of image families or generators.
\end{proof}
