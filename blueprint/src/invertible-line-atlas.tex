\section{Native original invertibility supplies the same genuine line atlas}
\label{sec:invertible-line-atlas}

\begin{definition}[The genuine original over-site atlas from native invertibility]
\label{sc0-native-line-atlas:actual-over-atlas}
\lean{EnvelopeProperty.CanonicalGeometry.invertibleLineAtlas}
\leanok
For ANY original scheme and ANY original module $L$, native original
invertibility of $L$ DERIVES a genuine line atlas on that SAME original
module, with actual over-site structure-sheaf frames. No atlas, cover,
frame or comparison is added as a separate assumption.
\end{definition}
\begin{proof}
Unpack the actual native invertibility theorem's original open cover and
actual pullback-to-unit isomorphisms. Use the SAME native
restriction/pullback comparison to obtain actual original restriction
frames. The genuine original over-site equivalence then carries each
restriction frame into an over-site frame of the SAME original module.
The original supremum-cover equality gives coverage of EVERY original
point, including the empty-scheme case. These original opens, true
frames and derived coverage form the required actual line atlas.
\end{proof}
