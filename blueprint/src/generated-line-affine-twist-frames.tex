\section{Original generated-line frames and the same pulled projective line}

\begin{definition}[The same actual affine map's original coordinate line frame]
\label{def:fc-generated-line-affine-twist-frame}
\leanok
\lean{EnvelopeProperty.GeneratedLineAffineTwistFrames.generatorCoordinate, EnvelopeProperty.GeneratedLineAffineTwistFrames.paddedCoefficient_generator, EnvelopeProperty.GeneratedLineAffineTwistFrames.coordinateSectionHom, EnvelopeProperty.GeneratedLineAffineTwistFrames.affineChartFactor, EnvelopeProperty.GeneratedLineAffineTwistFrames.affineChartFactor_comp, EnvelopeProperty.GeneratedLineAffineTwistFrames.affineChartFactor_coordinate, EnvelopeProperty.GeneratedLineAffineTwistFrames.pulledCoordinateSection, EnvelopeProperty.GeneratedLineAffineTwistFrames.pulledCoordinateSection_isIso, EnvelopeProperty.GeneratedLineAffineTwistFrames.affineTwistFrame, EnvelopeProperty.GeneratedLineAffineTwistFrames.affineTwistIso}
\uses{thm:fc-generated-tuple-unit-chart,thm:fc-coordinate-section-own-chart-frame,thm:fc-line-section-factorization}
Let $X$ be an actual integral affine scheme, $L$ its original line,
$G$ its original finite generators, and $e$ an actual whole frame.
When the actual coefficient of one original generator $G_i$ is one,
the SAME original affine projective morphism factors through that
original coordinate chart. Its actual pulled original $O(1)$ frame
therefore gives an actual whole isomorphism $f^*O(1)\simeq L$.
\end{definition}
\begin{proof}
The original padded tuple has pivot one at the coordinate of that
SAME original generator. Compose the genuine original tuple chart
factor with the original affine-spectrum isomorphism. Its entire
triangle is the SAME original affine projective morphism. The original pivot coordinate section is an actual isomorphism on
its original chart, so its SAME original pullback along the literal
factor is an isomorphism. Its actual inverse is the canonical
pulled-line frame. Compose it with the inverse of the SAME original
frame $e$.
\end{proof}

\begin{theorem}[The actual pulled coordinate sections are the same original generators]
\label{thm:fc-generated-line-affine-twist-sections}
\leanok
\lean{EnvelopeProperty.GeneratedLineAffineTwistFrames.pulledCoordinateSection_relation, EnvelopeProperty.GeneratedLineAffineTwistFrames.affineTwistFrame_sectionHom, EnvelopeProperty.GeneratedLineAffineTwistFrames.affineTwistIso_sectionHom}
\uses{def:fc-generated-line-affine-twist-frame,thm:fc-coordinate-section-chart-ratio,thm:fc-line-section-factor-scalar-relation}
The preceding actual original line isomorphism sends each pulled
original coordinate section indexed by $G_j$ to the SAME original
global generator $G_j$ on the ENTIRE original affine scheme.
\end{theorem}
\begin{proof}
On the original projective chart the SAME whole coordinate section
$X_j$ equals the actual scalar $X_j/X_i$ times the SAME original
pivot section. Pull this entire relation through the literal actual
coordinate factor. Its original ring value on the native
spectrum is the literal image of the SAME coefficient of $G_j$.
The original affine-spectrum unit cancels the original global-section
identification, giving precisely that original coefficient in
$\Gamma(X,O_X)$. Native pullback composition and unit coherence
then give the entire original section-morphism identity. The SAME
frame $e$ gives this exact coefficient for the original generator,
so its inverse gives the asserted equality of original sections.
\end{proof}
