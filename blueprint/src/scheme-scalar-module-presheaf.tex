\section{Literal scalar-linear sections on every original open}

\begin{lemma}[Original scalar-linear module sections on every original open]
\label{lem:fc-scheme-scalar-module-presheaf}
\uses{lem:fc-affine-module-flat-base-change}
\lean{EnvelopeProperty.SchemeScalarModulePresheaf.openSections,EnvelopeProperty.SchemeScalarModulePresheaf.presheaf,EnvelopeProperty.SchemeScalarModulePresheaf.sheaf,EnvelopeProperty.SchemeScalarModulePresheaf.topSectionsIso,EnvelopeProperty.SchemeScalarModulePresheaf.topSectionsIso_apply}
\leanok
For an original $p:X\to\operatorname{Spec}R$ and any original module $M$,
the actual section module $\Gamma(U,M)$ carries its literal original
$R$-action through $R\to\Gamma(U,\mathcal O_X)$. These section modules
and the original restriction maps form an actual sheaf of $R$-modules.
At the original top open, this is the literal whole global-section
module used in the preceding affine comparison.
\end{lemma}
\begin{proof}
Use the actual map $p$ on sections from the original spectrum top open
to each original source open, preceded by the genuine spectrum section
isomorphism. Restrict the native module action along that exact ring
homomorphism. Native module semilinearity and presheaf composition make
each actual restriction $R$-linear. Identity and composition are the
original identities and compositions of the module presheaf.
Forgetting coefficients recovers the literal original module sheaf,
whose actual sheaf condition therefore gives the stated sheaf condition.
The top coefficient homomorphism is the original global coefficient map.
\end{proof}
