\section{The entire original dual evaluation and principal-open generation}

\begin{lemma}[The whole original dual evaluation]
\label{lem:all-section-dual-evaluation}
\leanok
\lean{EnvelopeProperty.AllSectionDualEvaluation.familyEvaluation_all,EnvelopeProperty.AllSectionDualEvaluation.familyEvaluation_imageIdeal}
For any original invertible module $L$, the original dual evaluation
of ALL its original global sections is exactly the whole original
free evaluation tensored with the original dual, followed by the
original pairing. Its actual whole image ideal is the original
base ideal generated by ALL global sections.
\uses{def:scheme-module-all-global-evaluation,prop:generated-line-whole-base-ideal-unit}
\end{lemma}
\begin{proof}
Test the actual free coproduct on every original basis injection.
The genuine preserved-coproduct comparison identifies that injection
with the same original dual summand. The actual tensor-unit
coherence, the exact original section/free-basis identity and
functoriality identify the whole map with the tensored original
evaluation followed by pairing. The whole family-image formula
then identifies its entire image ideal with the supremum of all
original section ideals, exactly the original base ideal. No
global-generation premise is used for this identity.
\end{proof}

\begin{proposition}[Entire original dual evaluation is epi on a generated principal open]
\label{prop:all-section-dual-evaluation-principal-epi}
\leanok
\lean{EnvelopeProperty.AllSectionDualEvaluation.restrict_familyEvaluation_epi}
Let $X$ be quasicompact and separated, $\pi:X\to B$ any morphism,
$L$ invertible and $P=\pi^{-1}D(r)$. If the actual restriction
$L|_P$ has genuine generating sections, the restriction of the
ENTIRE original all-section dual evaluation is an epimorphism.
\uses{lem:all-section-dual-evaluation,prop:scheme-module-original-evaluation-principal-epi}
\end{proposition}
\begin{proof}
The original whole free evaluation restricted to $P$ is epi by
the actual localization-and-cokernel theorem. Native restriction
is genuinely monoidal via its original pullback comparison.
Its tensor naturality square and invertible tensor comparisons
identify the restricted tensor of that same original evaluation
with the tensor of its restricted map by the SAME restricted dual
line. The latter is epi because tensoring by that actual invertible
line is an equivalence. The actual original pairing is invertible,
as is its restriction. The preceding whole-map identity therefore
gives the claimed epi, with no chosen matching-family or tensor
comparison certificate. In the eventual concrete test-configuration
consumer, ampleness and the actual source line isomorphism must
still supply generation on $P$.
\end{proof}
