\section{The intrinsic original differential and coordinate independence}
\label{sec:etale-differential-intrinsic}

\begin{theorem}[Every original wedge of universal differentials is closed]
\label{lem:cartier-etale-universal-wedge-closed}
\lean{EnvelopeProperty.Cartier.EtaleDifferentialIntrinsic.differential_universalWedge}
\leanok
For EVERY tuple of original functions $g_1,\ldots,g_q$ of the SAME original
etale coordinate ring, the original form $dg_1\wedge\cdots\wedge dg_q$ is
closed in the SAME actual original complex. No coordinate-function,
closedness, characteristic or derivative-comparison premise is assumed.
\end{theorem}
\begin{proof}
In degree zero the original exterior unit is closed because the SAME
actual degree-zero differential is the original universal differential of
one. A successor universal wedge is the actual product of the SAME original
one-form $dg_1$ and the tail original wedge. The native one-degree exterior
identification and true original exterior cons/product equality retain the
original vector and whole tail form exactly. The preceding full original
graded Leibniz formula applies. The original one-form $dg_1$ is already
proved closed, and genuine induction makes the tail closed. Both actual
terms therefore vanish in the SAME original exterior algebra; injectivity
of the true homogeneous submodule inclusion proves the original equality.
\uses{thm:cartier-etale-original-graded-leibniz,lem:cartier-etale-intrinsic-closed-generators}
\end{proof}

\begin{theorem}[Whole original intrinsic universal-generator formula]
\label{lem:cartier-etale-intrinsic-generator-formula}
\lean{EnvelopeProperty.Cartier.EtaleDifferentialIntrinsic.differential_smul_universalWedge}
\leanok
For EVERY original coefficient $a$ and EVERY tuple of original functions,
the SAME actual differential satisfies
$d(a\,dg_1\wedge\cdots\wedge dg_q)=da\wedge dg_1\wedge\cdots\wedge dg_q$.
\end{theorem}
\begin{proof}
Apply genuine original scalar Leibniz to the SAME original coefficient and
whole actual universal wedge. Its genuine closedness kills the second
term. All original universal differentials, exterior products, original
coefficient actions and the actual differential are retained.
\uses{lem:cartier-etale-universal-wedge-closed,lem:cartier-etale-intrinsic-scalar-leibniz}
\end{proof}

\begin{theorem}[Entire differential is independent of actual etale coordinates]
\label{thm:cartier-etale-whole-differential-coordinate-independence}
\lean{EnvelopeProperty.Cartier.EtaleDifferentialIntrinsic.differential_eq_of_coordinates,EnvelopeProperty.Cartier.EtaleDifferentialIntrinsic.complexIso_of_coordinates,EnvelopeProperty.Cartier.EtaleDifferentialIntrinsic.frobeniusComplexIso_of_coordinates}
\leanok
For ANY TWO actual original etale coordinate tuples on the SAME original
$R$-algebra $B$, their ENTIRE actual exterior differentials agree on every
original homogeneous form and every degree. The two coordinate tuples may
have different lengths. No coordinate-change or derivative-matching input
is assumed. The SAME original additive complexes, and in prime characteristic
the SAME original Frobenius-linear complexes, have true native isomorphisms
whose EVERY component is the identity on the original exterior module.
\end{theorem}
\begin{proof}
The second actual coordinate tuple gives its genuine original finite
exterior cotangent basis. Every original form has its true original
coefficient expansion in this basis. Every actual basis wedge is exactly
the wedge of the SAME universal differentials of the second tuple's
original coordinate functions, by the proved original cotangent-basis
values and the native exterior-basis formula.
Both differentials satisfy the preceding intrinsic formula on EVERY
original coefficient times this SAME original universal wedge, even though
one differential came from the other tuple. Hence they agree on each term.
Actual additivity and the true entire original basis expansion give equality
on EVERY original form. No equality of tuple lengths is needed.
The actual whole complex isomorphisms use identity components on the SAME
original exterior modules. The derived whole differential equality gives
the true native cochain commutation; native Frobenius restriction retains
the SAME actual original scalar action and differential.
\uses{lem:cartier-etale-intrinsic-generator-formula}
\end{proof}
