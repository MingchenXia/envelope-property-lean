\section{Actual original FS nonvanishing from genuine whole-section norms}
\label{sec:native-line-fubini-study-nonvanishing}

\begin{definition}[Actual original FS functions of an original line]
\label{def:native-line-whole-section-general-fs}
\lean{EnvelopeProperty.NativeLineFubiniStudy.IsFS}
\leanok
\uses{def:native-line-whole-section-fs}
An actual original FS function of class coefficient $a$ is the weighted
true-norm evaluation of finite data of entire original sections of
$L^{\otimes ma}$, with the original positive integer denominator $m$, where
these actual original sections are not all zero. Arbitrary real weights and
common zeroes are allowed. The definition contains no chosen model or desired
norm or nonvanishing comparison.
\end{definition}

\begin{theorem}[True original FS nonvanishing is detected on the entire native space]
\label{thm:native-line-whole-section-fs-nonvanishing}
\lean{EnvelopeProperty.NativeLineFubiniStudy.FSData.eval_ne_bot_iff_exists_norm_ne_zero,EnvelopeProperty.NativeLineFubiniStudy.FSData.nonzero_iff_exists_eval_ne_bot,EnvelopeProperty.NativeLineFubiniStudy.IsFinFS.isFS}
\leanok
\uses{def:native-line-whole-section-general-fs,thm:scheme-original-global-section-norm-detection,def:native-line-whole-section-fs}
At each actual original native point, the weighted original FS evaluation is
not negative infinity exactly when some actual original member has nonzero
true norm there. On an integral original proper scheme, a finite family is not
all zero exactly when this weighted function is not negative infinity
somewhere on the whole native point space. Every actual original finite
rational FS function is consequently an actual original FS function.
\end{theorem}
\begin{proof}
The original positive reciprocal denominator preserves nonnegative-infinite
extremes. A finite supremum of the actual logarithmic weighted terms is
negative infinity exactly when every term is negative infinity. The genuine
extended logarithm makes this equivalent to zero norm of every original
section at that point. Genuine original whole-section norm detection gives a
native point with nonzero norm for every nonzero original member. Conversely,
a member with nonzero norm cannot be the original zero section. For the finite
rational predicate, choose its actual nonvanishing member at the genuine
trivial native point over the original generic point. These arguments retain
zero sections, common zeroes and empty families without a nonvanishing
certificate or model comparison assumption.
\end{proof}
