\section{The same canonical differential along an original local lift}
\label{sec:valuative-canonical-differential}

\begin{theorem}[Entire original differential isomorphism along local lifts]
\label{sc0-valuative-canonical:whole-pulled-differential}
\lean{EnvelopeProperty.CanonicalGeometry.pullback_exteriorDifferential_isIso_of_formallyEtale_composite,EnvelopeProperty.CanonicalGeometry.pullback_exteriorDifferential_isIso_of_source_localization}
\leanok
Let $g:Y\to X$ be an original morphism between original smooth
$k$-schemes of the same relative dimension $n$, with $X$ affine and
an actual original global differential basis. For EVERY original
map $l:\operatorname{Spec}V\to Y$ from an original local ring whose
ORIGINAL composite $l g$ has a formally etale whole section-ring
map, the SAME ENTIRE pullback $l^*(\delta_g)$ of the original top
exterior differential is an actual isomorphism. In particular this
holds for EVERY actual lift whose original structural triangle is
the spectrum of an original source localization $R\to V$.
No desired inverse, target-affine chart, Jacobian-unit or
coefficient-matching certificate is supplied.
\end{theorem}
\begin{proof}
The preceding actual affine formal-etale theorem makes the SAME
whole original composite differential $\delta_{l g}$ an
isomorphism. The already proved ENTIRE original differential
composition identity expresses it, through the true native
pullback-composition and structural-associativity comparisons, as
$l^*(\delta_g)$ followed by the SAME original $\delta_l$.
Cancelling the actual pullback-composition isomorphism shows this
actual whole composite is an isomorphism.

The source and middle modules are genuine invertible lines by
original smoothness and actual pullback. The target module is
also genuinely invertible: the actual composite differential
isomorphism identifies it with pullback of the original source
canonical line. The true local-spectrum line-map cancellation
therefore proves that the SAME entire first map $l^*(\delta_g)$
is an isomorphism. All actual frames are derived internally from
these original invertibility facts and the original local ring.

For a genuine original localization triangle, actual localization
formal etaleness holds in the original rings. The preceding
native spectrum/global-section coefficient-square theorem
transports it to the SAME actual composite section map. Apply the
first assertion. The intervening $Y\to X$ and $l$ need not be
etale; no extra locality or determinant hypothesis is introduced.
\uses{sc0-affine-formally-etale:whole-native-differential,
      sc0-local-line-cancel:entire-first-factor,
      sc0-spec-formally-etale:original-section-map}
\end{proof}

Actual proper valuative existence provides these original lifts
with both original triangles. Comparing the SAME pulled Hom-section
and its original rational coefficient, then the full rounded
canonical-module pushforward, remain subsequent obligations.
No vanishing conclusion is claimed here.
