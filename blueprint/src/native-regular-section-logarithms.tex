\subsection{Original native section logarithms and genuine rational-unit adjustments}

\begin{lemma}[Whole original section logarithms, restriction and pullback]
\label{scheme:actual-original-native-section-logarithms}
\leanok
\lean{EnvelopeProperty.Berkovich.SchemeValuedPoint.sectionLogAbs,
EnvelopeProperty.Berkovich.SchemeValuedPoint.sectionLogAbs_of_mem,
EnvelopeProperty.Berkovich.SchemeValuedPoint.sectionLogAbs_of_notMem,
EnvelopeProperty.Berkovich.SchemeValuedPoint.sectionLogAbs_restrict,
EnvelopeProperty.Berkovich.SchemeValuedPoint.sectionLogAbs_map,
EnvelopeProperty.Berkovich.SchemeValuedPoint.continuousOn_sectionLogAbs,
EnvelopeProperty.Berkovich.SchemeValuedPoint.sectionLogAbs_unit_eq_coe_log}
\uses{scheme:valued-points,scheme:valued-point-pullback,scheme:valued-point-topology}
For ANY actual scheme $X$, original scheme open $V$ and original section
$a\in\Gamma(X,V)$, define the extended-real function on the original native
point space by the actual logarithm of its genuine section evaluation when
the support lies in $V$, and by negative infinity otherwise. At EVERY actual
point supported in $V$ this is exactly the ORIGINAL extended logarithm.
It is continuous on the true support-open preimage of $V$, including section
zeros. For an original section UNIT the same function is the finite real
logarithm of its original evaluation and is neither infinity on that locus.
For actual scheme-open restriction, whole evaluation equality retains the
original logarithm on the smaller support locus. Every true scheme map
pulls the ENTIRE extended function back to the actual original section map,
with its exact preimage scheme open. These statements also hold on any exact
prescribed-base native locus without inferring an algebra action on $\Gamma(X,V)$.
\end{lemma}
\begin{proof}
The actual support condition is part of the function definition. On its genuine
support-open subspace the original section evaluation is continuous by the
checked native topology, and the original extended logarithm is continuous,
even at zero. Genuine presheaf restriction commutes with EVERY original
section evaluation, so applying the same logarithm gives the restriction law.
For a true scheme map its actual point map has exactly the support-preimage
condition, and the genuine all-element section evaluation square gives
whole function equality on that locus; off it both original functions are
negative infinity by their definitions. Actual units evaluate nonzero,
because their genuine inverse multiplies to one. Hence the actual extended
logarithm is precisely its finite real logarithm there. Restriction to the
actual prescribed-base subtype preserves every value and continuity claim.
\end{proof}

\begin{theorem}[Actual original unit logarithms give rational PL terms and adjustments]
\label{scheme:actual-native-rational-unit-log-adjustments}
\leanok
\lean{EnvelopeProperty.Berkovich.RelativeSchemeValuedPoint.isConvexPLOn_smul_sectionLogAbs,
EnvelopeProperty.Berkovich.RelativeSchemeValuedPoint.IsConvexPLOn.add_smul_sectionLogAbs,
EnvelopeProperty.Berkovich.RelativeSchemeValuedPoint.IsDecrConvexPLLimitOn.add_smul_sectionLogAbs,
EnvelopeProperty.Berkovich.RelativeSchemeValuedPoint.IsLocallyPSHOn.add_smul_sectionLogAbs}
\uses{scheme:actual-original-native-section-logarithms,scheme:actual-native-convex-pl-closure,scheme:actual-native-local-psh-closure}
Let $v$ be ANY prescribed valuation of ANY original coefficient ring and use
its actual native scheme point space. For an actual $a\in\Gamma(X,V)^\times$
and ANY rational $q$, the ORIGINAL function $q\log|a|$ is intrinsically convex
PL on the true support-open preimage of $V$. If $u$ is intrinsically convex
PL, an actual decreasing convex PL limit, or intrinsically locally psh on
$U$, then $u+q\log|a|$ belongs to that SAME class on the ACTUAL intersection
of $U$ with this support-open locus. The rational coefficient may be negative
or zero. No field, domain, finite type, Noetherianity, separation, completeness,
norm bound or classical harmonicity is assumed. Old function classes and
old proof bodies remain untouched.
\end{theorem}
\begin{proof}
Take the ORIGINAL one-element unit family $a$ and the genuine singleton
rational coefficient vector $(q,0)$. Its exact finite-unit formula is the
actual $q$ times the finite real logarithm, hence precisely the ORIGINAL
extended-real function on the actual support-open locus. This is a genuine
presentation, not a unit-PL property certificate. Negative $q$ causes no
convexity issue because this is a single real affine expression in a genuine
unit value. The zero case is the actual zero expression.

Intersect the two original open domains. True open restriction and the
already checked SAME-function sum theorem prove the convex PL adjustment.
Use the actual constant sequence of the original unit PL term for decreasing
limits, and add it termwise to the original restricted sequence. Its values
are finite there, so the genuine extended-real infimum sum law applies,
including where the ORIGINAL $u$ is negative infinity. For the local class
use the actual finite intersection of the original local presentation
neighborhood and the support-open locus, then the true local sum theorem.
No countable intersection, common denominator or analytic harmonicity inference
is introduced.
\end{proof}
