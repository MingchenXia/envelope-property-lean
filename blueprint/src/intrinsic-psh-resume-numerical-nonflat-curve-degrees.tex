\section{Original curve line degrees under finite dominant maps without flatness}

\begin{theorem}[The actual geometric Cartier ideal has its whole degree projected]
\label{thm:intrinsic-numerical-nonflat-cartier-degree}
\uses{scheme:existing-ideal-module-affine-sections,def:fc-scheme-coherent-euler-characteristic,def:fc-original-curve-line-degree,def:intrinsic-numerical-canonical-function-field-degree,def:fc-curve-cartier-original-equations,thm:fc-curve-cartier-native-local-orders,thm:fc-curve-cartier-ideal-finite,thm:fc-curve-finite-closed-subschemes,lem:nonflat-dominant-cartier-comap,thm:intrinsic-numerical-cartier-order-full-fibre,thm:fc-curve-cartier-weighted-degree,lem:actual-integral-projection-dimension-bound,thm:fc-curve-finite-map-projective}
\lean{EnvelopeProperty.NumericalNonflatCurveDegrees.degree_comap_toModules}
\leanok
Let $q:C\to\operatorname{Spec}k$ be an original projective structure on
an integral scheme of dimension at most one, and let $g:D\to C$ be an
actual finite dominant morphism with $D$ integral. For every original
effective Cartier ideal $I$,
\[
 \deg_{gq}(I\mathcal O_D)^{\sim}=N(g)\deg_q I^{\sim},
\]
where the degree is the original normalized full coherent Euler
characteristic and $N(g)$ is the same canonical original function-field
extension degree. No flatness, target normality, support finiteness,
residue extension or degree comparison is assumed.
\end{theorem}
\begin{proof}
The actual finite map derives the projective structure on the same
original $D$, and the integral-map dimension bound gives $\dim D\leq1$.
Dominance makes the actual original ideal comap Cartier. Original
projective geometry makes both original schemes compact and locally
Noetherian. The proper support of each original Cartier ideal has its
actual finite closed subscheme. Its original closed immersion has finite
range equal to that support. The native weighted order is zero outside
this same support, so its function on all original curve points has
finite support, internally derived.

For any actual map of point sets and any genuinely finite-support
integer function, its sum over each original fibre is the finite filter
sum over its same support. Summing those filters over all original
image points recovers the sum over all original source points. Apply
this identity to the actual original source Cartier weighted orders.
The proved whole original fibre projection changes every inner sum
into $N(g)$ times the original target Cartier weighted order. The
original intrinsic Cartier degree is minus the whole native weighted
order sum on each original curve. These exact identities give the
formula with the same canonical $N(g)$.
\end{proof}

\begin{theorem}[Every original invertible curve module has its full degree projected]
\label{thm:intrinsic-numerical-nonflat-whole-line-degree}
\uses{scheme:existing-ideal-module-affine-sections,def:fc-scheme-coherent-euler-characteristic,thm:intrinsic-numerical-nonflat-cartier-degree,def:fc-original-curve-line-degree,def:intrinsic-numerical-canonical-function-field-degree,thm:fc-original-projective-line-cartier-ratio,lem:actual-cartier-ratio-line-sheaf,lem:actual-ideal-module-pullback-map,cor:dominant-integral-cartier-canonical-module-pullback,lem:cartier-ratio-canonical-pullback,lem:cartier-actual-tensor-dual-functorial,lem:nonflat-dominant-cartier-comap,thm:fc-curve-cartier-weighted-degree,thm:fc-curve-cartier-ideal-degrees,lem:actual-integral-projection-dimension-bound,thm:fc-curve-finite-map-projective}
\lean{EnvelopeProperty.NumericalNonflatCurveDegrees.degree_pullback}
\leanok
For the same original $q,C,D,g$, and every actual original invertible
module $L$ on $C$,
\[
 \deg_{gq}(g^*L)=N(g)\deg_q L.
\]
The entire original line and genuine full Euler degrees are retained.
There is no flatness, normal-target, chosen Cartier ratio, finite support,
matching module, rank or desired degree identity hypothesis.
\end{theorem}
\begin{proof}
Original projectivity internally produces actual effective Cartier
ideals $I,J$ and a whole original isomorphism $L\simeq I^{\sim}\otimes
(J^{\sim})^\vee$. Actual dominance and integral source make the
canonical original module comparisons
$g^*I^{\sim}\to(I\mathcal O_D)^{\sim}$ and
$g^*J^{\sim}\to(J\mathcal O_D)^{\sim}$ isomorphisms. These are the
existing actual comparison maps; no module match is supplied.

The genuine whole tensor/dual pullback isomorphism identifies the
pullback of this same original Cartier ratio with the actual ratio of
these same geometric comap ideals. The original ratio degree is the
difference of the two original Cartier ideal degrees. Apply the
preceding nonflat whole Cartier degree projection to each factor and
factor out the same $N(g)$. Whole original module isomorphisms preserve
the actual normalized full Euler degree, giving the formula for $L$.
\end{proof}

Whole-real numerical curve-degree projection and proper-surjective nef
reflection/injectivity require their subsequent genuine consumers. No
numerical metric, norm, global FS, baseideal or vanishing statement is
asserted here.
