\section{Every original line section has its genuine normalized rational coefficient}
\label{sec:line-section-ratios}

The original scheme is integral, the original module $L$ is genuinely
invertible, and $d$ is an original nonzero global section. Both the
original generic frame and nonzero generic germ below are DERIVED
from that actual geometry; no rational coefficient data are assumed.

\begin{theorem}[Whole original generic frame normalized by the original section]
\label{sc0-line-section-ratios:whole-generic-frame}
\lean{EnvelopeProperty.CanonicalGeometry.genericNormalizedFrame,EnvelopeProperty.CanonicalGeometry.genericNormalizedFrame_generator,EnvelopeProperty.CanonicalGeometry.genericNormalizedFrame_apply_frame}
\leanok
There is a genuine linear equivalence from the SAME entire original
module generic stalk to the SAME original function field, sending the
actual generic germ of $d$ to one. In EVERY genuine original local frame
it is exactly the actual generic coordinate divided by the original
generic coordinate of $d$. No choice-of-frame compatibility or nonzero
generic-germ premise is supplied.
\end{theorem}
\begin{proof}
Native original invertibility supplies the genuine original line atlas.
The already proved injectivity of the actual global module germ sends
the original $d\ne0$ to a nonzero element of the SAME actual stalk.
Choose an actual atlas frame at the original generic point; the actual
whole generic frame theorem identifies the SAME original stalk with
its original function field. Normalize this genuine frame by the
actual generic germ of $d$, using the preceding genuine normalized-line
construction. Its generator is exactly one. Independence of EVERY
original initial frame gives the displayed formula in ANY genuine
local frame, without a supplied comparison equation.
\uses{sc0-native-line-atlas:actual-over-atlas,sc0-normalized-line-frame:normalization-independent,sc0-generic-line:original-stalk-line}
\end{proof}

\begin{theorem}[Faithful rational coefficients of EVERY original section]
\label{sc0-line-section-ratios:every-original-section}
\lean{EnvelopeProperty.CanonicalGeometry.sectionRatio,EnvelopeProperty.CanonicalGeometry.sectionRatio_injective,EnvelopeProperty.CanonicalGeometry.sectionRatio_frame_formula}
\leanok
On EVERY nonempty original open, the SAME actual module germ followed
by this normalized whole frame gives a genuine semilinear map of ALL
original sections into the original function field. It is injective.
In ANY genuine frame on that open, its exact value is the actual
coefficient germ of the section divided by the actual coefficient
germ of the SAME restricted original $d$.
\end{theorem}
\begin{proof}
Compose the SAME original semilinear generic germ with the genuine
normalized whole generic linear equivalence. If two original generic
germs agree, the actual native stalk equality theorem produces a
smaller original open containing the original generic point where
their restrictions agree. It is nonempty, so the atlas-derived genuine
restriction injectivity makes the original sections equal. Thus the
actual generic germ on EVERY nonempty open is injective, and so is
its composition with the whole normalized frame. The preceding
arbitrary-frame formula and proved genuine local/global germ-frame
coefficient identities give the exact displayed quotient for EVERY
original section. No selected section subspace replaces the whole module.
\uses{sc0-line-section-ratios:whole-generic-frame,sc0-generic-line:original-restriction,sc0-generic-line:whole-germ-coefficient}
\end{proof}

\begin{theorem}[Original restriction and the SAME original generator]
\label{sc0-line-section-ratios:original-restriction-generator}
\lean{EnvelopeProperty.CanonicalGeometry.sectionRatio_restrict,EnvelopeProperty.CanonicalGeometry.sectionRatio_generator}
\leanok
These entire original rational coefficients commute with EVERY original
restriction between nonempty opens. The SAME original global generator
$d$ restricts to coefficient one on EVERY such open.
\end{theorem}
\begin{proof}
Native original module germ-res naturality identifies the actual generic
germs of the original section and its exact restriction. Apply the SAME
normalized original frame to that whole equality. In particular, every
restriction of $d$ has its SAME original global generic germ, whose
normalized coefficient was proved to be exactly one.
\uses{sc0-line-section-ratios:whole-generic-frame,sc0-line-section-ratios:every-original-section}
\end{proof}

These are genuine original section-to-function-field coefficients,
not an arbitrary rank-one model. The actual BP differential section
still must be proved nonzero on its actual integral target, and its
pushed rounded section coefficients must be proved regular before
identifying the entire rounded canonical module pushforward.
