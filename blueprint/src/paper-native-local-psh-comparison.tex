\subsection{The unchanged affine classes at the trivial base valuation}
\begin{theorem}[Actual original affine function classes are the trivial-base specialization]
\label{paper:original-affine-local-psh-comparison}
\uses{scheme:finite-coefficient-local-psh,scheme:actual-affine-local-psh-comparison,spectrum:trivial-field-bridge}
\lean{EnvelopeProperty.isConvexPLOn_relativeSpectrum_iff,
EnvelopeProperty.isDecrConvexPLLimitOn_relativeSpectrum_iff,
EnvelopeProperty.isLocallyPSHOn_relativeSpectrum_iff}
\leanok
For any actual field $k$ and commutative $k$-algebra $A$, the genuine
$\operatorname{Berk}(k,A)\simeq\operatorname{RelativeSpectrum}_{1}(A)$
homeomorphism identifies the UNCHANGED old convex-PL, decreasing-limit and
local-psh classes with the independently defined finite-$A$ classes at the
trivial valuation. Composing with the actual native affine homeomorphism
identifies these unchanged old classes with the genuine regular-unit classes
on the SAME $\operatorname{Spec}A$ and exact trivial-$k$ native locus.
No domain, finite-type, Noetherian, completeness or geometric witness is required.
\end{theorem}
\begin{proof}
The actual old-to-relative homeomorphism and its inverse retain every original
$A$ evaluation. Pull each true open neighborhood back through the genuine
homeomorphism. Retain the SAME finite tuple of original coefficients and the
SAME nonempty finite rational family. Every nonvanishing condition and every
whole logarithmic maximum is then identical. The whole point inverse laws
prove the reverse direction, including all ambient and neighborhood conditions.
For actual decreasing sequences, compose every term with the real point map;
all pointwise inequalities and true infima remain equal. The real homeomorphism
preserves the actual local neighborhoods. Finally apply the proved intrinsic
native-to-finite-$A$ equivalences and these exact original specializations.
The result concerns the original unchanged function classes. It neither changes
the old weakly-psh definition nor asserts harmonicity, subharmonicity or the
converse from an arbitrary proper-birational witness.
\end{proof}
