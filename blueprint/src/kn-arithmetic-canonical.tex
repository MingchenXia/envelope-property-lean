\section{Relative canonical models and their actual arithmetic fibres}

The smooth affine arithmetic producer in PR~215 constructs a smooth algebra
$B$ over a finite-type smooth integer algebra $S$, and an actual algebra
isomorphism $k\otimes_S B\simeq A$ to the original characteristic-zero affine
algebra.  Its projective-family producer likewise retains the original scheme,
closed embedding, and projective twisting lines.  The missing comparison is
for relative differential and canonical sheaves on this arithmetic family.

\begin{lemma}[Actual affine pullback of an associated module sheaf]
\label{lem:kn-arithmetic-affine-tilde-pullback}
\lean{EnvelopeProperty.Vanishing.ArithmeticCanonicalAffine.tildePullbackIso}
\leanok
For a ring map $A\to C$ and an actual $A$-module $M$, pullback along
$\operatorname{Spec}C\to\operatorname{Spec}A$ identifies $\widetilde M$ with
$\widetilde{C\otimes_A M}$.
\end{lemma}
\begin{proof}
The actual affine pullback is quasicoherent.  The affine pullback global-section
comparison identifies its sections with extension of scalars of the sections
of $\widetilde M$.  The latter sections are the original $M$.  Apply the tilde
functor to this isomorphism and use the actual quasicoherent counit
$\widetilde{\Gamma(-)}\simeq(-)$ to recover the whole pulled-back sheaf.
\end{proof}

\begin{theorem}[The constructed global relative canonical line]
\label{thm:kn-arithmetic-global-canonical-atlas}
\lean{EnvelopeProperty.Vanishing.ArithmeticCanonicalGlobalFrames.chartFrame,EnvelopeProperty.Vanishing.ArithmeticCanonicalGlobalFrames.canonicalAtlas,EnvelopeProperty.Vanishing.ArithmeticCanonicalGlobalFrames.canonicalObject_isInvertible}
\leanok
\uses{thm:kn-arithmetic-fixed-base-standard-charts,lem:kn-arithmetic-global-exterior-restriction,lem:kn-arithmetic-global-affine-exterior}
For any commutative $R$ and any actual $n$-smooth $X\to\operatorname{Spec}R$,
the constructed global relative top exterior object has a derived genuine
line atlas and is a native invertible module on the whole original $X$.
\end{theorem}
\begin{proof}
Choose the actual fixed-$R$ standard-smooth affine neighbourhood produced at
each original point.  Its actual K\"ahler module has a derived rank-$n$ basis.
The coordinate exterior localization maps identify the constructed global
exterior sheaf on this chart with the tilde of its genuine exterior module.
The top wedge basis gives an actual rank-one affine frame.  Apply the proved
open-restriction comparison and the native equivalence between the affine
spectrum, the original open subscheme, and its open site to obtain the frame
on the original sheaf over that same open.  These actual opens cover every
original point.  Their derived frames therefore form a line atlas of the
already constructed whole sheaf, and the native line-atlas construction
derives invertibility.  Neither the global object nor its gluing is assumed.
\end{proof}

\begin{lemma}[Actual open restriction over an arbitrary arithmetic base]

For an actual open immersion $g:Y\to X$, the pullback of the constructed

\end{lemma}
\begin{proof}
The open immersion identifies actual coefficient rings on corresponding
opens.  The structural constant square commutes, so the inverse coefficient

shows that map is bijective.  Naturality follows from inverse-coefficient
naturality on every actual differential.  Sheafify the resulting presheaf
isomorphism and apply the actual open-restriction sheafification comparison.
Finally use the native restriction--pullback isomorphism.
\end{proof}

\begin{theorem}[Relative affine differentials on the actual arithmetic fibre]
\label{thm:kn-arithmetic-affine-cotangent-fibre}

\leanok

$\operatorname{Spec}B\to\operatorname{Spec}S$ over $\operatorname{Spec}\kappa$,
the pullback of $\widetilde{\Omega_{B/S}}$ is the actual field-relative
cotangent sheaf.  This applies in particular to residue fields of closed
points of the Noetherian arithmetic base.
\end{theorem}
\begin{proof}
The native tensor-product spectrum isomorphism identifies the actual fibre
with $\operatorname{Spec}C$, and its projection with the spectrum of the actual
inclusion $B\to C$.  Apply the affine pullback comparison.  The native K\"ahler
pushout isomorphism gives
$C\otimes_B\Omega_{B/S}\simeq\Omega_{C/\kappa}$; it sends every
$1\otimes db$ to the differential of the image of the same $b$.
Sheafifying this module isomorphism and using the existing actual affine
cotangent comparison gives the claimed whole-sheaf isomorphism.
\end{proof}

\end{proof}

\subsection{Global relative objects over the arithmetic base}

\begin{theorem}[The actual global relative cotangent and exterior sheaves]
\label{thm:kn-arithmetic-global-relative-objects}
\lean{EnvelopeProperty.Vanishing.ArithmeticCanonicalGlobal.relativeSheafHomEquiv,EnvelopeProperty.Vanishing.ArithmeticCanonicalGlobal.relativeExteriorSheaf,EnvelopeProperty.Vanishing.ArithmeticCanonicalGlobal.fieldCotangentIso,EnvelopeProperty.Vanishing.ArithmeticCanonicalGlobal.fieldExteriorIso}
\leanok
Let $f:X\to\operatorname{Spec}R$ for any commutative ring $R$.  The structural
map gives compatible constants $R\to\Gamma(X,U)$ on every actual open $U$.
The presheaf of relative K\"ahler modules, and its sheafification as an
$\mathcal O_X$-module, give the global relative cotangent sheaf.  Morphisms
from this sheaf to any actual module sheaf are precisely derivations
annihilating these structural constants.  Sheafifying the exterior powers
of the same cotangent presheaf gives its global all-degree exterior objects.
For a field base these are the already existing native objects.
\end{theorem}
\begin{proof}
The actual structural morphism and the global-section isomorphism of an
affine spectrum define the constant map, and restriction naturality follows
from functoriality of the actual structure presheaf.  The native relative
differentials construction supplies a universal derivation objectwise and
naturally.  Compose its hom--derivation equivalence with the sheafification
adjunction to obtain the displayed global universal property.  Exterior
powers use the same genuine restriction maps before sheafification.  Over a
field these formulas are definitionally the existing cotangent and exterior
sheaf definitions; no comparison datum is supplied.
\end{proof}

\begin{theorem}[Actual standard-smooth charts over the fixed arithmetic base]
\label{thm:kn-arithmetic-fixed-base-standard-charts}

relative dimension $n$.  Every original $x\in X$ has an actual affine
neighbourhood $V$ whose actual constant map $R\to\Gamma(X,V)$ is standard
smooth of relative dimension $n$.  Its spectrum morphism is exactly
$\operatorname{Spec}\Gamma(X,V)\to X\to\operatorname{Spec}R$.
\end{theorem}
\begin{proof}
Choose an original affine neighbourhood of $x$.  Composing its open immersion
with $f$ retains relative dimension $n$.  The native ring-hom characterization
of this geometric property implies that its actual coordinate map over the
fixed $R$ is source-locally standard smooth of dimension $n$.  Thus a set of
actual coordinate functions generates the unit ideal and standard smoothness
holds after localization at each function.  Their principal opens cover the
chosen affine neighbourhood; choose one containing the original $x$.
The genuine section ring on this principal open is canonically the same

and the native affine chart structure identity.  No target open is forced to

\begin{proof}

annihilates every original $R$-constant, and its restriction naturality follows

relative K\"ahler presheaf gives the actual raw differential map.  Compose
with the target sheafification unit, descend through the source
sheafification adjunction, and use the native sheaf pullback--pushforward
adjunction.  Its unit identity preserves the displayed raw differential map.
\end{proof}

The affine comparison below identifies this actual morphism with the native

\begin{theorem}[The whole arithmetic canonical model has its actual field fibres]
\label{thm:kn-arithmetic-global-canonical-fibre}
\lean{EnvelopeProperty.Vanishing.ArithmeticCanonicalGlobalComparison.canonicalPullback_isIso,EnvelopeProperty.Vanishing.ArithmeticCanonicalGlobalComparison.fieldCanonicalIso,EnvelopeProperty.Vanishing.ArithmeticCanonicalGlobalComparison.fieldCanonicalTensorIso}
\leanok
\uses{lem:kn-arithmetic-global-fibre-chart-cover}
Let $R$ be any commutative ring, let the original $X/R$ be smooth of relative
dimension $n$, and let $S$ be an actual $R$-algebra.  On the same native
categorical fibre $Y=X\times_R\operatorname{Spec}S$, with original first
projection $\pi$ and structural second projection $h$, the actual global
canonical differential is an isomorphism
\[
  \pi^*\omega_{X/R}\ \simeq\ \omega_{Y/S}.
\]
For a field $S=\kappa$, the target is the existing native canonical line of
this same whole fibre.  For every original model module $L$, the same
construction also proves
\[
  \pi^*(\omega_{X/R}\otimes L)
    \ \simeq\ \omega_{Y/\kappa}\otimes\pi^*L.
\]
No global model, gluing datum, field-fibre comparison, or vanishing statement
is a hypothesis.
\end{theorem}
\begin{proof}
On arbitrary genuine structural coefficient squares, construct the raw
relative K\"ahler map and its whole exterior maps from the original universal
derivations.  Spanning differentials and pure wedges prove composition of
the whole raw maps.  The actual sheafification and pullback adjunction units
give composition of the whole sheaf maps with the native pullback composition
isomorphism.  These constructed maps identify with the original global
base-change differential; along an open immersion their actual comparison is
invertible, including its original structural-map equality transport.

Apply this checked functoriality to the two actual paths from each derived
chart fibre to the original $X$.  The native first- and second-projection
equations retain both the original source map and the $S$-relative target.
The proved local fibre differential is invertible, and the actual open
comparisons and native pullback composition isomorphisms transport that
invertibility to the open pullback of the same original global map.
These actual fibre charts cover the whole native fibre by the preceding
lemma.  Native module-sheaf isomorphism detection on this open cover therefore
proves invertibility of the original whole map.

Over a field the constructed relative exterior object is definitionally the
existing native canonical object on that same fibre.  The genuine pullback
of the original tensor module commutes with the native sheafified tensor;
apply the canonical comparison to its first factor and retain the actual
pullback of the same original $L$ in the second factor.
\end{proof}
