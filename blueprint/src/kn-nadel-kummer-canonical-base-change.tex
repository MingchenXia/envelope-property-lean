\begin{lemma}[Multiplication and native counits under actual finite-free dual base change]
\label{lem:kn-nadel-finite-dual-base-change-diagram}
\lean{EnvelopeProperty.Vanishing.NadelKummerCanonicalBaseChange.algebraRestrictionEquiv,EnvelopeProperty.Vanishing.NadelKummerCanonicalBaseChange.nativeFunctionalEquiv,EnvelopeProperty.Vanishing.NadelKummerCanonicalBaseChange.nativeFunctionalEquiv_apply,EnvelopeProperty.Vanishing.NadelKummerCanonicalBaseChange.coefficientPairing,EnvelopeProperty.Vanishing.NadelKummerCanonicalBaseChange.dualBaseChangeEquiv,EnvelopeProperty.Vanishing.NadelKummerCanonicalBaseChange.dualBaseChangeEquiv_tmul,EnvelopeProperty.Vanishing.NadelKummerCanonicalBaseChange.coefficientPairing_baseChange,EnvelopeProperty.Vanishing.NadelKummerCanonicalBaseChange.baseChangedFrame,EnvelopeProperty.Vanishing.NadelKummerCanonicalBaseChange.baseChangedFrame_apply,EnvelopeProperty.Vanishing.NadelKummerCanonicalBaseChange.baseChangedFrame_counit_tmul}
\leanok
Let $A\to B$ be a finite free commutative algebra and $A\to S$ any
ring map.  Set $C=S\otimes_A B$.  The native finite-free dual
base-change equivalence satisfies
\[
 (s\otimes\phi)(t\otimes b)=st\,\phi(b)_S.
\]
For every original coefficient functional $\ell:B\to A$, it
identifies the base change of the original multiplication pairing
with multiplication against the actual extended functional
$\ell_C(s\otimes b)=s\ell(b)_S$ on $C$.  The native
$C$-linear coextension frame from $\ell_C$ has counit $\ell_C$.
\end{lemma}
\begin{proof}
Reuse the native finite-free dual base-change equivalence.  Its
evaluation on $1\otimes b$ is its existing defining evaluation
formula; linearity gives the displayed formula on $t\otimes b$.
For the multiplication diagram evaluate both sides on two pure
tensors, use $(s\otimes b)(t\otimes c)=st\otimes bc$, and the
displayed dual formula.  The two resulting scalars agree in $S$.
Tensor generation proves equality of the whole maps.  The native
restriction/coextension adjunction applied to the actual $\ell_C$
gives the $C$-linear frame, whose value at $y$ is $\ell_C(yx)$.
Its native counit evaluates at one, so it is exactly $\ell_C$.
If the original multiplication pairing is perfect, base change
of its actual linear equivalence and the native dual base-change
equivalence show that the new pairing is perfect as well.  The
result makes no flatness assumption on $S$.
\end{proof}

the original unit gives the claimed counit, and evaluation on pure

\begin{theorem}[The whole actual top-frame counit square]
\label{thm:kn-nadel-etale-top-frame-counit-square}
\lean{EnvelopeProperty.Vanishing.NadelKummerCanonicalBaseChange.baseTopFrameMap,EnvelopeProperty.Vanishing.NadelKummerCanonicalBaseChange.targetTopFrameMap,EnvelopeProperty.Vanishing.NadelKummerCanonicalBaseChange.baseTopFrameMap_generator,EnvelopeProperty.Vanishing.NadelKummerCanonicalBaseChange.targetTopFrameMap_generator,EnvelopeProperty.Vanishing.NadelKummerCanonicalBaseChange.etaleCanonicalCounit_frame_naturality}

For the same original formally etale map, construct the semilinear
maps from the two old polynomial top modules by carrying their
original ordered wedges to the actual wedges of the images of their
native K\"ahler differentials.  The coefficient maps are the same
original $a:A\to S$ and $B\to C$.  If these maps are denoted by
$u_A$ and $u_B$, the whole actual counit diagram commutes:
\[
 \operatorname{counit}_C(u_B(w))
   =u_A(\operatorname{counit}_B(w))
 \qquad\text{for every original }w\in\omega_{B/R}.
\]
\end{theorem}
\begin{proof}
The actual coefficient square also agrees on the original small
ring $R$, since the original power map fixes all its coefficients.
The native formally etale differential bases have already been
proved termwise to be the actual differentials of the images of
the original coordinates.  Their ordered exterior generators are
therefore the stated actual top wedges.  Define each semilinear
map using its original coefficient homomorphism on the unique
coefficient of the old original top wedge.  Additivity and
semilinearity follow from the original ring homomorphism laws.

Write the arbitrary old top form as $w=g\,dt$.  The already proved
new counit coefficient on its right image is
$a(\Lambda_B(g))\,dx_S$.  The original counit gives
$\Lambda_B(g)\,dx$, whose actual base frame map has exactly that
same value.  This proves the whole map equality for all $w$;
no naturality diagram is assumed as input.  These are maps on
the same fixed coordinate chart.  Arbitrary changes to different
coordinate systems and intrinsic global gluing are not inferred
from this fixed-frame square alone.
\uses{thm:kn-nadel-etale-top-frame-base-change,cor:kn-nadel-kummer-canonical-counit}
\end{proof}
