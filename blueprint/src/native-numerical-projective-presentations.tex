numerical quotient of an integral native-projective $X$, there
is an internally constructed actual closed immersion of that
same original $X$ into a finite product of original polynomial

common actual denominator factor for every given class. No
projective-presentation, numerical-class, or whole line comparison
certificate is supplied.
\end{theorem}

\begin{proof}
Use the genuine simultaneous original numerical-line-family
producer to obtain original invertible lines $L_i$, one original
invertible $T$, finite global generators of $T$ and of every
$L_i\otimes T$, and every given class's exact original real
expression in the differences $[L_i\otimes T]-[T]$.
Put $T$ followed by all these actual numerators into one finite
family with these actual finite global generators. Apply the
proved actual generated-line-family projective embedding theorem.
It constructs one extra original projective closed-embedding
factor and the original factor for every line in the family,
with the whole original structure triangle and the entire
original pullback $\mathcal O(1)$ isomorphism for each line.

The common denominator is the first generated-line factor; the
original numerator $L_i\otimes T$ is the corresponding subsequent
factor. The genuine numerical invariance under whole original
line isomorphisms identifies their actual factor pullback classes
with these exact original denominator and numerator classes.
Substitute these true identities term by term into the already
proved original numerical-class expressions. The result retains
every original class, the same original $X$, the same entire
closed embedding and one common denominator factor. Invertibility
of every actual factor pullback is derived from the original
$\mathcal O(1)$ invertibility and actual whole pullback. This is
an actual native multiprojective geometric presentation; the
additional homogeneous-coordinate/function-field comparison to
the old algebraic \texttt{MultiModel} carrier, ample topology and
model psh numerical invariance remain separate obligations.
\end{proof}
