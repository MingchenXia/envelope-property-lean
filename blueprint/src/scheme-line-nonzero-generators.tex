\section{Genuine nonzero original line sections from projective generation}

\begin{theorem}[A true generating family contains an actual nonzero section]
\label{thm:fc-original-line-nonzero-generator}
\leanok
\lean{EnvelopeProperty.SchemeLineNonzeroGenerators.id_ne_zero, EnvelopeProperty.SchemeLineNonzeroGenerators.exists_generatorHom_ne_zero, EnvelopeProperty.SchemeLineNonzeroGenerators.exists_section_ne_zero}
\uses{thm:fc-original-line-image-frames}
An actual invertible module on a nonempty original scheme has nonzero
identity. Every actual global generating family of that same original
line contains a genuine nonzero original section morphism
$\mathcal O_X\to L$. No finite-family or supplied nonzero-section premise
is needed.
\end{theorem}
\begin{proof}
Choose an original point and an actual original affine line frame near
it. If the whole line identity were zero, its actual restriction and
conjugation by that frame would make the identity on the original local
structure module zero. Evaluation at the original section $1$ would give
$1=0$ in the original nonempty-open section ring, a contradiction.

If every original generator section were zero, the actual coproduct
universal property would make the original free evaluation map zero.
It is genuinely epic, so cancellation would make the original line
identity zero, contradicting the preceding result. A nonzero original
generator is the required whole section morphism.
\end{proof}

\begin{theorem}[True nonzero sections of original projective twists]
\label{thm:fc-original-line-eventual-nonzero-sections}
\leanok
\lean{EnvelopeProperty.SchemeLineNonzeroGenerators.exists_pullback_twist_section_ne_zero, EnvelopeProperty.SchemeLineNonzeroGenerators.exists_eventual_twist_section_ne_zero}
\uses{thm:fc-original-line-nonzero-generator}
For any actual map to original polynomial projective space, every original
nonnegative pulled-back coordinate twist has an actual nonzero section
on a nonempty original scheme. For any actual closed immersion into
that projective space and any SAME original invertible line $L$, every
sufficiently large original twist of $L$ has a genuine nonzero global
section. No chosen nonzero section or global-generation certificate is
supplied.
\end{theorem}
\begin{proof}
The original nonnegative coordinate powers genuinely generate the actual
original projective twist. Their actual pullback generates the SAME
pulled-back original line, and the preceding theorem gives a nonzero
original section.

An actual invertible line is genuinely quasicoherent and finitely
presented, hence finite type. True eventual projective generation
therefore supplies an actual generating family for each sufficiently
large SAME original twist. These twists are actually invertible, by
native pullback invertibility and the genuine original tensor comparison.
Apply the preceding nonzero-generator theorem to their actual generating
families. The degree bound is produced by true projective generation;
no numerical, divisor, local-frame or nonzero-section certificate is used.
\end{proof}
