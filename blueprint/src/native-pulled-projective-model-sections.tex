\section{Every original pulled-line global section is a whole model section, and conversely}
\label{sec:native-pulled-projective-model-sections}

\begin{theorem}[Whole original global sections and whole model section space]
\label{thm:native-pulled-projective-model-sections}
\lean{EnvelopeProperty.NativePulledProjectiveModelSections.coefficient, EnvelopeProperty.NativePulledProjectiveModelSections.coefficient_eq_sectionRatio, EnvelopeProperty.NativePulledProjectiveModelSections.coefficient_chart_fraction, EnvelopeProperty.NativePulledProjectiveModelSections.coefficient_mem_sections, EnvelopeProperty.NativePulledProjectiveModelSections.coefficient_injective, EnvelopeProperty.NativePulledProjectiveModelSections.coefficient_surjective}
\leanok
\uses{thm:native-pulled-projective-line-frames,thm:native-pulled-projective-line-pivot,thm:model-sections-iff-chart-fractions,sc0-native-line-ratio:whole-frame,sc0-line-section-ratios:original-restriction-generator,thm:projective-fixed-native-model-charts}
\source{bj22-trivval:sec:tc}
Assume throughout this statement that the original scheme $X$ is integral.
Fix an original actual closed projective embedding, an original nonempty
pivot chart, and an original nonnegative degree $d$. Every actual original
global section of the whole original pulled $O(d)$ line has a literal native
function-field coefficient, normalized by its actual original pivot-power
section. This coefficient belongs to the whole genuine degree-$d$ section
space of the same fixed model. This is a bijection of the whole original
global section set with the whole model section set, with every actual
original chart coefficient retained exactly. No ambient homogeneous-form
representation, local realization, or section-comparison certificate is
assumed.
\end{theorem}
\begin{proof}
Take the actual generic germ of the original global section's coefficient
in its actual original pivot frame. The actual original pivot-power global
section is nonzero and has native generic coefficient one. The canonical
native section-ratio construction therefore identifies the chosen coefficient
with the genuine ratio to this same whole original normalizing section.
In every other original nonempty chart, the true original normalizer has
coefficient $(X_i/X_j)^d$. Its native generic value is the inverse of the
original generic chart denominator. The canonical native frame formula
therefore shows that the normalized coefficient divided by the original
model chart denominator is exactly the actual generic germ of the whole
original regular chart coefficient. The entire original section-algebra
equivalence places that fraction in the genuine model chart algebra.
The whole model chart-fraction criterion now proves genuine model section
membership. Faithfulness of the canonical original section ratio proves
injectivity on the entire original global section space.

Conversely, take any actual model section. Its chart fractions belong to the
whole actual model chart algebras. Their inverse original section-algebra
equivalences produce actual original regular coefficients on every nonempty
original chart. Apply the inverses of the original whole line frames to
obtain actual local line sections. The same canonical native frame formula
says that each local section has the given original normalized function-field
coefficient. Restriction retains that coefficient. On every original overlap,
faithfulness of the actual native section ratio therefore identifies the
actual restricted line sections. Genuine original sheaf gluing produces a
whole original global section, whose normalized coefficient is the prescribed
model section. The nonempty original charts cover the same whole original
scheme; empty charts contribute no extra assumption.
\end{proof}
