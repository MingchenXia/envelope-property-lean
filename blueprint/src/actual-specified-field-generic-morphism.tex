\subsection{The actual relative normalization in the specified finite field extension}

\begin{lemma}[The actual specified-field generic morphism and original coefficients]
\label{lem:actual-specified-field-generic-morphism}
\lean{EnvelopeProperty.SpecifiedFieldSchemeNormalization.genericSectionIso_coefficients}
\leanok
Let $X$ be the original integral scheme and $L$ the actual specified
extension of its original canonical function field. The actual map
$\operatorname{Spec}L\to\operatorname{Spec}K(X)\to X$ is
quasi-compact and quasi-separated. Its inverse image of every actual
nonempty open is the whole original field spectrum. The actual section
ring on that preimage is the SAME original $L$, and its coefficient
map is exactly the original generic-germ map followed by the originally
specified field embedding.
\end{lemma}
\begin{proof}
The original field spectrum has a single point, and that point maps
to the SAME original generic point of $X$. Every original nonempty
open contains this point. The single-point inverse images give actual
quasi-compactness. The original field spectrum map is affine and the
original generic-stalk map is separated, giving quasi-separatedness
of their composite. Actual restriction to the whole preimage and the
canonical affine-spectrum global-section isomorphism identify its
section ring with $L$. Functoriality of the SAME original scheme
section maps, the actual generic-stalk coefficient identity, and
affine-spectrum naturality give the literal coefficient composite.
\end{proof}
