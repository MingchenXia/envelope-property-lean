\begin{theorem}[True all-point intrinsic convexity in the original prescribed class]
\label{local:actual-prescribed-class-intrinsic-convex-normal-model}
\lean{EnvelopeProperty.ProjSubvariety.IsLocallyConvexAll.exists_prescribedClass_intrinsicConvex_normalizedRatioMetric}
\leanok
\uses{local:actual-normalized-model-admissible-nonvanishing,projective:actual-original-native-prescribed-convexity-pullback,local:actual-prescribed-class-whole-normal-metric}
Let the original variety be projectively normal over any field, let
$a>0$ be the original rational class, and let the original real function

condition. There exist positive integers $r,d$ with the EXACT original

and every coordinate choice defining the actual $\mathcal O(d)$ line, the
TRUE negative-log model norm of the actual homogeneous section tensored
with the actual canonical ratio section is intrinsically convex PL in
actual original scheme regular units on the whole actual model form locus.
No nefness, numerical positivity, or residual-curve slope premise is assumed.
\end{theorem}
\begin{proof}
The established original prescribed-class construction produces the actual
$r,d,C,I,J$, the identity $d=ra$, and the genuine all-point ratio-weight
formula, with all required original ideal logarithms finite. These are
constructed from the original local convexity, rather than supplied as
comparison data.

For each original admissible $F$, the genuine original-native convexity
pullback theorem applies to the literal actual normalized-model projection.
Its pulled function is exactly
$\varphi(w)-r^{-1}\log|F(w)|$, where $w$ is the derived original restriction,
because the whole projected native point equals that original point. This
holds on the entire actual model form locus. Multiply the genuine convex
presentation by the nonnegative rational $r$ and translate it by the rational
constant $-C$. The intrinsic convex PL algebra acts on the actual rational
unit-expression vectors and preserves their actual finite maximum.

On this locus, the preceding nonvanishing lemma gives $|F(w)|\ne0$.
The all-point ratio-weight formula identifies the actual ratio-section weight
with $r\varphi(w)-C$. The genuine tensor-section norm formula identifies
the actual polarized section weight with this ratio weight minus the
original $\log|F(w)|$. Consequently the translated and scaled actual convex
function is exactly the TRUE model section weight. Equality of functions on
the original domain preserves the actual regular-unit presentations. The
argument uses every actual model point, without imposing a Gauss-lift condition,
and retains the original class $d=ra$ throughout.
\end{proof}
