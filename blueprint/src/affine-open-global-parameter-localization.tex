\section{Actual affine module restriction localizes at the same global base parameter}
\label{sec:affine-open-global-parameter-localization}

\begin{theorem}[The original affine-open restriction is localization at the original parameter]
\label{sc0-affine-global-parameter:actual-restriction-localization}
\lean{EnvelopeProperty.AffineOpenGlobalParameterLocalization.restriction_isLocalizedModule}
\leanok
For ANY original scheme map $\pi:X\to B$, original quasicoherent
module $M$, actual affine open $U\subset X$, and actual original
global function $r\in\Gamma(B,\mathcal O_B)$, the SAME entire
restriction
\[
 \Gamma(U,M)\longrightarrow\Gamma(U\cap\pi^{-1}D(r),M)
\]
is localization at powers of the SAME $r$ as a module over the
original $\Gamma(B,\mathcal O_B)$. Both actions and the map are
precisely the pre-existing original base-module presheaf ones.
No affineness of $X$ or $B$, pushforward quasi-coherence, localized
target module, scalar-tower or localization certificate is supplied.
Empty basic opens and the zero parameter are included.
\end{theorem}
\begin{proof}
Use the actual coefficient homomorphism from the original global
base ring to $\Gamma(U,\mathcal O_X)$: pull back by the SAME
$\pi$ and then genuinely restrict to the SAME $U$. Its action
on the original $U$-sections is exactly the native base-presheaf
action, giving the first scalar tower. On the actual basic-open
target, genuine original presheaf composition identifies the two
coefficient restrictions, giving the second scalar tower.

The native affine quasicoherent localization theorem applies to
the SAME original restricted parameter and the SAME module
restriction, over $\Gamma(U,\mathcal O_X)$. Genuine restriction
of scalars for powers therefore makes this entire map localization
at the SAME original global $r$, retaining both actual native
base-presheaf module structures. Finally original restriction
and inverse-image basic-open identities prove that this actual
basic open is exactly $U\cap\pi^{-1}D(r)$. Transport along this
proved equality gives the asserted original restriction, without
an input matching equation or chosen localized-module proxy.
\end{proof}

This is the affine geometric input to the separate finite-cover
Cech proof of whole quasi-compact quasi-separated global section
localization. It does not assert that the whole global theorem
or a proper pushforward comparison has already been assembled.
