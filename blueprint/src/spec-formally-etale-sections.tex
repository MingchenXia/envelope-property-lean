\begin{theorem}[The original whole section-ring map remains formally etale]
\label{sc0-spec-formally-etale:original-section-map}
\lean{EnvelopeProperty.spec_appTop_formallyEtale}
\leanok
For ANY original formally etale commutative ring homomorphism,
the whole original global-section map of its SAME native spectrum
morphism is formally etale. No field, nonzero, finite-presentation,
coefficient-square or replacement-ring comparison premise is supplied.
\end{theorem}
\begin{proof}
The genuine native global-sections-of-spectrum isomorphisms are
actual bijective ring maps; their native etaleness derives formal
etaleness. The actual native spectrum/global-sections naturality
square identifies the ENTIRE original section-ring homomorphism
with the composite of the first original ring isomorphism, the
SAME given original ring map, and the inverse original target ring
isomorphism. This identity is derived on every original coefficient
using the actual source isomorphism's surjectivity and genuine
inverse identities. True formal etaleness is stable under actual
ring-map composition, proving the assertion for the SAME whole
native section homomorphism.
\end{proof}

This transports genuine localization formal etaleness to the exact
section algebras used by the original canonical sheaf differential,
without assuming its desired native coefficient square.
