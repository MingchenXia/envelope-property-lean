\section{The original whole unit-cover comparison on native sections}

\begin{lemma}[The same comparison evaluates its actual unit]
\label{lem:kn-unit-original-native-value}
\lean{EnvelopeProperty.Vanishing.NadelGlobalCanonicalTrace.unitBaseOriginalNativeValue}
\leanok
For every original base canonical section $w$, the native adjunction unit
followed by the defining native-section and field-transport composite of
the same original unit-cover comparison equals its actual native canonical
pullback followed by that same original field transport.
\end{lemma}
\begin{proof}
The original unit cover is etale. Apply the existing native canonical
base-change tensor formula to $1\otimes w$ and postcompose with the
original field-transport map. Read these arguments from the original
unit-cover comparison itself, so its coefficient and module instances
are retained literally. This is a native value identity; it does not
assert mixed counit normalization or global canonical trace.
\end{proof}
