\subsection{Actual valued generic points retain all original scheme sections}

\begin{lemma}[Actual specified-field native valued generic point]
\label{lem:actual-specified-field-native-valued-generic-point}
\lean{EnvelopeProperty.Berkovich.SpecifiedFieldGenericValuedPoints.point_eval}
\leanok
Let $X$ be the SAME actual integral scheme and let the original field
$L$ carry the original embedding of its actual canonical function field.
Every actual nonnegative real-valued valuation on the SAME $L$ constructs
a native valued point of the SAME whole $X$, by the actual generic
morphism $\operatorname{Spec}L\to X$. Its underlying original point is
the generic point. For EVERY original section $s$ on EVERY nonempty
original open $U$, its actual native evaluation is exactly the original
valuation of the image in $L$ of the SAME original generic germ of $s$.
The construction is continuous from the actual original spectrum of $L$
to the native whole valued-point space of $X$.
\end{lemma}
\begin{proof}
Use the actual spectrum-to-native-valued-point homeomorphism for the
SAME original $L$, then the actual native valued-point functor applied
to the original specified-field generic morphism. Its underlying point
is the original generic point. The genuine original generic morphism's
inverse image of every nonempty original $U$ is the whole original
spectrum of $L$. Evaluate the original pulled-back section there,
using actual section restriction to the whole spectrum and its native
whole-section isomorphism with $L$. The actual whole coefficient square
of the original generic morphism identifies this section value with
the image of the SAME original generic germ. Native section evaluation
naturality proves the asserted equality without replacing any section
or valuation. Continuity follows from the actual native affine
homeomorphism and continuity of the genuine valued-point functor.
\end{proof}
