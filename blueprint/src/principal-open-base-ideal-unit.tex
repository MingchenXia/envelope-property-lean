\section{The whole original base ideal is unit on a generated principal open}

\begin{proposition}[The actual original base ideal on the original principal open]
\label{prop:principal-open-base-ideal-unit}
\leanok
\lean{EnvelopeProperty.PrincipalOpenBaseIdealUnit.baseIdeal_comap_eq_top}
Let $X$ be quasicompact and separated, $\pi:X\to B$ any morphism,
$r\in\Gamma(B,\mathcal O_B)$ and $L$ an actual invertible module.
If the actual restriction of $L$ to $P=\pi^{-1}D(r)$ is globally
generated, then the geometric restriction to $P$ of the ENTIRE
original base ideal generated by ALL original global sections
on $X$ is the unit ideal.
\uses{lem:all-section-dual-evaluation,prop:all-section-dual-evaluation-principal-epi,lem:ideal-module-restriction-unit}
\end{proposition}
\begin{proof}
Use the original all-section dual evaluation, whose entire
actual image ideal is the original base ideal. Its actual
whole source is quasicoherent and its restriction to $P$ is
epi by the actual principal-open evaluation theorem. The
original whole image factorization, mapped by native restriction,
then forces the SAME restricted image-ideal inclusion to be epi.
Native open restriction preserves limits, so it retains the
actual inclusion's monomorphism. In the original abelian module
category the restricted inclusion is therefore an isomorphism.
The preceding geometric ideal-restriction lemma shows that this
SAME whole image ideal restricts to the unit ideal. Transport
along its proved equality with the original base ideal gives
the assertion. No chosen finite family, matching certificate,
ideal comparison or verticality premise is supplied. Eventual
verticality for a test configuration still requires internally
deriving the generation hypothesis from its original ample line.
\end{proof}
