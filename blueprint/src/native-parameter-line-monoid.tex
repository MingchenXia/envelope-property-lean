\section{The genuine standard action on the original parameter line}
\label{sec:native-parameter-line-monoid}

\begin{theorem}[The same affine line, unit group and standard action {\cite[\S1.2]{BJ22}}]
\label{thm:native-parameter-line-monoid}
\lean{EnvelopeProperty.ProjBerk.nativeParameterLine, EnvelopeProperty.ProjBerk.nativeParameterLineMonoidIso, EnvelopeProperty.ProjBerk.nativeParameterLineMonObj, EnvelopeProperty.ProjBerk.nativeParameterExponentMap, EnvelopeProperty.ProjBerk.nativeParameterGroupToMonoid, EnvelopeProperty.ProjBerk.nativeParameterGroupToMonoid_isMonHom, EnvelopeProperty.ProjBerk.nativeParameterGroupInclusion, EnvelopeProperty.ProjBerk.nativeParameterGroupInclusion_isMonHom, EnvelopeProperty.ProjBerk.nativeParameterGroupInclusion_left, EnvelopeProperty.ProjBerk.nativeParameterGroupInclusion_isOpenImmersion, EnvelopeProperty.ProjBerk.nativeParameterGroupInclusion_opensRange, EnvelopeProperty.ProjBerk.nativeParameterLine_one, EnvelopeProperty.ProjBerk.nativeParameterLineModObj, EnvelopeProperty.ProjBerk.nativeParameterGroupInclusion_isModHom}
\leanok
For every original commutative ring $R$, the \emph{same}
ordinary polynomial spectrum $\mathbf A^1_R=\operatorname{Spec}R[t]$
has an internally derived genuine multiplicative monoid
structure. Its unit is literally the original parameter-one
spectrum map. The actual Laurent multiplicative group has
an internally derived genuine monoid inclusion into this
same line, whose whole underlying map is precisely
$\operatorname{Spec}(R[t]\to R[t,t^{-1}])$, and whose entire
image is exactly the original open $D(t)$.
Restriction of the genuine line multiplication along this
inclusion gives the actual standard multiplicative-group
action on the same line. The whole unit-open inclusion is
equivariant for this action and the regular group action.
No monoid law, action or unit-open comparison certificate is supplied.
\end{theorem}

\begin{proof}
The actual natural-exponent monoid algebra $R[\mathbb N]$
is canonically the original $R[t]$, with the entire original
coefficient map. Its standard bialgebra has
$\Delta(t^n)=t^n\otimes t^n$ and $\epsilon(t^n)=1$.
The genuine affine bialgebra--monoid functor therefore supplies
a monoid on its spectrum. Transport across this actual
polynomial algebra isomorphism gives a monoid on precisely
the original $\mathbf A^1_R$.

The original exponent inclusion $\mathbb N\to\mathbb Z$
gives a genuine bialgebra homomorphism
$R[\mathbb N]\to R[\mathbb Z]$.
The same affine bialgebra functor gives a monoid morphism
from the actual Laurent group to this natural-exponent
spectrum, and hence to the same polynomial line.
Its whole coefficient map is the original $t\mapsto T$ map
into Laurent polynomials. This is the original localization
by $t$, so its spectrum map is an open immersion with whole
image exactly $D(t)$.
The group unit is actual Laurent evaluation at one, and the
inclusion preserves units. Composing that Laurent evaluation
with the entire original polynomial-to-Laurent map is
literally polynomial evaluation at one, on every coefficient
and the original variable. Thus the derived line unit is
exactly the original parameter-one map.

Use the genuine regular monoid action on this same line and
restrict scalars along the actual group inclusion. The genuine
monoid action laws give the group action laws on the entire
original line. As $\Delta(t)=t\otimes t$, this action is
multiplication of the parameter by the original Laurent unit,
which is the standard action. Finally the full multiplication
preservation equation for the actual monoid inclusion is
precisely its equivariance equation for the regular group
action and this restricted action. This proves all whole
original scheme and action comparisons.
\end{proof}
