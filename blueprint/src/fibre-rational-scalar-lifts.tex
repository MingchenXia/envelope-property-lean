The actual canonical completed stalk residue-field scheme point derives

\begin{proof}

of the actual canonical completed-field point recovers the whole
original native point, which already prescribes every base norm.
Native functoriality and the actual affine base-point homeomorphism
therefore prove the entire coefficient norm identity.
\end{proof}

\begin{lemma}[An actual rational section lifting every whole native point]

embedding maps its norm point to the norm point of the completed
residue field. The latter's actual canonical scheme point recovers
exactly the original whole native point.
\end{proof}
