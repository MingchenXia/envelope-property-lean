\section{Finite normalization of the same original coefficient slice and its whole original trait}
\begin{definition}\label{def:scheme-coefficient-slice-normalization}
Normalize the actual original coefficient slice inside its own unchanged native function field. Retain the whole projection to the original model and the original polynomial coefficient structure. The same actual original DVR trait lifts to this actual normalization, and its whole original model and parameter squares are unchanged.
\uses{thm:scheme-dvr-native-normalization-lift}
\lean{EnvelopeProperty.SchemeCoefficientSliceNormalization.model,EnvelopeProperty.SchemeCoefficientSliceNormalization.projection,EnvelopeProperty.SchemeCoefficientSliceNormalization.structureMap,EnvelopeProperty.SchemeCoefficientSliceNormalization.centerLift,EnvelopeProperty.SchemeCoefficientSliceNormalization.centerLift_projection,EnvelopeProperty.SchemeCoefficientSliceNormalization.centerLift_structure}\leanok
\end{definition}
\begin{proof}
The literal original fraction-field point has schematically dense image in the actual original coefficient slice and factors through the same whole original DVR trait. Hence that actual trait map is dominant. Its original DVR stalks are normal, so the preceding genuine normalization lift constructs its whole actual trait map into the same native normalization. Compose its exact whole original normalization projection with the existing original slice model and parameter squares.
\end{proof}
\begin{theorem}\label{thm:scheme-coefficient-slice-normalization-finite}
The resulting actual model is integral with every original stalk integrally closed. If the original parameter model is proper, the normalization projection to the same original coefficient slice is finite, and the resulting original polynomial structure is proper.
\uses{def:scheme-coefficient-slice-normalization}
\lean{EnvelopeProperty.SchemeCoefficientSliceNormalization.model_isIntegral,EnvelopeProperty.SchemeCoefficientSliceNormalization.stalk_isIntegrallyClosed,EnvelopeProperty.SchemeCoefficientSliceNormalization.normalizationProjection_isFinite,EnvelopeProperty.SchemeCoefficientSliceNormalization.structure_isProper}\leanok
\end{theorem}
\begin{proof}
Actual native normalization supplies the original integral scheme and integrally closed local stalks. The actual original slice is proper and hence locally of finite type over the same original polynomial base. Composing with the polynomial coefficient structure gives local finite type over the actual original coefficient field. Finiteness of normalization over an original field therefore applies to this same actual model. Finite maps are proper; compose with the same original proper parameter structure. This proof normalizes the original field model before completion and does not assume finite normalization over an arbitrary complete base.
\end{proof}
