\begin{proposition}[The whole source line isomorphism in every actual power]
\label{prop:native-test-configuration-line-powers}
\leanok
\lean{EnvelopeProperty.NativeTestConfiguration.TestConfiguration.unitOpenLinePowerIso,EnvelopeProperty.NativeTestConfiguration.TestConfiguration.unitOpenRestrictLinePowerIso}

the original total-space module and $L$ the original module on
$X$, with only the original action-linearization isomorphism
leg and original fibre-one identification. For every $n\geq0$,
the actual whole restriction of $M^{\otimes n}$ to the original
noncentral open is isomorphic to the pullback there of the
SAME original $L^{\otimes n}$.
\uses{lem:bundle-tensor-power-isomorphism,lem:bundle-tensor-power-pullback,thm:native-test-configuration-line-trivialization}
\end{proposition}
\begin{proof}

the whole original open line isomorphism. Apply the actual
tensor-power isomorphism to it. On both sides use the genuine
whole native pullback comparison for the SAME actual powers.
Compose with the actual native restriction--pullback comparison
along the original open inclusion. This constructs the entire
isomorphism without supplying any power linearization, generic
line, or chosen restriction comparison. The construction works
for arbitrary original modules and includes the zeroth power.
\end{proof}
