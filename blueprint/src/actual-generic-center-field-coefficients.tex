\subsection{Actual proper model centers retain the original generic field coefficients}

\begin{lemma}[The same original generic-point residue field]
\label{lem:actual-generic-residue-field-equivalence}
\lean{EnvelopeProperty.Berkovich.SchemeValuedPoint.genericResidueEquiv_germ}
\leanok
For an original integral scheme, the SAME native function field is genuinely
isomorphic to the original residue field at its generic point. Transport to
any actual point equal to that SAME generic point retains EVERY original
section's generic germ and its original residue evaluation.
\end{lemma}
\begin{proof}
The original generic stalk is the actual native function field and is a
field. Its original residue map is injective as a field homomorphism and
surjective as the actual native residue quotient. This SAME map is the
required field equivalence. Native section evaluation is precisely its
composite with the original generic germ, giving the entire section formula.
\end{proof}

\begin{lemma}[The whole actual proper-center stalk coefficient square]
\label{lem:actual-generic-center-stalk-coefficients}
\uses{lem:actual-generic-residue-field-equivalence}
\lean{EnvelopeProperty.Berkovich.RelativeSchemeValuedPoint.genericCenter_stalk_coefficients}
\leanok
Let an actual proper integral model over an arbitrary bounded prescribed base
have a genuine native point with its SAME original generic support. The
actual proper-center stalk map into its original residue valuation ring,
followed by the original field inclusion, equals the ENTIRE original stalk
map into the native function field followed by the above genuine residue
field equivalence. No coefficient or center-preservation certificate is given.
Consequently the original native support residue field is the SAME actual
fraction field of the original center stalk under this actual coefficient map.
\end{lemma}
\begin{proof}
Every original center-stalk element is the actual germ of a whole original
section on a genuine center neighborhood. The true proper-center section map
followed by its original valuation-ring inclusion equals that section's
original residue evaluation. Native germ-to-function-field naturality and
the genuine generic-residue field equivalence give exactly the same value.
This proves the square on EVERY original stalk element. The original
center stalk already has the native function field as its true fraction
field; transport by the genuine field equivalence proves the final assertion.
\end{proof}

\begin{lemma}[Unique positive scale of every original valuation with a genuine DVR center]
\label{lem:actual-generic-center-unique-dvr-scale}
\uses{lem:actual-generic-center-stalk-coefficients,lem:actual-local-dvr-real-scale-unique}
\lean{EnvelopeProperty.Berkovich.RelativeSchemeValuedPoint.existsUnique_curveCenter_realScale}
\leanok
If that SAME original center stalk is a DVR, the actual WHOLE native residue
valuation is the genuine real scaling of its original maximal-ideal valuation
at one unique positive parameter. On an actual normal locally Noetherian
integral curve of dimension at most one, a nongeneric original center derives
this DVR hypothesis internally.
\end{lemma}
\begin{proof}
The actual original center-stalk map is local by the genuine proper-model
construction. The entire coefficient square just proved identifies its
original field inclusion with the actual fraction-field map. The true local
DVR classification therefore gives the WHOLE original native residue
valuation and its unique positive scale. For the final curve assertion,
actual normality and the original nongeneric center's true codimension one
derive the original local DVR, so no new valuation or DVR premise is supplied.
\end{proof}
