\subsection{True model norms of arbitrary original generic-fibre sections under pullback}

\begin{theorem}[Every actual original generic-section morphism retains its model norm]
\label{berkovich:actual-generic-section-hom-model-norm-pullback}
\lean{EnvelopeProperty.Berkovich.RelativeSchemeValuedPoint.modelLineNorm_pullbackResidueSectionHom_eq_overBase}
\leanok
\uses{berkovich:actual-generic-local-frame-residue-pullback,berkovich:actual-residue-section-hom-pullback}
For actual proper models over compatibly valued coefficient rings with bounded
coefficients, and ANY actual scheme map preserving the whole coefficient-base
square, the TRUE model norm of every original target residue-fibre section
morphism equals the TRUE model norm of its actual original residue-field
pullback on the source. The original section need not extend to any global
section of the target model. No flatness or properness of the intervening map,
nor frame or metric preservation certificate, is required.
\end{theorem}
\begin{proof}
Choose an actual original local unit frame at the target point's true valuative
center, using the original line's actual invertibility cover. Genuine center
naturality puts the source center in the actual preimage open. Pull the original
frame back by the actual scheme map. The established whole residue/local-frame
comparison identifies its actual generic frame with the residue-field pullback
of the original target generic frame.

In that actual target fibre frame, the arbitrary original section morphism is
multiplication by its actual top-section coefficient: this is the genuine
structure-module endomorphism/global-section theorem. The whole frame pairing
and native pullback naturality send that exact equation to multiplication by
the actual residue-field pullback coefficient in the true source generic frame.
Evaluate both actual section morphisms at the original unit section. The true
model norm in any original local center frame is the original residue valuation
of precisely this actual coefficient. Naturality of the genuine affine
$\Gamma\operatorname{Spec}$ isomorphism identifies the two scalar coefficients
under the SAME original residue-field map. The target native valuation is,
by definition, the source valuation restricted along that original map.
Their actual model norms are therefore equal.
\end{proof}

\begin{corollary}[Every original generic-fibre section has its true pulled model norm]
\label{berkovich:actual-generic-section-model-norm-pullback}
\lean{EnvelopeProperty.Berkovich.RelativeSchemeValuedPoint.modelLineNorm_pullbackResidueSection_eq_overBase}
\leanok
\uses{berkovich:actual-generic-section-hom-model-norm-pullback,berkovich:actual-residue-section-pullback}
In the same situation, the true norm of the literal actual residue-field
pullback of EVERY original generic-fibre section equals its original model
norm at the SAME whole mapped native point, including the zero section.
\end{corollary}
\begin{proof}
Convert the arbitrary original fibre section to its true original structure-line
section morphism. Apply the preceding genuine norm equality. The actual
structure-line/top-section equivalence evaluates that original morphism at
one to recover exactly the original section. The source section is precisely
the defined actual residue-field pullback. This gives the asserted equality
on the entire original generic-line section module, without an extension premise.
\end{proof}
