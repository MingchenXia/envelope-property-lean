\begin{theorem}[Whole native Laurent and noncentral-open comparison]
\label{thm:native-test-configuration-unit-open}

Let $\mathcal X$ be any literal original test configuration
in the preceding definition. The same native scheme pullback
$P=\mathcal X\times_{\mathbf A^1}\mathbf G_m$ is isomorphic,
over the same original $k$, to precisely the whole original
noncentral open $\mathcal X\setminus\mathcal X_0$.
Both complete inclusion diagrams are retained. Its original
projection to $\mathcal X$ and original parameter map to
$\mathbf G_m$ are genuinely equivariant, the latter for the
original regular group action. The entire action on this
same native $P$ is internally derived. No unit-open action,
trivialization, normality or irreducibility is assumed.
\end{theorem}

\begin{proof}
The actual original unit-group inclusion is an open immersion
with entire image $D(t)$. Base change along the original
$\pi:\mathcal X\to\mathbf A^1$ gives the actual first
projection $P\to\mathcal X$, which is an open immersion
with whole image exactly $\pi^{-1}D(t)$.
This is precisely the original noncentral open in the same
original total scheme. The two original open immersions
with this identical entire range give a whole native
scheme isomorphism, retaining both actual inclusion equations.
Those equations and the original coefficient triangles prove
that this whole isomorphism is over the same original $k$.

The original test-configuration action makes $\pi$ equivariant
for the internally derived standard action on the same
original parameter line. The actual original group inclusion
is equivariant for its regular action and this standard line
action. The native equivariant Cartesian-square construction
therefore derives a genuine action on exactly this same
native $P$, with both entire original projections equivariant.
This establishes all whole original comparisons without a
replacement product, a desired action certificate, or a
normalization of the original total model.
\end{proof}
