\section{The actual affine pushforward of the same associated module sheaf}
\label{sec:spec-pushforward-tilde}

Let $f:R\to S$ be ANY original homomorphism of commutative rings.
All spectra, maps, modules and sheaves below are the original native
objects. No flatness, finite generation, nonzero or comparison
certificate is supplied.

\begin{theorem}[Every original global section has its same restricted coefficient action]
\label{lem:cartier-spec-pushforward-sections}
\lean{EnvelopeProperty.SpecPushforwardTilde.sectionsIso,EnvelopeProperty.SpecPushforwardTilde.sectionsIso_hom_apply}
\leanok
For every original module sheaf $N$ on $\operatorname{Spec}S$, the
actual global sections of its pushforward under the SAME original
$\operatorname{Spec}(f)$ identify genuinely with the native restriction
of scalars of its original global sections. The entire comparison
retains every same original section, its original additive operations
and its exact original $R$-coefficient action.
\end{theorem}
\begin{proof}
The inverse image of the whole original spectrum is the whole
original source. Thus pushforward global sections are precisely
the same entire original sections. The native spectrum coefficient
comparison identifies the original $R$-action through the actual
pullback of each original spectrum section with the native original
$f$-restricted $S$-action. This is the whole genuine inverse
$\Gamma\operatorname{Spec}$ naturality identity, applied to every
original coefficient and then to the original section's scalar
action. The actual identity-on-sections additive equivalence is
therefore linear, giving the genuine native module isomorphism.
\end{proof}

\begin{theorem}[The same whole affine pushed associated sheaf]
\label{thm:cartier-spec-pushforward-tilde}
\lean{EnvelopeProperty.SpecPushforwardTilde.pushforwardTildeIso}
\leanok
For EVERY original $S$-module $M$, the actual whole original sheaf
$\operatorname{Spec}(f)_*(\widetilde M)$ is genuinely isomorphic to
$\widetilde{\operatorname{Res}_f M}$. The construction uses the actual
native associated-sheaf and pushforward functors and retains their
original coefficient map, with no sheaf or coefficient comparison
data supplied.
\end{theorem}
\begin{proof}
The native associated sheaf is quasicoherent and its actual native
associated-sheaf/global-sections counit is invertible. Genuine affine
spectrum pushforward preserves the actual localization property,
so the native counit for the SAME pushed sheaf is invertible as
well. Invert this actual counit, giving the associated sheaf of its
actual global sections. Apply the preceding true global-section
comparison and then the actual original associated-sheaf unit
isomorphism, restricted through the SAME original $f$. Apply the
genuine associated-sheaf functor to these actual original module
isomorphisms. Their composite gives the asserted whole sheaf
isomorphism. All native inverse identities are part of these genuine
isomorphisms; no target sheaf equivalence is an input.
\uses{lem:cartier-spec-pushforward-sections}
\end{proof}

The intended consumer is the SAME actual affine scheme Frobenius:
its true spectrum coefficient identity will specialize this result
to the original Frobenius-restricted exterior modules. Constructing
and comparing the actual sheaf differential and Cartier map, their
whole overlap descent and Deligne--Illusie splitting remain further
obligations. No such descent or vanishing is claimed here.
