\section{The original localized inverse projection preserves native local data}

\begin{theorem}[Actual whole original inverse section localization]
\label{thm:fc-localized-inverse-section-localization}
\leanok
\lean{EnvelopeProperty.LocalizedInverseStalks.projection_sections_isLocalization}
For any actual affine $Y\to\operatorname{Spec}A$ and actual coefficient
localization $A\to S$, the literal original whole section map of
$Y_S\to Y$ is localization at the image of the same original multiplicative
set.  This property is derived internally, not supplied to the consumer.
\end{theorem}
\begin{proof}
The original whole affine section tensor equivalence preserves both actual
coefficient projections.  Its original first-projection triangle makes it
an isomorphism over the same original $\Gamma(Y,\mathcal O_Y)$, so the native
tensor-localization theorem transports to the literal original section map.
\end{proof}

\begin{theorem}[Same original point, stalk and residue data]
\label{thm:fc-localized-inverse-native-stalks-residues}
\leanok
\lean{EnvelopeProperty.LocalizedInverseStalks.projection_stalkMap_isIso, EnvelopeProperty.LocalizedInverseStalks.projection_residueFieldMap_isIso, EnvelopeProperty.LocalizedInverseStalks.projection_injective}
Every native original stalk map and residue-field map of that same entire
inverse projection is an isomorphism.  Its actual original point map is
injective.  No domain, normality, Noetherianity or flatness of the original
$Y\to\operatorname{Spec}A$ is required.
\uses{thm:fc-localized-inverse-section-localization,thm:fc-affine-localization-native-stalks,thm:fc-affine-localization-native-residue-fields}
\end{theorem}
\begin{proof}
Apply the actual affine-localization stalk and residue theorems to the
internally derived literal section localization.  The actual coefficient
localization spectrum map is a native preimmersion; its actual base change
therefore has an injective original point map.  Every point and local map
remains the original one, with no point, residue or degree matching premise.
The nongeneric-point/fibre bijection and global singular-curve degree sum
remain their separate concrete consumers.
\end{proof}
