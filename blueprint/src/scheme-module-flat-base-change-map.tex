\section{The canonical original scalar-extension section map}

\begin{lemma}[The canonical scalar-extension section comparison]
\label{lem:fc-scheme-module-flat-base-change-map}
\lean{EnvelopeProperty.SchemeModuleFlatBaseChangeMap.unitMap,EnvelopeProperty.SchemeModuleFlatBaseChangeMap.sectionComparison,EnvelopeProperty.SchemeModuleFlatBaseChangeMap.unitMap_apply,EnvelopeProperty.SchemeModuleFlatBaseChangeMap.sectionComparison_tmul,EnvelopeProperty.SchemeModuleFlatBaseChangeMap.targetSheaf,EnvelopeProperty.SchemeModuleFlatBaseChangeMap.unitComparison,EnvelopeProperty.SchemeModuleFlatBaseChangeMap.comparison,EnvelopeProperty.SchemeModuleFlatBaseChangeMap.comparison_app,EnvelopeProperty.SchemeModuleFlatBaseChangeMap.comparison_tmul}
\leanok
\uses{lem:fc-scheme-scalar-module-presheaf,prop:fc-finite-cech-flat-base-change}
On the actual cartesian scalar base change of an original
$p:X\to\operatorname{Spec}R$, let $g$ and $q$ be its actual projections.
For any original module $M$, the original pullback adjunction unit gives
a canonical natural section comparison
$S\otimes_R\Gamma(U,M)\to\Gamma(g^{-1}U,g^*M)$ on every original open.
Its value on every $s\otimes m$ is the original coefficient $s$ times
the actual original pullback-unit section of $m$.
\end{lemma}
\begin{proof}
The actual cartesian square and original spectrum section naturality
identify the two whole coefficient maps on each original open. The
original module adjunction unit is therefore linear over the literal
original $R$ actions. Extend that original linear map along $R\to S$
using the genuine tensor universal property. The actual unit's
presheaf naturality and the original module restriction scalar formula
prove naturality of the entire tensor comparison, by checking pure
tensors. No scalar compatibility, section map or naturality square is
supplied as a certificate.
\end{proof}
