\section{Integral ampleness in dimension zero}
Throughout this section $X$ is the original integral scheme and its actual
topological Krull dimension is at most zero. No residue-field closure,
selected global frame, unit comparison, curve or positivity certificate
is an input.

\begin{lemma}[An original local line frame becomes global]
\label{lem:seshadri-original-dimzero-global-frame}
\lean{EnvelopeProperty.SeshadriAmplenessCriterionDimensionZeroAmpleness.nonempty_unitIso_of_dimension_le_zero}
\leanok
Every original invertible $L$ is whole-isomorphic to the original
structure module on $X$.
\end{lemma}
\begin{proof}
Unpack the original native invertibility cover. Its actual open sets
cover the original generic point, so choose one actual open $U$ containing
that point with its original native pullback frame. The closed complement
$Z=X\setminus U$ is proper because it misses that actual point. The
existing proved zero-dimensional proper-closed emptiness theorem gives
that $Z$ has no points. Thus $U$ is the actual top open, not merely a
neighborhood to which a frame is assumed to extend.

Transport the chosen original frame along this equality to the actual
top-open pullback. Pullback along the existing scheme isomorphism
$X|_X\simeq X$ is the existing native equivalence. Compose the actual
top-open frame with the inverse of the actual pullback-unit isomorphism,
then apply this fully faithful functor's actual preimage-isomorphism
operation. This produces a whole original $L\simeq\mathcal O_X$.
No new section carrier or gluing certificate occurs.
\end{proof}

\begin{theorem}[Native very ampleness in integral dimension zero]
\label{thm:seshadri-original-dimzero-very-ample}
\lean{EnvelopeProperty.SeshadriAmplenessCriterionDimensionZeroAmpleness.isVeryAmple_of_dimension_le_zero}
\leanok
Let $p:X\to\operatorname{Spec}k$ be the original projective morphism
over a field. Every original invertible $L$ is genuinely native very
ample for this same $p$.
\uses{lem:seshadri-original-dimzero-global-frame}
\end{theorem}
\begin{proof}
Internally obtain an actual finite-dimensional projective closed
embedding $i$ for the original $p$, including its actual base triangle.
Let $H=i^*\mathcal O(1)$ be its actual original whole pullback; it is
invertible by the existing native theorem. Apply the preceding internal
frame producer to both this same $H$ and the original $L$. Their actual
whole comparisons $H\simeq\mathcal O_X\simeq L$ identify the original
pullback with the same $L$. The same original embedding, its closedness,
its original base triangle and this internally constructed whole
comparison are exactly a witness of native very ampleness of $L$.
No extra compactness or separatedness input is needed.
\end{proof}

\begin{theorem}[Native ampleness in integral dimension zero]
\label{thm:seshadri-original-dimzero-ample}
\lean{EnvelopeProperty.SeshadriAmplenessCriterionDimensionZeroAmpleness.isAmple_of_dimension_le_zero}
\leanok
Under the same ordinary original hypotheses, $L$ is genuinely native
ample.
\uses{thm:seshadri-original-dimzero-very-ample}
\end{theorem}
\begin{proof}
The original first tensor power of $L$ is invertible by the existing
native tensor-power theorem. Apply the preceding very-ampleness result
directly to that original power. The original invertibility of $L$,
the positive exponent one and this native very-ampleness witness are
literally the existing native ample predicate. This avoids introducing
an additional desired comparison between the first power and $L$.
\end{proof}

The frame result does not require a field or projective morphism. It is
the actual original global unit comparison produced from invertibility
and zero-dimensional integrality alone. The last two results provide
the genuine zero-dimensional base of the separate integral Nakai
induction; they do not assert the positive-dimensional criterion or any
Main result.
