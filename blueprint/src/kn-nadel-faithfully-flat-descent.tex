pullbacks of a module homomorphism.  It is not an additional permanent
input to Nadel vanishing.  Its geometric verification for the original
cover must use the actual cross-chart maps and the intrinsic trace
compatibility already proved above.

$D=S\otimes_A S$ has its two actual coefficient maps $p_0,p_1:S\to D$

composition of scalar extension.  The native composition unit
formula gives the stated forward value.  Its inverse value follows
from whole final-ring linearity and the actual tensor balancing

\end{proof}

\begin{lemma}[The actual overlap and the native scalar-extension coaction]
\label{lem:kn-nadel-faithfully-flat-overlap-coaction}
\lean{EnvelopeProperty.Vanishing.NadelFaithfullyFlatDescent.pullbackLeft_unit,EnvelopeProperty.Vanishing.NadelFaithfullyFlatDescent.pullbackRight_unit,EnvelopeProperty.Vanishing.NadelFaithfullyFlatDescent.coaction_of_pullbacks,EnvelopeProperty.Vanishing.NadelFaithfullyFlatDescent.pullbacks_of_coaction,EnvelopeProperty.Vanishing.NadelFaithfullyFlatDescent.pullbacks_eq_iff_coaction}

For an actual commutative ring map $f:A\to S$ and an original
$A$-module $M$, form the actual ring $D=S\otimes_A S$, its left and
right coefficient maps, and the original structural map $A\to D$.
The native scalar-extension adjunction gives
\[
 \delta_M:S\otimes_A M\longrightarrow S\otimes_A(S\otimes_A M),
 \qquad s\otimes m\longmapsto s\otimes(1\otimes m).
\]
The two actual $D$-pullbacks of an $S$-linear map
$\lambda:S\otimes_A M\to S\otimes_A N$, identified through the
native scalar-composition isomorphisms, agree if and only if
$\delta_N\lambda=(1\otimes\lambda)\delta_M$.
\end{lemma}
\begin{proof}
Both actual overlap coefficient maps have the same composite with
$f$ by the tensor balancing law.  Native composition of scalar
extension identifies each iterated pullback with extension through
that actual common map.  On an original unit pure tensor, the left
pullback followed by the actual tensor associator has value
$\delta_N(\lambda(1\otimes m))$; the right has value
$1\otimes\lambda(1\otimes m)$.  These formulas follow from the
native scalar-composition unit formula and actual tensor balancing.
Scalar-extension homomorphisms are determined by their values on
$1\otimes m$.  The same native unit formula for $\delta_M$ therefore
proves the claimed equivalence of whole-map equalities, retaining
the original overlap ring and both coefficient maps.
\uses{lem:kn-nadel-faithfully-flat-coefficient-paths,lem:kn-nadel-faithfully-flat-tensor-comparison}
\end{proof}

\begin{theorem}[Unique descent of an actual compatible module map]
\label{thm:kn-nadel-faithfully-flat-module-map-descent}
\lean{EnvelopeProperty.Vanishing.NadelFaithfullyFlatDescent.comparison_full,EnvelopeProperty.Vanishing.NadelFaithfullyFlatDescent.comparison_faithful,EnvelopeProperty.Vanishing.NadelFaithfullyFlatDescent.existsUnique_of_coaction,EnvelopeProperty.Vanishing.NadelFaithfullyFlatDescent.existsUnique_descendedMap,EnvelopeProperty.Vanishing.NadelFaithfullyFlatDescent.descendedMap,EnvelopeProperty.Vanishing.NadelFaithfullyFlatDescent.descendedMap_baseChange,EnvelopeProperty.Vanishing.NadelFaithfullyFlatDescent.descendedMap_unique,EnvelopeProperty.Vanishing.NadelFaithfullyFlatDescent.pullbacks_baseChange,EnvelopeProperty.Vanishing.NadelFaithfullyFlatDescent.nativeTensorMorphism,EnvelopeProperty.Vanishing.NadelFaithfullyFlatDescent.existsUnique_linearMap}
\leanok
Suppose $f:A\to S$ is faithfully flat.  For arbitrary original
$A$-modules $M,N$, every actual $S$-linear map
$\lambda:S\otimes_A M\to S\otimes_A N$ whose two actual native
$D$-pullbacks agree is the scalar extension of a unique actual
$A$-linear map $g:M\to N$:
\[
 S\otimes_A g=\lambda.
\]
No descended map, comparison isomorphism, or effective-descent
certificate is supplied as an input.
\end{theorem}
\begin{proof}
Use the preceding actual overlap calculation to make $\lambda$ a
morphism between the native comparison coalgebras of the two
original modules.  Native faithfully flat module descent proves
that the actual scalar-extension functor is comonadic.  Its actual
comparison functor for the original extension/restriction adjunction
is therefore full and faithful.  Take the preimage of this actual
coalgebra morphism.  The whole comparison-map equality gives the
stated whole scalar-extension equality, and faithfulness gives
uniqueness.  This reuses the existing generic module-descent theorem;
only the original overlap and its concrete homomorphism interface
are new.
\uses{lem:kn-nadel-faithfully-flat-overlap-coaction}
\end{proof}

Subsequent application to the original finite flat Kummer cover must
construct the actual overlap identifications and verify this descent
condition using the proved genuine K\"ahler/canonical trace diagrams.
The lemma does not replace those geometric obligations with a final
vanishing hypothesis.  Global canonical duality, local vanishing,
and Nadel vanishing remain separate goals.
