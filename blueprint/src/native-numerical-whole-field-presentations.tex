\begin{theorem}[Simultaneous original numerical classes and entire native homogeneous field model]
\label{thm:native-numerical-whole-field-presentations}
\lean{EnvelopeProperty.NativeNumericalWholeFieldPresentations.exists_simultaneous_whole_field_presentation}
\leanok
\uses{thm:native-numerical-finite-class-families,thm:generated-line-family-closed-projection,thm:finite-projective-native-field-models,thm:native-numerical-projective-presentations}
\source{bj22-trivval:sec:tc}
Every finite family of genuine original real numerical classes
on an integral native-projective $X$ has one actual closed
embedding of that same $X$ into a finite original projective
product, over its exact original structure map, with a first
constituent which is itself closed. Each given class is an
actual real combination of differences of the original
factor $\mathcal O(1)$ classes with one common denominator
factor. The actual original projective ratios of these same
factors internally construct a homogeneous model over the
entire same native $K(X)$, retaining exactly all original
factor dimensions and every original coordinate value.
No numerical-class, field-generation or model comparison
certificate is supplied.
\end{theorem}

\begin{proof}
Use the genuine original finite-class-family producer to
obtain finitely many original invertible lines $L_i$, one
original invertible denominator $T$, actual finite global
generators of $T$ and of every $L_i\otimes T$, and all given
classes' exact original expressions in
$[L_i\otimes T]-[T]$. Put the original denominator first and
these original numerators after it. Apply the actual
projective embedding theorem with a closed first constituent.
It supplies one extra original closed-embedding factor and
the whole original $\mathcal O(1)$ pullback isomorphism for
each original denominator and numerator, on the same $X$.
Numerical invariance under these actual whole line
isomorphisms gives every asserted original class equality.

Take the actual constituents of this same product map.
Their original structure triangles follow from the exact
whole product triangle and native projection identities.
The first is genuinely closed. Apply the whole-native-field
finite-family model construction to these same maps.
It internally chooses their actual original generic charts,
takes the unchanged original projective ratios in native
$K(X)$, and derives generation of that entire field from the
first closed constituent. The resulting homogeneous model
has exactly these original dimensions and coordinates by
its defining construction. Thus it retains the same original
projective factors as the numerical formulas. An actual
scheme or analytic identification and invariance of model
psh under the intrinsic numerical quotient are further
comparison theorems; they are not inferred here.
\end{proof}
