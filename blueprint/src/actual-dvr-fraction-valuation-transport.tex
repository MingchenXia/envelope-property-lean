\subsection{The same original DVR valuation under genuine fraction-field transport}

\begin{lemma}[Whole native DVR valuation naturality on every original fraction]
\label{lem:actual-dvr-fraction-valuation-transport}
\lean{EnvelopeProperty.DVRFractionValuationTransport.valuation_comap}
\leanok
For the SAME original DVR $R$, two genuine original fraction fields $K,F$,
and an actual field map whose original coefficient square commutes, the native
maximal-ideal valuation on $F$ pulls back to exactly the native maximal-ideal
valuation on $K$. EVERY original fraction and zero are retained.
\end{lemma}
\begin{proof}
On EVERY original $R$ coefficient, BOTH native valuations are exactly its
SAME original integral maximal-ideal valuation, by native DVR valuation
construction. The actual original coefficient square therefore gives equality
on the whole original ring. Every original fraction in $K$ is a genuine
quotient of original ring elements with nonzero denominator; the given field
map and both valuations preserve that quotient, yielding the whole valuation
identity. No valuation-preservation condition is supplied.
\end{proof}
