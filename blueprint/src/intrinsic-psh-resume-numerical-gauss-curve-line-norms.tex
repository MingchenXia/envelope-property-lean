\section{The same original rational section has its true point-frame model norm}

Keep the original integral ambient scheme $Y$, the original integral
central scheme $C$, the actual morphism $i:C\to Y$, and the actual
invertible line $L$ on $Y$. Its map to an original polarized model may
be nondominant; no function-field embedding from that model is used.
Let $Y\to\operatorname{Spec}R$ be the actual proper structure morphism
with its actual bounded base valuation $v$. All native points, residue
fibres, proper centers and model norms are the already defined original
ones. An actual point of generic support is transported only along its
literal equality with the original generic point.

\begin{theorem}[Both original line coefficients retain the actual norm at every true point center]
\label{thm:intrinsic-numerical-original-two-frame-model-norm}
\lean{EnvelopeProperty.NumericalGaussCurveLineNorms.exists_twoFrame_modelNorm}
\leanok
\uses{thm:intrinsic-numerical-two-frame-original-coefficient-squares,def:gauss-central-line-original-generic-carrier,lem:gauss-central-line-true-center-generator-unit-norm,def:scheme-line-actual-model-norm,lem:actual-generic-residue-field-equivalence,lem:actual-generic-native-field-valuations,scheme:proper-native-center,cor:central-generic-prescribed-section-same-rational-lift,def:central-generic-original-local-section-value}
Fix ONE actual $i(\eta_C)$-neighborhood $U$ and actual frame
$\delta:O_U\simeq L|_U$. Let $\rho$ and $\sigma_C$ be its existing
original ambient and central generic sections. For each original $x\in C$,
internally construct an actual $p=i(x)$-neighborhood $V$, its genuine
frame $\delta_x$, a true overlap $W\subset U\cap V$ containing $i(\eta_C)$,
a genuine $r\in\Gamma(Y,W)^\times$, a genuine
$u\in\mathcal O_{Y,i(\eta_C)}^\times$, and actual nonzero
$f\in K(Y)$, $b\in K(C)$. These retain the original germ/stalk identities
and both original fibre equations
\[
 f=\operatorname{germ}_{\eta_Y}r=\operatorname{algebraMap}(u),\qquad
 b=i_{\eta_C}^{\#}u,\qquad
 \rho=f\rho_x,\quad\sigma_C=b\sigma_x.
\]
For EVERY actual native point $y$ over $v$ having original generic support
and TRUE proper center $i(x)$, the SAME original generic section satisfies
\[
 \|\rho(y)\|_L=|f(y)|,
\]
where the right side is the original whole-function-field valuation of
$y$ applied to this actual $f$. No norm, coefficient, section-coherence, order or slope identity is
supplied. The quantified points satisfy the ordinary actual true-center
condition stated above; no center comparison for a weighted point is
asserted here. In particular $p$ is NOT
required to lie in $W$: the actual $p$-frame lives on $V\ni p$, while the
old $\delta$ only lives near $i(\eta_C)$.
\end{theorem}
\begin{proof}
Apply the genuine two-frame producer to the given SAME $\delta$ and $x$.
It internally gives $V,\delta_x,W,r,u,f,b$ and both literal original fibre
identities, as well as the actual regular-unit representation of $f$.
Retain this representation for the later original weighted-point section
evaluation; it is valid on $W$ even if $p\notin W$.

The original equality-transport of generic residue-fibre sections preserves
scalar multiplication. To verify this, work first with an arbitrary scheme
point and its actual equality with the generic point; eliminate that equality.
Both sides are then the SAME original pulled-back module, actual generic
residue scalar and actual inverse $\Gamma\operatorname{Spec}$ scalar map.
The identical point transport sends the original generic section of
$\delta_x$ to its original local-section fibre value. Thus the internally
proved $\rho=f\rho_x$ holds in the actual generic-line module of EVERY such
$y$, with its actual residue scalar.

The true center is $i(x)\in V$. The existing genuine local-generator norm
formula therefore gives $\|\rho_x(y)\|_L=1$. This uses the actual
$p$-frame $\delta_x$ on $V$, not the old frame on $U$ or $W$. Apply the
original model norm's scalar law to the preceding internally derived
section identity. The actual $\Gamma\operatorname{Spec}$ isomorphism cancels
its inverse scalar map, leaving precisely the original generic-residue
field equivalence. Its composition with the actual residue valuation is
by definition the whole original function-field valuation of $y$.
Multiplication by the proved generator norm one gives the displayed equality.
\end{proof}

This is the actual norm dictionary for the internally constructed original
line coefficient. The later weighted native point specialization must use
its separately proved TRUE center and its genuine whole-field/section
evaluation. Identification of $b$ with the actual central generic-section
order, and the final weighted Euler-degree argument, remain distinct
mathematical consumers; no such identity is an incoming premise here.
