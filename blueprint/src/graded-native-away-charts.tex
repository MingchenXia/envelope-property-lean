\subsection{Whole native homogeneous-away charts of original graded seminorms}

\begin{definition}[Actual whole native chart homeomorphism]
\label{projective:actual-whole-graded-native-away-chart}
\lean{EnvelopeProperty.Berkovich.RelevantGradedSpectrum.nativeAwayHomeomorph}
\leanok
For any actually graded commutative ring, any original homogeneous $f$ of
positive degree, the ENTIRE actual native valued-point space supported
in its true Proj basic open is homeomorphic to the ENTIRE original
homogeneous-away seminorm spectrum. No field, normality, boundedness or
chosen chart comparison is assumed.
\end{definition}
\begin{proof}
Use the actual native open-restriction homeomorphism, then the genuine
native Proj basic-open/spectrum scheme isomorphism, then the actual
whole affine native-spectrum homeomorphism. Each map is a proved whole
homeomorphism on the independently defined original point spaces.
\end{proof}

\begin{lemma}[Every original away fraction is its actual original section value]
\label{projective:actual-whole-graded-away-chart-value}
\lean{EnvelopeProperty.Berkovich.RelevantGradedSpectrum.nativeAwayHomeomorph_val}
\leanok
\uses{projective:actual-whole-graded-native-away-chart}
For EVERY actual native support-open point and EVERY original
homogeneous-away element $q$, its value under this whole chart is
EXACTLY the true native evaluation of the SAME original
$\operatorname{awayToSection}(q)$ section on the SAME original Proj open.
\end{lemma}
\begin{proof}
Lift the original native point through the actual open-restriction
homeomorphism. Whole affine-spectrum evaluation is evaluation of the
actual original global section of $q$. Pull this section through the
true Proj basic-open scheme isomorphism. Its native global-section map
is the actual away-to-section map conjugated by the original spectrum
and open top-section isomorphisms. These genuine ring isomorphisms
cancel, giving exactly the actual original away section. The native
open-inclusion evaluation identity gives the displayed original value.
All support proofs are transported as dependent propositions; no
coordinate-only point equality is substituted.
\end{proof}

\begin{theorem}[Canonical original graded points retain their whole fraction seminorm]
\label{projective:actual-graded-native-canonical-away-seminorm}
\lean{EnvelopeProperty.Berkovich.RelevantGradedSpectrum.nativeAwayHomeomorph_nativePoint}
\leanok
\uses{projective:actual-whole-graded-away-chart-value}
If an ORIGINAL relevant graded seminorm has support in the true basic
open, its actual canonical native point has under this whole chart the
ENTIRE restriction of its genuine original localization valuation to
the SAME homogeneous-away ring.
\end{theorem}
\begin{proof}
Compare every original homogeneous-away element using the preceding
true native chart-value theorem and the actual canonical graded native
point's already proved away-section evaluation formula. The right side
is precisely actual spectrum pullback of the original localization
valuation. Extensionality of WHOLE valuations proves the equality.
\end{proof}

\begin{theorem}[Whole chart and canonical point inverse identities]
\label{projective:actual-graded-native-away-point-recovery}
\lean{EnvelopeProperty.Berkovich.RelevantGradedSpectrum.nativeAwayHomeomorph_map_awayι, EnvelopeProperty.Berkovich.RelevantGradedSpectrum.nativePoint_eq_map_awayι}
\leanok
\uses{projective:actual-whole-graded-native-away-chart, projective:actual-graded-native-canonical-away-seminorm}
EVERY native affine homogeneous-away point, mapped through the actual
Proj away open immersion, is sent by the SAME entire chart to its
ORIGINAL whole affine seminorm. Consequently each original canonical
graded native point is EXACTLY the image under the literal original away
chart immersion of the actual affine native point of its genuine
original homogeneous fraction seminorm, including the residue valuation.
\end{theorem}
\begin{proof}
The native away immersion is the literal composite of the inverse true
Proj basic-open scheme isomorphism and original open inclusion. Actual
open-restriction and scheme-isomorphism homeomorphisms cancel on this
whole composite; the remaining map is exactly the original whole affine
spectrum homeomorphism. For a canonical original point, its whole chart
seminorm is the preceding genuine localization restriction. Apply the
injectivity of the SAME actual whole chart homeomorphism and the first
identity to recover equality of entire original native points. Support
in the basic open for the affine image follows from the actual whole
range of the genuine away immersion.
\end{proof}
