\begin{theorem}[Whole original affine canonical differential isomorphism]
\label{sc0-affine-formally-etale:whole-native-differential}
\lean{EnvelopeProperty.CanonicalGeometry.exteriorCotangentSheafPullbackMap_isIso_of_formallyEtale}
\leanok

affine scheme morphism whose SAME actual global-section ring map

exterior differential is an actual isomorphism. No target
smoothness, finite presentation, desired-inverse, sheaf-unit or
coefficient-matching hypothesis is supplied.
\end{theorem}
\begin{proof}
The actual structural section algebras and SAME original section
ring map form a genuine algebra tower. Formal etaleness derives
an actual target differential basis from the original source
basis. The preceding basis-only whole affine canonical frame
therefore derives target canonical invertibility and quasicoherence,
without asserting finite presentation of $Y$. Original source
smoothness derives source canonical invertibility and true
quasicoherence of its actual native pullback.

The SAME source and target exterior sheafification units are
bijective on the ENTIRE original affine section modules by the
proved free-affine comparison. The genuine all-form native affine
pullback comparison identifies the WHOLE original sheaf differential
between those units with the original raw scalar-extended
canonical differential. This raw map is genuinely bijective from
formal etaleness by the preceding entire-map theorem. The actual
units and native pullback comparison are isomorphisms, so the SAME
original global-section differential is an isomorphism.

Finally quasicoherent module maps on an actual affine scheme are
retained by the true global-sections/associated-sheaf comparison:
conjugate by the SAME original affine spectrum isomorphism and use
the genuine from-tilde-global-sections isomorphisms on both original
modules. Naturality identifies the entire original map with the
associated-sheaf map of its actual global-section isomorphism.
Thus the WHOLE original module morphism is an isomorphism.
\uses{sc0-affine-canonical-basis:whole-frame,

\end{proof}
