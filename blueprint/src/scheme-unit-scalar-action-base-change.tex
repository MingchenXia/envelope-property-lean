\section{Original functions and whole scalar maps under genuine native pullback}
\label{sec:scheme-unit-scalar-action-base-change}

\begin{theorem}[The same original function gives the actual pulled unit map]
\label{sc0-unit-scalar-base-change:unit-section}
\lean{EnvelopeProperty.SchemeUnitScalarActionBaseChange.sectionHom_pullback_unit}
\leanok
For ANY original morphism $f:Y\to X$ and ANY original global function $a$,
the pullback of its actual original structure-module section endomorphism,
conjugated by the SAME native structure-unit pullback isomorphism, is the
actual original section endomorphism of $f^*a$. No affine, flatness or
unit-comparison premise is supplied.
\end{theorem}
\begin{proof}
Under the genuine native pullback--pushforward adjunction, its unit
comparison is precisely the original structure-ring homomorphism.
Adjunction naturality reduces the entire claimed square to the original
structure-ring map commuting with multiplication by $a$. On every original
open and every original function this is multiplicativity of the SAME
ring map, together with its genuine restriction naturality for the
restriction from the original top open. Sheaf-morphism extensionality
then gives the entire original map equality; adjunction injectivity and
the actual unit isomorphism recover the desired conjugation.
\end{proof}

\begin{theorem}[The entire original unit action under the true unit comparison]
\label{sc0-unit-scalar-base-change:whole-unit-action}
\lean{EnvelopeProperty.SchemeUnitScalarActionBaseChange.unitAction_pullback}
\leanok
For ANY original endomorphism of the original structure module, its
entire original unit action pulls back by conjugation with the SAME
native structure-unit pullback isomorphism.
\end{theorem}
\begin{proof}
The genuine strong monoidal functor left-unit and tensor coherence gives
this equality first for the native monoidal unit. The actual native
monoidal-to-structure-unit pullback theorem gives the original square
between both unit comparisons. Cancelling its genuine isomorphisms
identifies both conjugations as entire original maps. Substitute this
identity into the original left-unit action formula. No unit coherence
or matching equation is supplied as a premise.
\end{proof}

\begin{theorem}[The entire original scalar action pulls back]
\label{sc0-unit-scalar-base-change:whole-scalar}
\lean{EnvelopeProperty.SchemeUnitScalarActionBaseChange.globalScalarAction_pullback}
\leanok
For ANY original module sheaf $M$, pullback of its entire original action
by $a$ equals the entire original action of $f^*a$ on the SAME native
pullback module. No frame, quasi-coherence, invertibility or compatibility
premise is supplied.
\end{theorem}
\begin{proof}
In an arbitrary strong monoidal functor, genuine tensor naturality and
left-unit coherence transport the original left-unit scalar action by
conjugating its unit endomorphism with the actual monoidal unit comparison.
The genuine native monoidal-to-structure-unit pullback theorem identifies
this with conjugation by the SAME original structure-unit comparison.
The preceding theorem identifies that actual conjugate with the SAME
original pulled global function's section endomorphism. Substituting in
the whole original left-unit expression gives equality of the entire
maps, with no equation about chosen local sections assumed.
\end{proof}
