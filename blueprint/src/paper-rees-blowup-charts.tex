\subsection{Actual Rees charts and the original paper blowup charts}

\begin{theorem}[The same whole finite-family fraction chart]
\label{paper:actual-rees-original-blowup-chart}
\uses{algebra:actual-rees-degree-zero-chart-equivalence}
\lean{EnvelopeProperty.ReesPaper.family,
EnvelopeProperty.ReesPaper.Chart,
EnvelopeProperty.ReesPaper.fractionAlgebra_eq_blowupChart,
EnvelopeProperty.ReesPaper.chartEquiv,
EnvelopeProperty.ReesPaper.chartEquiv_coe,
EnvelopeProperty.ReesPaper.chartEquiv_algebraMap,
EnvelopeProperty.ReesPaper.chartEquiv_coordinateRatio,
EnvelopeProperty.ReesPaper.scalarAlgebra,
EnvelopeProperty.ReesPaper.baseMap,
EnvelopeProperty.ReesPaper.chartEquivScalar,
EnvelopeProperty.ReesPaper.chartEquivScalar_comp_base}
\leanok
Let $A$ be the ORIGINAL domain, $s\subseteq A$ an actual finite set,
$j\in s$ with $j\ne0$, and let the Rees presentation family be the
ACTUAL subtype inclusion $s\to A$. Its genuine degree-zero chart has a
constructed $A$-algebra equivalence with the EXISTING paper ring
$\operatorname{blowupChart}(s,j)=A[h/j:h\in s]\subseteq\operatorname{Frac}A$.
Every original coefficient and every original coordinate fraction are
preserved. No new blowup-chart ring or ring-equivalence certificate is used.
\end{theorem}
\begin{proof}
The actual range of the subtype-indexed family $h\mapsto h/j$ is exactly
the actual image of the original set $s$ under that SAME fraction function:
both implications follow by retaining the original element and its actual
membership proof. Thus the two original adjoined subalgebras are equal,
not merely abstractly isomorphic. Compose the proved genuine Rees chart
algebra equivalence with the subalgebra equivalence of that equality.
Its forward map into the SAME original fraction field is the established
whole homogeneous-fraction map, so it preserves every coefficient and every
true original $h/j$. The actual $A$-algebra law proves equality of the whole
original coefficient ring maps; over any given commutative coefficient ring $k\to A$
construct the inherited action through $A$ and restrict the SAME equivalence.
When $k$ is the original coefficient FIELD, the resulting whole triangle
agrees with the existing paper $\operatorname{chartMap}$.
No property of a valuation is used in this algebraic proof.
\end{proof}

\begin{theorem}[Whole native and original paper point comparisons]
\label{paper:actual-rees-original-blowup-points}

The SAME actual chart equivalence induces genuine homeomorphisms on the
entire absolute affine spectra and native affine scheme-valued points,
and on the EXISTING paper spaces over trivially valued $k$.
On EVERY original chart element the transported value is its value under
the whole algebra equivalence. The maps to the ORIGINAL base point agree
as entire points. Every original coordinate fraction has the true
$\operatorname{chartFrac}$ value, and the original trivial-field bridge
commutes on entire points.
\end{theorem}
\begin{proof}
Pull back whole multiplicative seminorms along the ACTUAL ring equivalence
and its genuine inverse. The two whole ring inverse identities give both
point inverse laws; each entire evaluation pulls back to a true evaluation,
so both maps are continuous. Coefficient commutation yields the entire base
point triangle by actual seminorm extensionality on EVERY base element.
The same $k$-algebra equivalence preserves every original scalar value,
so its pullback is the existing paper algebra-equivalence homeomorphism,
with both whole inverse laws. The actual old-to-absolute bridge
commutes because both sides pull back the SAME entire ring map.

For native affine points use the already constructed genuine affine
scheme-valued-point homeomorphisms to spectra on both original rings.
Their exact Spec-map naturality identifies the resulting point map with
the actual Spec map of this SAME ring equivalence, rather than a chosen
native bijection. Thus the whole coefficient/base triangle and all original
point values agree. No generator-value inference for seminorms is used;
coordinate formulas are consequences of these entire ring-map identities.
The parent scheme construction supplies the separate actual chart inclusion
and proper-surjective projection; this bridge retains their original rings
without changing the existing weakly-psh definition.
\end{proof}
