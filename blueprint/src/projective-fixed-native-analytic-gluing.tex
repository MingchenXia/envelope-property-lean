\section{The whole original native analytic space is the fixed homogeneous model}
\label{sec:projective-fixed-native-analytic-gluing}

\begin{theorem}[Actual global native analytic reconstruction {\cite[\S1.2]{BJ22}}]
\label{thm:projective-fixed-native-analytic-gluing}
\lean{EnvelopeProperty.ProjectiveFixedNativeAnalyticGluing.nativeToModel, EnvelopeProperty.ProjectiveFixedNativeAnalyticGluing.nativeToModel_on_chart, EnvelopeProperty.ProjectiveFixedNativeAnalyticGluing.nativeToModel_mem_chartDomain_iff, EnvelopeProperty.ProjectiveFixedNativeAnalyticGluing.nativeToModel_injective, EnvelopeProperty.ProjectiveFixedNativeAnalyticGluing.nativeToModel_surjective, EnvelopeProperty.ProjectiveFixedNativeAnalyticGluing.nativeToModel_isLocalHomeomorph, EnvelopeProperty.ProjectiveFixedNativeAnalyticGluing.nativeModelHomeomorph}
\leanok
\uses{thm:projective-fixed-native-analytic-overlap,thm:projective-fixed-native-analytic-support}
For every actual closed embedding of an original integral scheme into finite
projective space over the original field, and every original nonempty pivot
chart, the original native analytic space with the exact original trivial
base valuation is homeomorphic to the one fixed reconstructed homogeneous
model over the entire original native function field. This global map agrees
with the whole original native comparison on every nonempty coordinate chart,
and preserves membership in every original coordinate support open exactly.
\end{theorem}
\begin{proof}
Every original support point lies in an original projective coordinate chart.
Define its model image using one such actual chart. Actual overlap
compatibility proves equality with the map from every other original chart
containing that point, so no compatibility premise is needed. The already
proved support comparison gives the exact inverse image of every model chart.
For injectivity, choose an original chart containing the first native point.
Equality of model images and exact support comparison put the second native
point in the same original chart, where the genuine chart homeomorphism is
injective. For surjectivity, choose a coordinate of model value one; such a
coordinate exists by the actual normalization of the model analytic space.
Its original generic coordinate is nonzero, hence the corresponding original
native chart is nonempty. The inverse of its genuine native chart
homeomorphism supplies an actual preimage of the whole model point.
Finally the global map restricted to every original support-open chart is
the genuine local homeomorphism followed by the open inclusion of its model
chart. These actual charts cover the original native space, so the global
map is a local homeomorphism. A bijective local homeomorphism is a genuine
global homeomorphism. All coefficient actions, native support points, and
whole chart algebras are the original ones throughout.
\end{proof}
