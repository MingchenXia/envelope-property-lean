\section{The original parameter open is schematically dense}
\label{sec:flat-parameter-open}

\begin{theorem}[Whole parameter-open density and reducedness]
\label{thm:flat-parameter-open}
\lean{EnvelopeProperty.FlatParameterOpen.inclusion_app_injective, EnvelopeProperty.FlatParameterOpen.isReduced_of_parameterOpen, EnvelopeProperty.FlatParameterOpen.inclusion_isSchemeTheoreticallyDominant, EnvelopeProperty.FlatParameterOpen.dense}
\leanok
\source{bj22-trivval:sec:tc}
Let the original $f:Z\to\operatorname{Spec}R$ be flat and let
$r$ be an original nonzerodivisor in $R$. The entire original
open $O=f^{-1}D(r)$ has an inclusion that is injective on
every original section ring and is schematically dominant.
If this same original $O$ is reduced, then all of $Z$ is reduced.
If $R$ is a domain and $f$ locally finitely presented, this
same original $O$ is topologically dense whenever $r\ne0$.
\end{theorem}

\begin{proof}
Flatness makes each original affine coefficient algebra flat
over $R$, so multiplication by the original nonzerodivisor
$r$ is injective on every such algebra. Consequently genuine
localization by $r$ separates the whole affine section ring.
Sheaf uniqueness extends this to injectivity of the entire
original restriction $\Gamma(Z,U)\to\Gamma(Z,U\cap O)$ for
every original open $U$. The original inclusion's section
map is precisely this restriction, with the actual original
open-scheme section identification. Hence it too is injective.
Every affine component of its scheme-image kernel is
contained in this zero section kernel, so the original
inclusion is schematically dominant. If $O$ is reduced, these
actual injections into reduced section rings show that all
original section rings of $Z$ are reduced, hence $Z$ is reduced.

For the last assertion, $D(r)$ is a nonempty open of the
irreducible spectrum of the domain $R$: its actual zero
prime belongs to it because $r\ne0$. It is therefore dense.
The original flat locally finitely presented $f$ is an open
map. The inverse image of a dense set under an open map is
dense, so the entire original $O$ is dense in $Z$.
No irreducibility or normality of $Z$ enters any assertion.
\end{proof}
