\begin{theorem}[An actual arbitrary proper birational native witness constructs the original finite-set witness]
\label{paper:actual-proper-birational-weakly-psh-converse}
\leanok
\lean{EnvelopeProperty.isWeaklyPSHOn_of_properBirational_nativeWitness}
\uses{paper:actual-native-witness-affine-chart-pullback,paper:actual-finite-family-original-affine-cover,scheme:actual-proper-birational-original-rees-domination}

be an ACTUAL proper scheme map and let genuine dense-open partial-isomorphism

need not be reduced, integral, projective, of finite type over $k$ or Noetherian.
Give its actual native space the exact trivial-$k$ locus via the ORIGINAL
composite $Y\to\operatorname{Spec}A\to\operatorname{Spec}k$.
If an original function $u$ on the actual old affine point space is intrinsically
locally psh after this genuine whole projection, then it satisfies the
UNCHANGED original finite-set chart definition of weakly psh.
No domination, chart lift, scalar action or function-class comparison
certificate is supplied. In particular no projective embedding of $Y$ is assumed.
\end{theorem}
\begin{proof}
The genuine proper-birational Rees domination theorem CONSTRUCTS an actual
finite original coefficient family $G:J\to A$, an actual member $G_j\ne0$
and a whole map $\delta:\operatorname{ReesScheme}(G)\to Y$ satisfying
$f\circ\delta=\mu_G$. The finite index and nonzero member are derived from
the original actual geometry. Use its real finite enumeration to form the
LITERAL original finite set $s=\operatorname{image}G$. It has a genuine
nonzero element, as required by the UNCHANGED old definition.

For EACH original $a\in s$, $a\ne0$, choose its actual index $i$ with
$G_i=a$. The true finite-family paper-chart comparison constructs the original
open chart $\alpha_i:\operatorname{Spec}(\operatorname{blowupChart}(s,a))\to
\operatorname{ReesScheme}(G)$, retaining EVERY original coefficient and its
WHOLE triangle $\mu_G\circ\alpha_i=\operatorname{Spec}(\operatorname{chartMap})$.
Composing with the ACTUAL $\delta$ therefore gives the exact original affine
chart triangle into $Y$.

The already checked original $k$-algebra law constructs the WHOLE scalar
triangle on that same chart. Actual native pullback of regular-unit presentations,
the genuine affine-unit comparison and the unchanged trivial-$k$ comparison
then give the original old locally psh function on THIS entire original chart.
Its projected point is exactly the old comap point on EVERY $A$ element.
Thus every nonzero original $a\in s$ has precisely the original chart property,
proving the UNCHANGED old weakly psh class. No assumption about native properness
of $\delta$, scheme-surjectivity of $\delta$, a projective witness, or a
support-only equality is used in this pullback argument.
\end{proof}

\begin{theorem}[Exact proper-birational witness equivalence for the unchanged old class]
\label{paper:actual-proper-birational-weakly-psh-witness-iff}
\leanok
\lean{EnvelopeProperty.IsWeaklyPSHOn.exists_properBirational_nativeWitness,
EnvelopeProperty.isWeaklyPSHOn_iff_properBirational_nativeWitness}
\uses{paper:actual-proper-birational-weakly-psh-converse,paper:actual-old-weakly-psh-native-rees-witness,scheme:actual-rees-regular-birational-data}

an ACTUAL proper birational $f:Y\to\operatorname{Spec}A$ for which the pullback
of the ORIGINAL $u$ is intrinsically locally psh on the actual exact trivial-$k$

Rees scheme: it is genuinely integral, proper and scheme-surjective, with
actual birational data and the entire original native function pullback.
No old definition or proof body is changed. Classical psh, harmonic comparison,
subharmonic finite descent and maximum principles remain separate analytic work.
\end{theorem}
\begin{proof}
From the original weakly psh finite-set witness, the checked actual original
Rees construction retains that SAME set, scheme, projection and native function.
It derives integrality, properness and scheme-surjectivity. Its actual nonzero
original generator is a genuine regular element of the original domain $A$.

construct a real partial isomorphism over its WHOLE original projection. Thus
it has genuine birational data, not an assumed birationality certificate.
These are the required actual witness properties.

Conversely extract the actual partial isomorphism and its WHOLE over-base

Rees domination and original-chart pullback theorem applies directly, giving
the UNCHANGED original weakly psh class. No reducedness or projective embedding
is extracted from the existential witness. These two constructions prove the
claimed exact equivalence while retaining the original point maps/functions.
\end{proof}
