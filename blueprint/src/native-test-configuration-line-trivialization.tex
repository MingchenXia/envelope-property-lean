\section{Original source linearization gives a whole noncentral-open line isomorphism}
\label{sec:native-test-configuration-line-trivialization}

\begin{theorem}[Actual whole source line trivialization]
\label{thm:native-test-configuration-line-trivialization}
\lean{EnvelopeProperty.NativeTestConfiguration.TestConfiguration.lineActionMap, EnvelopeProperty.NativeTestConfiguration.TestConfiguration.lineProjectionMap, EnvelopeProperty.NativeTestConfiguration.TestConfiguration.unitOpenFibreProjection, EnvelopeProperty.NativeTestConfiguration.TestConfiguration.lineActionLift_action, EnvelopeProperty.NativeTestConfiguration.TestConfiguration.lineActionLift_projection, EnvelopeProperty.NativeTestConfiguration.TestConfiguration.lineActionLift_original, EnvelopeProperty.NativeTestConfiguration.TestConfiguration.unitOpenLineIso}
\leanok
\uses{thm:native-test-configuration-action-fibre-diagrams}
\source{bj22-trivval:sec:tc}
Let $C$ be any literal original test configuration. Let $\mathcal L$
be an original module sheaf on its original total scheme, with
the actual source linearization isomorphism
$a^*\mathcal L\simeq\operatorname{pr}_2^*\mathcal L$ for the
original action and projection. Let $L$ be the original module
sheaf on the same original $X$, with the original fibre-one
identification of $\mathcal L|_{C_1}$ with the pullback of $L$.
Then the entire original restriction of $\mathcal L$ to the
same original noncentral open is actually isomorphic to the
pullback of $L$ by the original whole product trivialization's
$X$ projection. No desired open/generic line trivialization is
supplied. In particular the result applies to the original
linearized invertible sheaves of source test configurations,
and to every actual integral power representing a source
rational line bundle. No reducedness, normality, or integrality
assumption is required.
\end{theorem}

\begin{proof}
Use the actual original whole unit-open lift to the original group
action product. Its composite with the original action is exactly
the original open inclusion, while its composite with the original
second projection is the actual same-unit-fibre projection followed
by the original fibre-one inclusion. Pull the actual source
action linearization back along this whole lift, using the true
native pullback composition isomorphisms. The two original whole
scheme equations identify its source with the original restricted
module and its target with the pullback of the original fibre-one
restriction. Pull back the original source fibre-one module
identification along the same actual fibre projection. Compose
with the native pullback composition isomorphism. The original
whole action--fibre diagram identifies this composite scheme map
with precisely the original $X$ projection of the source product
trivialization, giving the asserted entire module-sheaf isomorphism.
This argument uses only the genuine action-isomorphism part of
the source linearization; its unit and cocycle laws are not
additional hypotheses needed for existence of this whole
isomorphism. Invertibility is likewise unnecessary for the
stronger arbitrary-module statement. Compatibility with the
full source unit/cocycle is a further coherence assertion,
not an assumption that replaces this actual producer.
\end{proof}
