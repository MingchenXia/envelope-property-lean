\section{Full actual original ample-line psh and the same native model}
\label{sec:native-ample-model-psh-comparison}

\begin{definition}[Independent original whole-section psh]
\label{def:native-line-whole-section-psh}
\lean{EnvelopeProperty.NativeLineFubiniStudy.IsPSH}
\leanok
\uses{def:native-line-whole-section-general-fs}
For an actual original line $L$ and real coefficient $\theta$, original psh
means a nonidentically negative-infinite upper semicontinuous function that is
the actual pointwise infimum of a nonempty directed decreasing net of actual
original FS functions whose original rational coefficients converge to
$\theta$. All terms use the original entire tensor-power global sections,
true original model norms and arbitrary real weights; common zeroes are
allowed. There is no model-psh or comparison predicate in this definition.
\end{definition}

\begin{theorem}[Every full original psh net transports with its true class]
\label{thm:native-ample-model-full-psh-transport}
\lean{EnvelopeProperty.NativeAmpleModelPSHComparison.isPSH_transport}
\leanok
\uses{def:native-line-whole-section-psh,thm:native-ample-model-full-fs-transport,def:gl-psh}
Assume throughout this statement that the original scheme $X$ is integral.
Fix the same actual original positive-power embedding with $r>0$. Every
original whole-section psh function of coefficient $\theta$ transports to
genuine model psh of coefficient $\theta/r$ under the same entire native
analytic homeomorphism.
\end{theorem}
\begin{proof}
Transport every actual original full FS term using the proved original/model
FS comparison. Divide each actual original rational class by the same integer
$r$; their real values converge to $\theta/r$. The entire original
homeomorphism preserves the actual pointwise antitone inequalities, original
nontriviality and every original infimum. Apply the genuine model FS net
criterion to these actual transported data, with no net-matching premise.
\end{proof}

\begin{theorem}[Exact full original psh comparison on the original ample ray]
\label{thm:native-ample-model-full-psh-iff}
\lean{EnvelopeProperty.NativeAmpleModelPSHComparison.isPSH_iff,EnvelopeProperty.NativeAmpleModelPSHComparison.isPSH_iff_finiteFSNetLimit}
\leanok
\uses{thm:native-ample-model-full-psh-transport,thm:native-ample-model-psh-finite-fs-net-criterion,thm:native-line-whole-section-fs-nonvanishing,thm:native-ample-model-numerical-class,def:gl-psh}
Assume throughout this statement that the original scheme $X$ is integral.
For every nonnegative real original coefficient $\theta$, independently defined
original whole-section psh is exactly genuine model psh of coefficient
$\theta/r$ under the same entire original homeomorphism. On this original ray,
full original FS decreasing nets and actual original finite rational FS
decreasing nets define the same original psh class.
\end{theorem}
\begin{proof}
The forward implication is the preceding full original net transport.
Conversely, the proved genuine model-psh criterion gives actual original
finite rational FS directed decreasing nets, with true original tensor-power
sections, original class convergence, actual antitone order, original
nontriviality, upper semicontinuity and pointwise infimum. Every such actual
finite rational FS term is a full original FS term by the genuine
whole-section nonvanishing theorem. The same net therefore satisfies the
independent full original psh definition. Combining this exact comparison
with the proved original finite FS net criterion gives their stated
equivalence on the original nonnegative ample ray.

These are actual whole original line/FS/psh comparisons under one genuine
same-scheme positive-power embedding. The scaled model coefficient has its
true intrinsic full-Euler numerical class by the separate numerical bridge.
Independence of arbitrary numerically equivalent line representatives, global
numerical finite dimensionality and the complete envelope theorem are further
mathematical obligations.
\end{proof}
