\label{lem:actual-module-homology-scalar-restriction}

native short complex of $B$-modules, actual scalar restriction preserves

commutes with the SAME native homology and cycle preservation comparisons.
No flatness, finiteness or homology-comparison premise is assumed.

mapped homology projection. Native homology-data projection coherence,
true functorial composition and BOTH original comparison inverses give
the ENTIRE projection square. The proof retains the actual native
comparisons; no unrelated abstract homology isomorphism is substituted.
\end{proof}
