\subsection{Every original normalized PL vertical center is realized by a genuine point}

\begin{theorem}[Original normalized PL models are finite and proper over any field]
\label{local:original-normalized-pl-model-proper-any-field}
\lean{EnvelopeProperty.ProjSubvariety.normalizedSimultaneousProjection_isFinite_anyField}
\lean{EnvelopeProperty.ProjSubvariety.normalizedSimultaneousStructure_isProper_anyField}
\leanok
\uses{def:actual-original-normalized-simultaneous-model,thm:actual-original-pl-simultaneous-blowup-integral}
For the SAME accepted original simultaneous PL model, finite original Gauss
ideal logarithms derive finite normalization projection and properness over
the SAME original polynomial base, over ANY original field. No perfectness or
normalization/proper-model certificate is required.
\end{theorem}
\begin{proof}
The original finite logarithms construct an original simultaneous-blowup point
and thereby derive its actual integrality. The SAME actual blowup is locally
finite type over its original coefficient field. The genuine arbitrary-field
finite normalization theorem therefore makes its SAME original normalization
projection finite. Composition with the original proper polynomial-base blowup
structure map is proper. All objects are the accepted original model and maps.
\end{proof}

\begin{theorem}[Actual dominance of the SAME normalized PL structure]
\label{local:original-normalized-pl-model-dominant}
\lean{EnvelopeProperty.ProjSubvariety.normalizedSimultaneousStructure_isDominant}
\leanok
\uses{berkovich:actual-gauss-point-dominance,def:actual-original-normalized-simultaneous-model}
For the original projectively normal variety, the SAME original normalized PL
model has a dominant original polynomial-base structure map.
\end{theorem}
\begin{proof}
The established original normal-affine normalization lift constructs an ACTUAL
original normalized Gauss point, retaining the ENTIRE prescribed coefficient
point. Its genuine positive-radius Gauss base forces dominance by the preceding
native-point theorem. Thus dominance is derived from original data.
\end{proof}

\begin{theorem}[Every original normalized-model vertical point is a TRUE model center]
\label{local:original-normalized-pl-vertical-center-realization}
\lean{EnvelopeProperty.ProjSubvariety.exists_normalizedSimultaneousGaussPoint_center}
\leanok
\uses{local:original-normalized-pl-model-proper-any-field,local:original-normalized-pl-model-dominant,berkovich:original-vertical-point-prescribed-gauss-center}
Every point of the ORIGINAL special fiber of the SAME accepted normalized PL
model is EXACTLY the TRUE valuative center of an ACTUAL original native point
over the SAME prescribed Gauss base. In particular this holds for the original
generic point of each original vertical curve. No chosen DVR, native point,
center, model-normality, perfectness or alteration is supplied.
\end{theorem}
\begin{proof}
Use the derived integrality of the SAME accepted original normalized model,
the genuine arbitrary-field properness and the derived actual dominance.
Apply the actual vertical-center point existence theorem to the ORIGINAL
polynomial-base structure and the ORIGINAL special-fiber point. It constructs
all original stalk, parameter, DVR and native normalization data internally,
and gives equality with that SAME original point as its TRUE model center.
No residual-field or analytic-branch identification is inferred from this
center equality; the curve degree bridge requires those further proofs.
\end{proof}
