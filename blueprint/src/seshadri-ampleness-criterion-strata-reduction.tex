\section{Conditional reduction from the same original integral strata}
This is a conditional general-ambient reduction. For each original point
$\eta\in X$ fix the literal reduced closure ideal
$I_\eta=\operatorname{vanishingIdeal}(\overline{\{\eta\}})$ and its actual
closed inclusion $i_\eta:Z_\eta\to X$. Assume genuine native ampleness of
the same $i_\eta^*L$ for every original point. In integral $X$ the generic
point is included, so this premise cannot prove the integral Nakai case.
The separate integral dimension induction must supply these strata results.

\begin{lemma}[Actual prime-piece twists]
\label{lem:seshadri-original-prime-piece-twist}
\lean{EnvelopeProperty.SeshadriAmplenessCriterionStrataReduction.closedPieceTwistIso}
\leanok
For an actual invertible $T$ on the same $Z_\eta$, the same original
$(i_{\eta*}T)\otimes L^m$ is canonically whole-isomorphic to
$i_{\eta*}(T\otimes(i_\eta^*L)^m)$.
\end{lemma}
\begin{proof}
Use the existing original line projection formula with line $L^m$ and
module $T$, then map the existing actual tensor-power
pullback comparison. Both functors and all modules are the original ones.
The native ample coherent Serre theorem on $Z_\eta$ gives a single bound
for every positive cohomology degree of the latter original module.
For any actual finite affine open cover of $X$, its actual preimages on
$Z_\eta$ are affine and cover it. Existing native affine Cech comparison,
actual base-scalar restriction and original closed-pushforward Cech
comparison give vanishing of the same original ambient field-complex
homology in every positive degree. No new cohomology carrier is introduced.
\end{proof}

\begin{theorem}[Original coherent twists: conditional positive vanishing]
\label{thm:seshadri-original-strata-coherent-vanishing}
\lean{EnvelopeProperty.SeshadriAmplenessCriterionStrataReduction.exists_eventual_fieldCohomology_vanishing_of_strataAmple}
\leanok
Let $p:X\to\operatorname{Spec}k$ be the original projective morphism,
with arbitrary possibly reducible or nonreduced $X$, let $F$ be the original
quasicoherent finite-type module, and assume the above ordinary strata
ampleness premise for the original invertible $L$. On every actual finite
affine cover, there is one bound after which all positive original
field-complex cohomology groups of $F\otimes L^m$ vanish.
\end{theorem}
\begin{proof}
Internally construct the already reviewed actual finite coherent prime
filtration of the same $F$. Induct on its real constructors and finite
length, with no incoming filtration certificate. The zero case follows
by the actual functor preserving zero objects. Whole-isomorphic stages
transport through the same tensor and homology functors. At an extension,
tensor the actual short exact sequence with the invertible original
$L^m$, preserving both actual maps and short exactness. The previous
stage and the actual prime quotient vanish above their internally obtained
bounds. Take their finite maximum. The actual original field-complex
long exact sequence, exact at the middle cohomology, makes that same
middle cohomology zero in every positive degree. Finite recursion gives
one final bound before all original exponents and all positive degrees.
\end{proof}

\begin{lemma}[Finite generators through actual closed pushforward]
\label{lem:seshadri-original-closed-pushforward-generators}
\lean{EnvelopeProperty.SeshadriAmplenessCriterionStrataReduction.exists_generatingSections_closedPushforward}
\leanok
An actual finite family generating a quasicoherent module on an actual
closed subscheme induces actual finite global generators of its original
whole pushforward.
\end{lemma}
\begin{proof}
Compose each original generator morphism with the actual structure quotient
$\mathcal O_X\to i_*\mathcal O_Z$. That quotient is the actual epic
closed-immersion map. Pushforward is exact on the actual quasicoherent
maps: on every original affine open, its preimage is affine and native
affine-section surjectivity applies to the original epic map. The sheaf
local surjectivity criterion gives the whole actual pushforward epimorphism.
Finite coproducts are preserved by this additive right adjoint through
their native finite-product universal property. Thus the actual free
map from the same finite index set is the composite of the finite
coproduct of the epic original structure quotient, the native coproduct
comparison, and the original pushed evaluation. It is epic. Use its
native free-hom equivalence to obtain the actual generating family.
\end{proof}

\begin{lemma}[Actual coherent extensions with lifted original generators]
\label{lem:seshadri-original-extension-global-generators}
\lean{EnvelopeProperty.SeshadriAmplenessCriterionStrataReduction.exists_generatingSections_of_shortExact}
\leanok
For an actual three-term coherent short exact sequence, finite global
generation of its left and right terms and surjectivity of its actual
original global-section quotient map imply actual finite global
generation of the middle term.
\end{lemma}
\begin{proof}
Choose lifts of the finitely many actual right generators using the
proved surjectivity of the original section map. Combine these lifts
with the images of the actual left generators into one actual free
map indexed by the disjoint union of the two finite original index sets.
Its composite with the original quotient is the actual right evaluation
on the right summand and zero on the left. If two maps out of the
middle term agree after this whole free map, their difference kills the
original left evaluation and hence the original left inclusion. Exactness
factors that difference through the original right quotient. The actual
right evaluation is epic and forces the factor to vanish, so the whole
free map is epic. The native free-hom equivalence gives actual finite
generating sections of the original middle module, not a lifting certificate.
\end{proof}

\begin{theorem}[Original coherent twists: conditional global generation]
\label{thm:seshadri-original-strata-coherent-generators}
\lean{EnvelopeProperty.SeshadriAmplenessCriterionStrataReduction.exists_eventual_generatingSections_of_strataAmple}
\leanok
Under the same ordinary strata premise, every sufficiently large
original $F\otimes L^m$ has actual finite original global generators.
\end{theorem}
\begin{proof}
Use the same internally constructed finite actual prime filtration.
The first theorem above gives eventual positive cohomology vanishing
for each prior coherent stage. The original ample coherent generation
producer on $Z_\eta$ and the actual closed-pushforward result give
eventual finite generation of each same original prime quotient twist.
Take the finite maximum at each actual extension. In particular the
left first cohomology is zero, so its actual first-cohomology map is
monic. The proved original H0 natural square and native long exact
sequence make the actual original quotient section map surjective.
Lift the finite right generators by this proved map and apply the
preceding extension lemma. Zero and whole-isomorphism cases use the
native zero/free and actual generating-section equivalences. This produces
all finite generators internally from the original data.
\end{proof}
