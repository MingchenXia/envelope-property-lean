\subsection{Actual original frame transport and native pullback composition}

\begin{lemma}[Whole original frame transport commutes with pullback composition]
\label{alggeom:actual-original-frame-pullback-composition}
\lean{AlgebraicGeometry.Scheme.Modules.frameViaFactor_pullbackComp}
\leanok
For actual scheme morphisms $i,b,f,g$ with the genuine original factorization
$ib=f$, transport of an actual unit frame through this factorization commutes
with the actual native pullback-composition isomorphisms for $g$. This is an
equality of whole original module isomorphisms.
\end{lemma}
\begin{proof}
Substitute the actual factorization. The native threefold pullback associativity
identity compares the two entire compositions of pullback-composition maps.
Cancel the first actual pullback isomorphism and the last actual inverse to
obtain the corresponding equality of frame transport maps. Expand only the
named genuine factor and frame definitions, then compose with the actual
pullback frame and structure-unit comparison. No coherence equation is data.
\end{proof}

\begin{lemma}[The actual factor comparison preserves every original whole frame]
\label{alggeom:actual-original-frame-factor-pairing}
\lean{AlgebraicGeometry.Scheme.Modules.frameFactorIso_pairing}
\leanok
For any genuine scheme factorization and any actual comparison to the same
composite pullback module, the factor comparison followed by that comparison
and the transported original frame equals the actual pullback of the original
frame, with its genuine structure-unit map.
\end{lemma}
\begin{proof}
Expand the actual original transported-frame definition. The given actual
comparison and its actual inverse cancel, as do the genuine factor comparison
and its inverse. Associativity of whole isomorphism composition leaves exactly
the true original frame pullback followed by the actual structure-unit map.
\end{proof}
