\section{The same geometric ideal module and original native closed kernel}

\begin{theorem}[The whole original ideal inclusion kills the original quotient]
\label{thm:fc-geometric-ideal-quotient-zero}
\leanok
\lean{EnvelopeProperty.GeometricIdealKernelModuleComparison.inclusion_quotient_zero}
The actual whole inclusion of the original geometric ideal module
$\mathcal I\to\mathcal O_X$ vanishes under the same original closed-subscheme
structure quotient. On every original open this follows from the true
original ideal membership condition and the actual closed-subscheme section map.
\end{theorem}

\begin{theorem}[Whole comparison retaining the literal original inclusion]
\label{thm:fc-geometric-ideal-native-kernel-module}
\leanok
\lean{EnvelopeProperty.GeometricIdealKernelModuleComparison.toModulesKernelIso, EnvelopeProperty.GeometricIdealKernelModuleComparison.toModulesKernelIso_hom_inclusion}
\uses{thm:fc-geometric-ideal-quotient-zero}
The same original geometric ideal module $I.\mathrm{toModules}$ is genuinely
isomorphic to the native kernel ideal module of its original closed immersion.
The whole comparison followed by the native kernel inclusion is exactly the
original geometric ideal inclusion. No comparison is supplied as an input.
\end{theorem}
\begin{proof}
The preceding actual whole vanishing gives the morphism into the original
native kernel by its true universal property. Conversely, any section of
that native kernel has actual included value annihilated by the original
quotient. The genuine original local ideal membership equivalence therefore
puts that same included value in the original geometric ideal module on the
same entire open. These maps preserve the original restriction maps and
scalar actions. Their composites retain the literal same original inclusions;
monicity of those genuine inclusions proves that they are whole inverses.
\end{proof}
