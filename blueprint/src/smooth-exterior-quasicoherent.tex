\section{All original smooth exterior cotangent sheaves are quasicoherent}
\label{sec:smooth-exterior-quasicoherent}

The morphism $f:X\to\operatorname{Spec}k$ is the SAME original
smooth morphism of relative dimension $n$ over a field. There
is no chosen cover, basis, quasicoherence, nonemptiness or
finiteness certificate among the hypotheses.

\begin{lemma}[The original affine chart in every exterior degree]
\label{lem:smooth-original-affine-exterior-quasicoherent}
\leanok
\lean{EnvelopeProperty.Cartier.SmoothExteriorQuasicoherent.affineChartIso}
On every actual original affine open with an actual etale
$n$-tuple, the whole restricted original exterior cotangent
sheaf in ANY degree $q$ is the associated sheaf of the SAME
original exterior K\"ahler module of its original coordinate ring.
\end{lemma}
\begin{proof}
The genuine native open-immersion exterior sheaf comparison
identifies the restriction with the actual exterior sheaf of
the original affine structural map. Its structural equality
retains the algebra action given by the SAME original $f$.
The actual etale tuple supplies its differential basis, and
the already proved principal-open localization construction
identifies the original exterior sheaf with the associated
sheaf of that SAME exterior module, in every degree.
\end{proof}

\begin{theorem}[Actual global quasicoherence in every degree]
\label{thm:smooth-original-exterior-quasicoherent}
\leanok
\lean{EnvelopeProperty.Cartier.SmoothExteriorQuasicoherent.exterior_isQuasicoherent,EnvelopeProperty.Cartier.SmoothExteriorQuasicoherent.frobeniusForm_isQuasicoherent}
Every original exterior cotangent sheaf of $f$ is quasicoherent.
In prime characteristic $p$, its SAME actual Frobenius scalar
restriction is quasicoherent as well. Empty schemes and zero
coordinate rings are included.
\uses{lem:smooth-original-affine-exterior-quasicoherent,thm:cartier-smooth-original-etale-affine-cover}
\end{theorem}
\begin{proof}
The original smooth geometry internally supplies an actual
cover by affine opens with genuine etale tuples. On each such
open the preceding isomorphism proves quasicoherence of the
original restriction, since actual associated sheaves are
quasicoherent. The native scheme isomorphism from that affine
open to its spectrum and the actual over-site equivalence
transfer this to the SAME module on the over-site. The native
cover-local quasicoherence criterion then proves the result
on the original whole scheme, with no selected-cover premise.
The actual absolute Frobenius has the original identity point
map, so the inverse image of each original affine open is
that SAME affine open: it is an affine morphism. Native affine
pushforward preserves quasicoherence. The already proved
whole functor identity between actual Frobenius pushforward
and actual Frobenius scalar restriction gives the final claim.
\end{proof}

This supplies genuine geometric quasicoherence for comparing
native affine sections and native sheaf cohomology. It does
not assert Cartier descent, Deligne--Illusie or vanishing.
