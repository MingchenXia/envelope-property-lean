\section{The actual finite Segre homogeneous coordinates retain the entire original function field}
\label{sec:finite-segre-native-coordinate-algebra}
\begin{theorem}[Every actual finite Segre coordinate is the original factor product]
\label{thm:finite-segre-native-coordinate-product}
\lean{EnvelopeProperty.FiniteSegreNativeCoordinateAlgebra.factorCoordinate,EnvelopeProperty.FiniteSegreNativeCoordinateAlgebra.factorCoordinate_self,EnvelopeProperty.FiniteSegreNativeCoordinateAlgebra.chart_nonempty,EnvelopeProperty.FiniteSegreNativeCoordinateAlgebra.coordinate_product}
\leanok
\uses{def:finite-original-segre-morphism,thm:segre-native-coordinate-product}
Let $X$ be integral and let the finite original projective family have its
same original base triangle. Choose for each factor an actual nonempty
inverse-image coordinate chart. The original generic point lies in all
these actual charts. The corresponding product-pivot chart of the genuine
finite Segre morphism is nonempty, and every actual Segre coordinate
ratio in the entire original $K(X)$ is exactly the product of the same
original factor-coordinate ratios. Each original factor pivot has value one.
\end{theorem}
\begin{proof}
For one factor these statements are the original chart condition and the
original pivot identity. For a larger family separate the first factor
and the remaining family. The binary generic-coordinate theorem applied
to the first factor and the recursively constructed tail chart gives
nonemptiness of the actual product chart and identifies each Segre ratio
with the first factor ratio times its tail ratio. The recursive identity
identifies the tail ratio with the product of all original tail ratios.
The product over a finite family is precisely the first factor times
this tail product. All values are taken in the same actual original
generic stalk $K(X)$, so no field or coordinate identification is supplied.
\end{proof}
\begin{theorem}[The actual homogeneous coordinate algebra has exactly the original product generators]
\label{thm:finite-segre-native-coordinate-algebra}
\lean{EnvelopeProperty.FiniteSegreNativeCoordinateAlgebra.fullFieldModel_S}
\leanok
\uses{thm:finite-segre-native-coordinate-product,thm:finite-original-segre-whole-line,thm:projective-chart-whole-native-field-model}
If the first original factor is a closed immersion, take the actual
one-block homogeneous model constructed from the genuine finite Segre
embedding and its product pivot, over the entire same original $K(X)$.
Its homogeneous algebra is exactly the $k$-algebra generated by
\[
 U\prod_jq_j^*(X_{j,a_j}/X_{j,i_j})
\]
for every original coordinate tuple $(a_j)_j$. The actual whole original
base triangle fixes the coefficient action. This identifies the entire
algebra, not merely the field generated by its coordinate ratios.
\end{theorem}
\begin{proof}
The actual finite Segre morphism is a closed immersion and its constructed
pivot chart is nonempty. Thus the original homogeneous-model producer
constructs its actual whole-function-field model. By construction its
algebra is generated by $U$ times each actual target coordinate ratio.
The genuine finite Segre index is a bijection from all tuples of original
factor coordinates to all target coordinates. The preceding theorem
therefore identifies this entire set of generators with the displayed
set, in both directions. Equality of the generator sets gives equality
of their generated $k$-subalgebras. The whole original morphism base
triangle is unchanged throughout this construction.
\end{proof}
The positive diagonal algebra of the actual multigraded family model must
still be identified with this same algebra before the full simultaneous
model comparison follows. Whole projective numerical-class finite
