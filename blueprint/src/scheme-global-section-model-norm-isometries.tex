\begin{theorem}[Every original global section retains its true norm under an actual line isomorphism]
\label{thm:scheme-global-section-model-norm-isometry}
\lean{EnvelopeProperty.SchemeGlobalSectionModelNormIsometries.globalSectionNorm,EnvelopeProperty.SchemeGlobalSectionModelNormIsometries.fibreSection_comp,EnvelopeProperty.SchemeGlobalSectionModelNormIsometries.globalSectionNorm_moduleIso}
\leanok
\uses{thm:actual-module-iso-global-sections,lem:scheme-original-global-section-hom,lem:fc-original-line-section-fibre,lem:scheme-line-actual-model-isomorphism-isometry}
\source{bj22-trivval:sec:tc}
On an actual original proper model over a prescribed bounded base valuation,
every genuine original isomorphism between invertible modules preserves the
true model norm of every entire original global section. Its section map is
exactly the original whole global-section isomorphism; the fibre section is
that of the same original section-unit morphism. No affine, quasicoherent,
section-lifting, frame-matching or metric-comparison hypothesis is required.
\end{theorem}
\begin{proof}
The original global-section/unit-morphism equivalence commutes with the
actual original module morphism. Pullback of that composition to the actual
residue-field fibre is the composition of the actual pulled morphisms, with
the same original structure-unit comparison. Evaluating at the original unit
therefore identifies the fibre section of the mapped original global section
with the actual pulled module morphism applied to the original fibre section.
The genuine native model-line isomorphism isometry applies to this exact
original fibre section, proving the true norm equality on every original
global section.
\end{proof}

\begin{theorem}[Every actual finite weighted family retains its entire original evaluation]
\label{thm:scheme-global-section-weighted-norm-isometry}
\lean{EnvelopeProperty.SchemeGlobalSectionModelNormIsometries.weightedNormEval,EnvelopeProperty.SchemeGlobalSectionModelNormIsometries.weightedNormEval_moduleIso}
\leanok
\uses{thm:scheme-global-section-model-norm-isometry}
\source{fhx-envelope-20261028:eq:FS-function}
For every finite weighted family of actual entire original global sections,
the genuine whole original module isomorphism and unchanged real weights
retain the entire weighted logarithmic model-norm evaluation, with the same
original denominator, at every actual original native point. Empty families,
zero sections and zero norms are included.
\end{theorem}
\begin{proof}
Take the actual finite image under the original whole global-section
isomorphism, retaining each original weight. The preceding true norm equality
identifies every logarithmic term, including negative infinity at zero.
The finite supremum is unchanged on taking this image. Multiplication by the
same original reciprocal denominator gives exactly the entire weighted
function identity; no finite-family comparison premise is supplied.
\end{proof}
