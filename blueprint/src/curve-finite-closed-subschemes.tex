\section{True finiteness of original proper-support curve subschemes}

\begin{theorem}[The actual original nongeneric curve points and closed support]
\label{thm:fc-curve-proper-support-points}
\leanok
\lean{EnvelopeProperty.CurveFiniteClosedSubschemes.coheight_eq_one, EnvelopeProperty.CurveFiniteClosedSubschemes.isClosed_singleton, EnvelopeProperty.CurveFiniteClosedSubschemes.genericPoint_not_mem, EnvelopeProperty.CurveFiniteClosedSubschemes.t1_subscheme}
Every nongeneric original point of an integral scheme of dimension at most
one has codimension one and is genuinely closed. A genuine proper closed
subset excludes the original generic point; hence any original ideal with
proper support has a true T1 original closed subscheme.
\end{theorem}
\begin{proof}
Actual topological Krull dimension bounds actual point coheight. The original
generic point is the greatest point, so a distinct point has positive
coheight and therefore coheight one. A further strict specialization would
force coheight at least two, so the point is closed. The actual original
generic point is dense, giving its exclusion from every proper closed set.
Pull back the actual closed singletons along the original closed immersion.
\end{proof}

\begin{theorem}[Actual proper integral curve geometry derives a finite closed morphism]
\label{thm:fc-curve-finite-closed-subschemes}
\leanok
\lean{EnvelopeProperty.CurveFiniteClosedSubschemes.finite_subscheme, EnvelopeProperty.CurveFiniteClosedSubschemes.subscheme_comp_isFinite}
\uses{thm:fc-curve-proper-support-points}
On an actual Noetherian integral curve, every original proper-support closed
subscheme has finitely many actual original points. For an actual original
proper integral curve over the original arbitrary field, the SAME original
closed-subscheme structure morphism is genuinely finite. No finite-divisor,
normality, smoothness, projectivity or local-equation premise is needed.
\end{theorem}
\begin{proof}
The true T1 scheme has topological dimension at most zero. Its actual local
Noetherian property therefore makes it locally Artinian and discrete. Its
same actual closed support is compact, so its original point set is finite.
For the actual proper original structure morphism, local Noetherianity
follows from actual finite type over the original field and compactness from
actual quasi-compactness over the original affine field spectrum. Thus the
actual closed source is finite as a point set. The original finite-type
closed structure composite is consequently locally quasi-finite. It is
proper as the actual composite of the original closed immersion and proper
structure morphism; native proper-plus-quasi-finite finiteness proves the
claim on this SAME original morphism.
\end{proof}
