\subsection{Original local convexity on the whole actual scheme and its genuine pullbacks}

\begin{definition}[The original native form locus and section weight]
\label{projective:actual-original-native-admissible-weight}
\lean{EnvelopeProperty.ProjSubvariety.nativeAdmissibleAnalyticLocus,EnvelopeProperty.ProjSubvariety.nativeAdmissibleWeight}
\leanok
\uses{projective:actual-original-admissible-chart-convexity}
On the actual original native scheme, let the analytic form locus be the
points whose original support belongs to the original homogeneous open
$D(F)$. For a native point corresponding to the original analytic point $w$,
define the original weight by $\varphi(w)-m^{-1}\log|F(w)|$.
\end{definition}
\begin{proof}
Use the actual original closed projective inclusion to define $D(F)$ and
the inverse whole original analytic/native homeomorphism to define $w$.
The formula uses the same original homogeneous polynomial and normalized value.
\end{proof}

\begin{lemma}[The original analytic and native form opens agree]
\label{projective:actual-original-native-form-open}
\lean{EnvelopeProperty.ProjSubvariety.nativeAnalyticHomeomorph_mem_nativeAdmissibleOpen}
\leanok
\uses{projective:actual-original-native-admissible-weight}
For every original analytic point $w$ and every original polynomial $F$,
its actual native point lies in this original native open if and only if
$|F(w)|\ne0$. No homogeneous-degree or normality premise is required here.
\end{lemma}
\begin{proof}
The whole original analytic/native homeomorphism commutes with the original
closed inclusion. The native ambient support is the original seminorm kernel,
so membership in the genuine homogeneous basic open is exactly nonvanishing.
\end{proof}

\begin{lemma}[The whole actual form locus is the genuine chart image]
\label{projective:actual-original-native-chart-range}
\lean{EnvelopeProperty.ProjSubvariety.nativeAdmissibleAnalyticLocus_eq_range}
\leanok
\uses{projective:actual-original-admissible-chart-scheme-iso,projective:actual-original-native-admissible-weight}
For an original homogeneous $F\notin I_X$ of positive degree, this entire
original native analytic locus is exactly the image of the actual original
affine chart map on prescribed-base native points.
\end{lemma}
\begin{proof}
The actual original chart map is an open immersion with precisely the original
scheme open $D(F)$ as range. The genuine open-immersion native-point theorem
identifies its full prescribed-base image with points supported in that range.
Substitute the proven literal original range equality.
\end{proof}

\begin{lemma}[Original chart convexity descends to the whole native open]
\label{projective:actual-original-native-admissible-convexity}
\lean{EnvelopeProperty.ProjSubvariety.nativeAdmissibleWeight_isConvexPLOn}
\leanok
\uses{projective:actual-original-admissible-chart-convexity,projective:actual-original-native-chart-range}
Original admissible coefficient-chart convexity implies actual regular-unit
convexity of the same original weight on the entire original native form locus.
\end{lemma}
\begin{proof}
Apply actual open-immersion descent of intrinsic regular-unit presentations to
the genuine original chart map. The preceding exact image equality verifies
the descent domain; its full inverse image is the whole affine point space.
The actual original weight composed with that map is definitionally the actual
chart weight, whose regular-unit convexity was already proved. Descent uses
actual inverse section-ring maps, so the descended units are genuine original
regular units on genuine original scheme opens.
\end{proof}

\begin{theorem}[Every actual compatible scheme map preserves the original convex weight]
\label{projective:actual-original-native-prescribed-convexity-pullback}
\lean{EnvelopeProperty.ProjSubvariety.IsLocallyConvexAll.nativeAdmissibleWeight_comp_mapOverBase}
\leanok

original $X$ preserve the whole coefficient-base square. The original
admissible weight pulls back to an intrinsic regular-unit convex PL function

\end{theorem}
\begin{proof}
Apply genuine regular-unit convexity pullback through the actual compatible
native-point map to the preceding theorem. The pullback uses the actual scheme
section homomorphisms on inverse-image original opens. Whole point and section
naturality preserve every rational logarithmic term and finite maximum, with
no affine, smoothness, nefness, or slope-preservation hypothesis.
\end{proof}
