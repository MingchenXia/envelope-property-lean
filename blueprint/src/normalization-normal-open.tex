\section{Whole normalization isomorphisms on original normal opens}

\begin{theorem}[Actual original normalization over an arbitrary normal open]
\label{thm:actual-normalization-isomorphism-normal-open}
\lean{EnvelopeProperty.IntegralSchemeNormalization.projection_isIso_on_normal_open}
\leanok
\uses{lem:actual-normalization-affine-isomorphism}
For an original integral scheme $Z$, its same actual original normalization
is a whole isomorphism over every original open $W$ whose actual original
stalks are integrally closed. The open may be empty, and finite normalization
is not an additional premise.
\end{theorem}
\begin{proof}
Use the canonical cover of the actual open scheme $W$ by all its original
nonempty affine opens. Each such open has a genuine affine image in the
original scheme $Z$, contained in the same original $W$. It is nonempty and
its original stalks are normal, so the proved actual affine-normalization
theorem makes the original normalization an isomorphism over that entire
original affine image. The native whole arrow isomorphism identifying a
restriction performed twice with the restriction to this image transfers
that isomorphism to the corresponding chart of the normalization restricted
over $W$. Isomorphism is target-local on the actual Zariski cover, so these
true whole affine isomorphisms prove the asserted whole isomorphism over $W$.
\end{proof}
