\section{Whole original factorization descends from the actual original open cover}
\label{sec:scheme-module-open-cover-factorization}

\begin{theorem}[Factorization through the same original monomorphism]
\label{sc0-scheme-module-open-cover-factorization:whole-map}
\lean{EnvelopeProperty.SchemeModuleOpenCoverDetection.factorization_iff}
\leanok
For actual original open immersions $j_i:Y_i\to X$ covering EVERY original
point, ANY original map $\delta:A\to B$ factors through an original
monomorphism $I\to B$ if and only if EVERY actual native pullback of
$\delta$ factors through the pullback of that SAME original monomorphism.
All module sheaves are arbitrary. No affine, quasicoherent, flatness,
exactness, chosen local-lift compatibility or gluing certificate is assumed.
\end{theorem}
\begin{proof}
A true global factorization pulls back by the actual native functors,
which preserve the original composition. Conversely form the SAME actual
native cokernel of the original inclusion. Each actual local factorization
kills its pulled cokernel composite, by genuine functorial composition and
the actual original cokernel relation. The proved true
open-cover detection theorem then forces the ENTIRE original cokernel
composite to be zero. In the actual abelian category of original module
sheaves, the original monomorphism followed by its true cokernel is exact.
Native exactness therefore supplies the actual whole original lift of
$\delta$, proving the claimed global factorization. The original monomorphism makes the resulting global lift unique; no
compatibility of the supplied local lifts is required as an extra assumption. It needs no exactness assumption
on the pullback functors themselves.
\end{proof}
