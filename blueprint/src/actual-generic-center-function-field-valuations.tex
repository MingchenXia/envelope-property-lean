\subsection{The original whole function-field valuation at an actual model center}

\begin{lemma}[Whole original generic-support native points retain their native field valuation]
\label{lem:actual-generic-native-field-valuations}
\uses{lem:actual-generic-residue-field-equivalence}
\lean{EnvelopeProperty.Berkovich.SchemeValuedPoint.eq_of_genericValuation_eq}
\leanok
The actual residue valuation of ANY original native point with its SAME
original generic support pulls back through the genuine generic-residue
field equivalence to a valuation of the SAME original native function field.
It retains EVERY original section value, and determines the WHOLE original
native point uniquely.
\end{lemma}
\begin{proof}
Pull back the original residue valuation through the actual generic-residue
field equivalence. The whole-section formula of that equivalence identifies
the value of EVERY original generic germ with the original native section
evaluation. The equivalence is surjective onto the ENTIRE original residue
field, so equality of the field valuations gives equality of the whole
residue valuations and therefore of the actual native points.
\end{proof}

\begin{lemma}[The actual center gives one unique positive scale on the original native function field]
\label{lem:actual-generic-center-native-field-scale}
\uses{lem:actual-generic-center-unique-dvr-scale,lem:actual-dvr-fraction-valuation-transport,lem:actual-generic-native-field-valuations}
\lean{EnvelopeProperty.Berkovich.RelativeSchemeValuedPoint.existsUnique_curveCenter_functionField_realScale}
\leanok
For a SAME actual generic-support native point on an original integral proper
bounded-base model whose genuine center stalk is a DVR, its ENTIRE original
native function-field valuation is the true original center DVR valuation
scaled at one unique positive parameter. On a normal locally Noetherian
original curve of dimension at most one, a nongeneric actual center derives
the SAME DVR internally.
\end{lemma}
\begin{proof}
The actual center theorem gives the whole original residue valuation as the
unique positive scale of its original local DVR valuation. Pull it back
through the SAME native generic-residue equivalence. The actual whole center
coefficient square and genuine fraction-field naturality identify the native
DVR valuation with the one on the SAME original function field, on EVERY
original fraction. The native real scale commutes pointwise with this actual
pullback. Original uniformizer evaluation makes the parameter unique. The
normal-curve assertion derives the actual center DVR before applying this
whole-field result.
\end{proof}

\begin{lemma}[Every original rational function has its true native order logarithm]
\label{lem:actual-generic-curve-center-order-logarithm}
\uses{lem:actual-generic-center-native-field-scale}
\lean{EnvelopeProperty.Berkovich.RelativeSchemeValuedPoint.exists_positive_genericCurveCenter_log}
\leanok
For that SAME native point with its actual nongeneric center on the original
normal curve, a single internally derived $s>0$ satisfies
\[
 \log |a|_y=-s\,\operatorname{ord}_{c(y)}(a)
\]
for EVERY original nonzero rational function $a$ in its SAME native function
field. The original function, actual center and native order are retained;
no order or valuation-preservation certificate is supplied.
\end{lemma}
\begin{proof}
The genuine original center DVR valuation of every nonzero original rational
function is the integer exponential of its negative native original order.
The actual real scale has logarithm equal to $s$ times that SAME integer.
Substitution in the whole-field equality just proved gives the formula for
EVERY original rational function with its original sign.
\end{proof}
