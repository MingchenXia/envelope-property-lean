\section{Actual original line sections, local frames and norms under scheme pullback}

\begin{lemma}[Original section pullback and genuine local frames]
\label{lem:fc-original-section-pullback-frame}
\leanok
\lean{EnvelopeProperty.SchemeLineSectionEvaluation.pullbackSectionHom_comp, EnvelopeProperty.SchemeLineSectionEvaluation.localPullbackFrame}
\uses{lem:fc-original-line-section-frame-naturality}
Actual pullback of the SAME original whole structure-line section morphism
commutes with genuine composition of original scheme maps.  An original
local frame pulls back to a genuine frame of the actual original pulled-back
line on the SAME actual inverse-image open.
\end{lemma}
\begin{proof}
The actual native pullback-composition isomorphism is natural in the
original section morphism.  The original composition identity for its
structure-unit comparison identifies the original source-unit morphism.
This gives the whole original section-composition identity.  Compose the
actual inverse-image-open pullback-composition isomorphism with the actual
frame transported through the original restricted-scheme triangle; this
constructs the true local frame on the actual pulled-back original line.
\end{proof}

\begin{lemma}[The original whole scalar equation survives actual pullback]

All identities are identities of whole original module morphisms.
\end{proof}

\begin{theorem}[Actual original pulled-back section norm from its original local coefficient]
\label{thm:fc-original-section-pullback-model-norm}
\leanok
\lean{EnvelopeProperty.Berkovich.RelativeSchemeValuedPoint.modelLineNorm_pullbackSection_eq_localEval}
\uses{lem:fc-original-section-pullback-scalar,thm:fc-original-local-section-model-norm}
On the actual proper source model, the model norm of the SAME pulled-back
original global line section is the original source valued-point evaluation
of its SAME pulled-back original local coefficient, whenever the actual
center lies in this original inverse-image open.  No properness of the
intervening morphism and no flatness hypothesis are required.
\end{theorem}
\begin{proof}
Actual original invertibility is preserved by native pullback.  Use the
true local frame on the actual inverse-image open and the preceding whole
scalar identity.  The original local-section norm theorem then computes
the actual proper-model norm as the original evaluation of exactly that
pulled-back local section.
\end{proof}
