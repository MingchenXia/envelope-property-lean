\section{The original line operations in the actual real Picard space}
\label{sec:native-real-picard-operations}

\begin{theorem}[Actual tensor, dual, and line-isomorphism operations]
\label{thm:native-real-picard-operations}
\lean{EnvelopeProperty.NativeRealPicard.picardClass_one, EnvelopeProperty.NativeRealPicard.picardClass_mul, EnvelopeProperty.NativeRealPicard.picardClass_inv, EnvelopeProperty.NativeRealPicard.lineClass_eq_of_iso, EnvelopeProperty.NativeRealPicard.lineClass_unit, EnvelopeProperty.NativeRealPicard.lineClass_tensor, EnvelopeProperty.NativeRealPicard.lineClass_dual, EnvelopeProperty.NativeRealPicard.lineClass_quotient}
\leanok
\uses{thm:native-real-picard, lem:fc-original-line-picard-tensor-dual}

In the real scalar extension of the same original native Picard
group, whole original invertible-line isomorphisms preserve classes,
the original unit line has class zero, actual original tensor
products give sums, and actual original duals give negatives.
In particular an actual original whole quotient isomorphism
$L\simeq M\otimes T^\vee$ gives exactly
$[L]_{\mathbf R}=[M]_{\mathbf R}-[T]_{\mathbf R}$.
No tensor/dual/numerical comparison certificate is supplied.
\end{theorem}

\begin{proof}
The canonical original Picard map is $a\mapsto1\otimes a$ in
the actual tensor product of the associated additive group.
Thus the original group unit, multiplication, and inverse map
to zero, addition, and negation by the three genuine tensor
identities. Whole original line isomorphisms already preserve
their same native original Picard classes. The original line
tensor product and the actual dual, with its actual evaluation,
represent exactly native multiplication and inverse by the
proved original line/Picard comparison. Composing these true
native identities with the same tensor map gives all the
asserted original real line identities. The actual original
quotient formula follows from the given whole original line
isomorphism, the tensor identity and the dual identity. The
invertibility of each actual tensor target is derived from
those of its actual two factors.
\end{proof}
