\begin{theorem}[Whole original semilinear exterior left multiplication]
\label{lem:cartier-exterior-semilinear-left-wedge}
\lean{EnvelopeProperty.Cartier.ExteriorBasisScalarExtension.leftWedge_ιMulti,EnvelopeProperty.Cartier.ExteriorBasisScalarExtension.exteriorSemilinearMap_leftWedge}
\leanok
For ANY actual original ring map $A\to B$ and ANY actual semilinear map
$\varphi:M\to N$, its true universal exterior map commutes with original
left exterior multiplication on EVERY original homogeneous form.
\end{theorem}
\begin{proof}
The original left product of a vector with a decomposable wedge is exactly
the original cons wedge, by the actual exterior algebra multiplication.
The genuine universal semilinear exterior map preserves each such original
wedge. This proves the left-product formula on the actual decomposable
generators. They span the ENTIRE original exterior module. Genuine span
induction, additivity and the original semilinear scalar identity extend it
to every original form, without a spanning or multiplicativity premise.
\end{proof}

\begin{theorem}[Every original wedge and genuine scalar extension]
\label{lem:cartier-exterior-basis-scalar-extension}
\lean{EnvelopeProperty.Cartier.ExteriorBasisScalarExtension.exteriorLinearEquiv_basis,EnvelopeProperty.Cartier.ExteriorBasisScalarExtension.exteriorEquiv_eq,EnvelopeProperty.Cartier.ExteriorBasisScalarExtension.exteriorEquiv_wedge}
\leanok
For actual original bases $b$ of an $A$-module $M$ and $c$ of a $B$-module
$N$ with the same ordered index set, and the actual coefficient map $A\to B$,
the actual exterior-basis scalar-extension comparison is the composition of
the genuine native exterior scalar-extension comparison and the actual
exterior map of the SAME degree-one basis isomorphism.
Consequently EVERY original decomposable wedge
$1\otimes(m_1\wedge\cdots\wedge m_q)$ maps to the wedge of the SAME actual
scalar-extended original vectors, without a basis-wedge or matching premise.
\end{theorem}
\begin{proof}
The actual exterior map of a genuine basis isomorphism preserves every
original wedge by the actual exterior universal property. In particular it
sends every original exterior basis vector to its SAME target basis vector.
The actual scalar-extension basis spans the entire original source module,
so these genuine basis values identify the two ENTIRE linear isomorphisms.
The already proved native scalar-extension wedge formula and the actual
exterior-map universal formula then give the assertion on EVERY original
wedge. No inverse, determinant or compatibility certificate is supplied.
\end{proof}

\begin{theorem}[Whole original basis comparison is canonical on wedges]
\label{lem:cartier-exterior-basis-universal-map}

The actual coefficient-one basis scalar-extension map on EVERY exterior
power equals the true universal exterior semilinear map of its SAME original
degree-one comparison. It therefore preserves actual left exterior
multiplication on EVERY original form.
\end{theorem}
\begin{proof}
The native tensor relation proves that the genuine coefficient-one tensor
map followed by any actual scalar-extended linear map is semilinear for the
SAME original ring map. The degree-one basis comparison sends every
original basis vector to its actual target basis vector.
The preceding full wedge formula identifies the two actual exterior maps
on every original decomposable generator. Genuine original span induction,
additivity and semilinearity identify the ENTIRE original maps. Substituting
this actual equality into the preceding universal left-product theorem
gives the whole original left-product comparison, with no matching premise.
\uses{lem:cartier-exterior-basis-scalar-extension,lem:cartier-exterior-semilinear-left-wedge}
\end{proof}

This is an actual general module/exterior comparison used to compare the
original etale differential with intrinsic wedge operations. It does not
assert coordinate independence of the differential, canonical Cartier sheaf
descent, Deligne--Illusie splitting or vanishing.
