\section{Same original finite-fibre weighted native order sums}

\begin{theorem}[Original fibre points are genuinely nongeneric]
\label{thm:fc-original-nonzero-prime-fibre-nongeneric}
\leanok
\lean{EnvelopeProperty.AtPrimeInverseRegularOrderSums.fibre_ne_generic}
For the actual original finite dominant integral curve over the original
domain, every original point over an original nonzero prime is nongeneric
on the original curve.
\end{theorem}
\begin{proof}
The original dominant map takes the original generic point to the original
base generic point, whose actual prime is zero.  Thus such a point cannot
lie in the same original nonzero-prime fibre.  No point correspondence is
assumed.
\end{proof}

\begin{theorem}[All original finite-fibre weighted section orders]
\label{thm:fc-original-fibre-native-order-local-inverse-sum}
\leanok
\lean{EnvelopeProperty.AtPrimeInverseRegularOrderSums.finsum_fibre_eq_localInverse}
Over the original Noetherian domain, the true weighted native order sum of
any original nonzero global regular section over all points of the same
original nonzero-prime fibre equals its actual pullback's true weighted
native order sum over every point of the entire same original local inverse.
The original field structure pulls back by the literal original projection.
\uses{thm:fc-original-nonzero-prime-fibre-nongeneric,thm:fc-at-prime-original-fibre-point-equiv,thm:fc-localized-inverse-native-stalks-residues,thm:fc-native-weighted-regular-section-transport}
\end{theorem}
\begin{proof}
Actual finite geometry derives local Noetherianity of the original source;
the original target localization and actual finite inverse derive it on
the same local inverse.  Reindex by the genuine whole original fibre--point
bijection, whose map is the literal original first projection.  The actual
native projection stalk isomorphism, actual original residue coefficient
map, native original section germ and internally proved nonzero pullback
identify each weighted order.  The actual original generic point term is
zero, so the whole inverse sum is the same nongeneric sum.  No fibre, stalk,
residue, order, nonzero pullback or sum matching certificate is supplied.
\end{proof}
