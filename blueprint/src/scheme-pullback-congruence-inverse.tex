\begin{lemma}[The original pullback congruence for the reverse equality]
\label{lem:scheme-pullback-congruence-reverse-hom}
\lean{EnvelopeProperty.SchemePullbackCongrInverse.reverse_hom}
\leanok
For the same two scheme maps, equality, and module, pullback along the reverse
equality has exactly the inverse map of the original pullback congruence.
\end{lemma}
\begin{proof}
Eliminate the equality of scheme maps. Both original congruences then become
the identity isomorphism, so the assertion is reflexivity.
\end{proof}
