\subsection{Actual original quotient numerators in the native admissible chart}

\begin{lemma}[Exact original fraction identity under the whole chart comparison]
\label{projective:actual-admissible-native-quotient-fractions}
\lean{EnvelopeProperty.ProjSubvariety.quotChartNativeAwayEquiv_quotChartMk_mul}
\leanok
\uses{projective:actual-original-admissible-chart-scheme-iso}
Let $F$ be any original homogeneous form of degree $d$ nonzero modulo
the ORIGINAL ideal, $m\in\mathbb N$, and $G$ ANY original polynomial.
Under the WHOLE original quotient-chart/native-away equivalence, the
SAME original quotient-chart element $\operatorname{quotChartMk}(m,G)$
retains the literal actual quotient-localization fraction: its actual
ordinary localized value multiplied by the original quotient image of
$F^m$ equals the localized image of the ORIGINAL homogeneous component
$G_{md}$. No homogeneous restriction on $G$, positivity of $d$ or
supplied fraction-preservation premise is imposed.
\end{lemma}
\begin{proof}
Use the actual canonical original quotient-localization algebra map.
It kills precisely the original ideal, and the original quotient image
of $F$ is a genuine unit in its true localization. The whole quotient
chart equivalence was constructed from this literal quotient-chart lift
and the injective actual native homogeneous-away embedding into the
same original ordinary localization. Unfold that actual construction
and apply the proven whole quotient-chart-equivalence compatibility to
identify the original native-away value with its SAME quotient-chart
lift. The original quotient-chart numerator formula for that genuine
lift, multiplied by the actual original denominator power, is exactly
the localized original homogeneous component $G_{md}$. This proves the
literal original ring equality, rather than an identity only after
applying selected seminorms or taking ideals.
\end{proof}

\begin{corollary}[The whole SAME homogeneous numerator is the SAME native fraction]
\label{projective:actual-admissible-native-homogeneous-fraction}
\lean{EnvelopeProperty.ProjSubvariety.quotChartNativeAwayEquiv_quotChartMk}
\leanok
\uses{projective:actual-admissible-native-quotient-fractions}
If the ORIGINAL $G$ is homogeneous of degree $md$, its entire original
quotient-chart element maps to EXACTLY the genuine native homogeneous
quotient-away fraction with numerator the ORIGINAL quotient image of
$G$ and denominator the ORIGINAL quotient image of $F^m$. This is an
equality of WHOLE ring elements, not merely values under chosen points.
\end{corollary}
\begin{proof}
Apply injectivity of the actual homogeneous-away embedding into the
SAME ordinary quotient localization. Multiply both original embedded
elements by the genuine unit given by the original quotient image of
$F^m$. The preceding exact original numerator identity gives the
localized image of $G$ on the first side because its original homogeneous
component is itself. The actual localization fraction specification gives
the SAME localized numerator on the second side. Cancel the actual unit.
No domain replacement or weakened equality is used.
\end{proof}
