\subsection{The actual generic graph comparison retains the ORIGINAL coefficient action}

\begin{theorem}[Every original generic coefficient is retained]
\label{scheme:generic-field-original-coefficients}
\lean{EnvelopeProperty.SchemeGenericFieldCoefficients.fieldHom_coefficients}
\leanok
\uses{scheme:generic-field-point-hom-diagram}
Let $Y$ be an actual integral scheme, $g:\operatorname{Spec}K\to Y$
an actual dominant field point and $f:Y\to\operatorname{Spec}R$ an
actual whole structure morphism. If the original coefficient triangle is
$g\circ f=\operatorname{Spec}(\alpha)$, then the actual native generic
coefficient map $k(Y)\to K$ composed with the SAME actual stalk coefficient
map $R\to k(Y)$ equals the SAME original $\alpha$ on EVERY element.
\end{theorem}
\begin{proof}
The genuine native generic-stalk structure triangle identifies the spectrum
of the actual $R\to k(Y)$ map with the native generic morphism followed by
$f$. Compose with the spectrum of the true $k(Y)\to K$ field-point
coefficient map. Its proved whole generic diagram turns this into the SAME
original $g\circ f$, hence the SAME $\operatorname{Spec}(\alpha)$.
Faithfulness of native $\operatorname{Spec}$ proves equality of the entire
original coefficient ring maps, not only selected parameter values.
\end{proof}

\begin{definition}[The genuine generic-graph field isomorphism preserves actual base fields]
\label{scheme:generic-graph-original-coefficient-algequiv}
\lean{EnvelopeProperty.SchemeGenericFieldCoefficients.functionFieldAlgEquiv}
\leanok
\uses{scheme:generic-field-original-coefficients,scheme:generic-graph-original-function-field}
If the SAME actual generic graph has original projection to an actual
integral $X$ with its original generic triangle, and the SAME original
coefficient triangle over a field $F$ agrees with the actual $F$-action on
$k(X)$, its true native function-field comparison is an actual
$F$-algebra isomorphism. Its source uses the SAME original structure-map
stalk algebra, and its target the SAME original action on $k(X)$.
\end{definition}
\begin{proof}
Use the proved actual native generic-graph ring isomorphism. The preceding
whole coefficient theorem, applied to the actual original structure
morphism, proves its scalar-commutation field on EVERY actual $F$ element.
Thus the source and target actions are retained literally rather than
replaced by an independently supplied coefficient comparison.
\end{proof}
