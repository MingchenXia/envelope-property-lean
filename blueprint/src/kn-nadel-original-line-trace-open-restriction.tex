\begin{lemma}[The exact original line trace under native open restriction]
\label{lem:kn-original-line-trace-native-open-restriction}
\lean{EnvelopeProperty.Vanishing.NadelGlobalCanonicalTrace.originalLineTrace_nativeOpenRestriction}
\uses{lem:kn-original-line-trace-native-square,lem:kn-nadel-native-open-module-square,lem:adjunction-square-from-unit-equation}
\leanok
For an actual open cartesian square, the exact original inverse-PF line trace
restricts to the same native whole-module base-change comparison, followed by
the original open restriction-to-pullback comparison, the native composite
pullback comparison, and the chart's original pulled-line trace.
\end{lemma}
\begin{proof}
The original native line square is supplied by the structure-trace square.
Apply the same open restriction adjunction. The canonical comparison between
open restriction and pullback has precisely the original pullback unit as its
adjoint. The original module-square restriction theorem identifies the remaining
adjoint with native whole-module base change. Composition gives the result.
\end{proof}
