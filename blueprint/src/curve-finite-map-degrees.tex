\begin{theorem}[True line degree scaling for the same finite flat curve map]
\label{thm:fc-curve-finite-flat-line-degree}
\leanok
\lean{EnvelopeProperty.CurveFiniteMapDegrees.degree_comap_toModules, EnvelopeProperty.CurveFiniteMapDegrees.degree_pullback_ratio, EnvelopeProperty.CurveFiniteMapDegrees.degree_pullback}
\uses{thm:fc-curve-finite-map-projective,thm:fc-scheme-finite-flat-closed-degree,thm:fc-original-projective-line-cartier-ratio}

projective curve, every SAME original invertible line has actual
pullback degree equal to its original degree multiplied by the
native rank of the SAME original map at the original generic
point. No divisor, support, basis, rank or degree certificate is
supplied.
\end{theorem}
\begin{proof}
Actual original Cartier supports are finite by original integral
curve geometry. The actual geometric comap support is finite by
native finite base change. The true finite closed-ideal Euler
formula and the entire field-linear inverse-section dimension
formula give the ideal degree scaling. Internally produce an actual
original Cartier ratio for every original line; native true
flat module, tensor and dual pullbacks preserve the same ratio.
The full normalized Euler ratio formula then gives the result for
that SAME arbitrary original line, without a regular source premise.
\end{proof}

\begin{theorem}[Actual dominant normal-curve map derives positive degree scaling]
\label{thm:fc-curve-normal-finite-line-degree}
\leanok
\lean{EnvelopeProperty.CurveFiniteMapDegrees.degree_pullback_of_normalCurve, EnvelopeProperty.CurveFiniteMapDegrees.genericRank_pos, EnvelopeProperty.CurveFiniteMapDegrees.degree_pullback_nonneg_iff_of_normalCurve}
\uses{thm:fc-curve-finite-flat-line-degree,thm:fc-normal-curve-dominant-flat}
For an actual finite dominant morphism of original integral schemes
to an original normal integral projective curve, actual flatness is
internally derived and the original generic rank is strictly
positive. Thus every original line has nonnegative degree if and
only if its SAME true pullback line has nonnegative degree.
This scope does not assume a singular target to be normal or flat.
\end{theorem}
\begin{proof}
Actual normal one-dimensional base stalks and original dominant
stalk injectivity derive flatness of the SAME entire map. Native
rank positivity at the image of the original generic point, and
actual dominance's original generic-point equality, give positivity
of the same generic rank. Combine the preceding true degree
identity with positivity of this internally derived integer factor.
\end{proof}
