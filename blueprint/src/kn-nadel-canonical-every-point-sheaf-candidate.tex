\section{Actual whole canonical candidates at every original base point}

\begin{definition}[Produced actual whole canonical-candidate chart and map]
\label{def:kn-canonical-every-point-whole-candidate}
\lean{EnvelopeProperty.Vanishing.NadelGlobalCanonicalTrace.producedCanonicalCandidateChart,EnvelopeProperty.Vanishing.NadelGlobalCanonicalTrace.producedCanonicalCandidate}
\leanok
The original ordinary tame SNC data internally produce, at every original
base point $x$, an actual whole free chart of the original cover together
with its actual regular native canonical sheaf candidate. Only the genuine
closed point and framed geometric data are chosen. The entire original
model, whole free basis and same actual ratio candidate are then explicitly
constructed. No Hom is selected by unconstrained classical choice.
The candidate has no assumed normalization or rational-factor law.
\uses{def:kn-structure-trace-whole-free-chart,def:kn-canonical-whole-ratio-native-sheaf-candidate}
\end{definition}

\begin{lemma}[The same actual produced candidate charts cover every base point]
\label{lem:kn-canonical-every-point-whole-candidate-cover}
\lean{EnvelopeProperty.Vanishing.NadelGlobalCanonicalTrace.mem_producedCanonicalCandidateChart}
\leanok
Every original base point belongs to its same internally produced actual
whole canonical-candidate chart. No chart or covering certificate is a
caller input.
\uses{def:kn-canonical-every-point-whole-candidate}
\end{lemma}
\begin{proof}
Choose a genuine closed specialization of the original point. Use the
original absent-row and framed-coordinate producers at that closed point.
The resulting affine open contains the original point by specialization.
Construct the same whole original model and its complete free basis, and
apply the actual ratio-candidate constructor to those same geometric data.
The point-membership proof is carried with that actual constructed pair.
\end{proof}
