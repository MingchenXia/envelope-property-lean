\begin{theorem}[Whole normalized projection over an original isomorphism open]
\label{thm:actual-normalized-pl-model-open-isomorphism}
\lean{EnvelopeProperty.ProjSubvariety.normalizedSimultaneousProjection_isIso_on_originalOpen}
\lean{EnvelopeProperty.ProjSubvariety.normalizedSimultaneousComposite_isIso_on_originalOpen}
\leanok
\uses{thm:actual-original-pl-variety-product-normal,thm:actual-normal-stalk-over-open-isomorphism,thm:actual-normalization-isomorphism-normal-open}
On an original projectively normal variety, whenever its actual simultaneous
blowup is a whole isomorphism over an original open $W$, the actual
normalization projection is a whole isomorphism over the actual inverse-image
open, and the actual normalized-model composite is a whole isomorphism over $W$.
\end{theorem}
\begin{proof}
The original variety-polynomial product has genuinely normal original stalks.
The actual whole original open isomorphism therefore makes every original
blowup stalk over $W$ normal. Integrality of the original blowup is derived
from its actual finite-log Gauss lift. The actual normalization theorem on
arbitrary original normal opens makes the same normalization projection a
whole isomorphism there. The native restriction-of-composition identity and
composition of these two true isomorphisms prove the composite assertion.
\end{proof}

ideal-log formula with the actual section model norm on this same actual
normal proper model. All asserted original geometric properties are derived.
\end{proof}
