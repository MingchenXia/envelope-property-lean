\begin{definition}[The actual original generic canonical comparison]
\label{def:kn-canonical-original-generic-comparison}
\lean{EnvelopeProperty.Vanishing.NadelGlobalCanonicalTrace.originalGenericCanonicalIso,
EnvelopeProperty.Vanishing.NadelGlobalCanonicalTrace.originalGenericCanonicalIso_differential}
\leanok
Write $p:Y_\eta\to Y$, $q:Y_\eta\to\operatorname{Spec}K$ and
$\gamma:\operatorname{Spec}K\to X$ for the actual entire original
generic fiber square. The proved inverse of $p^*\delta$ followed by
native cartesian pullback comparisons gives
$p^*\omega_Y\simeq q^*\gamma^*\omega_X$. Composing the original
pulled differential with this comparison recovers exactly the native
cartesian source comparison.
\uses{thm:kn-canonical-original-generic-differential-iso}
\end{definition}

\begin{definition}[The same whole original rational canonical trace]
\label{def:kn-canonical-original-rational-trace}
\lean{EnvelopeProperty.Vanishing.NadelGlobalCanonicalTrace.genericRationalCanonicalTrace}
\leanok
The original smooth integral SNC and tame data internally define a map
$\pi_*\omega_Y\to\gamma_*\gamma^*\omega_X$. Restrict the original
canonical sheaf by the actual native adjunction unit to the entire
generic fiber, apply the preceding genuine inverse differential, then
apply the trace of the entire actual finite generic algebra tensored
with the original pulled canonical line through the native line
projection formula. The target is rational. This definition asserts
neither a regular factor nor a global inverse for $\delta$.
\uses{def:kn-canonical-original-generic-comparison,def:kn-structure-trace-rational,lem:kn-canonical-actual-generic-inclusion-mono}
\end{definition}
