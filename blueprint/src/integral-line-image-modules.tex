\section{The actual whole module of a nonzero line section's zero ideal}

\begin{theorem}[Original line frames and their whole image ideals]
\label{thm:fc-original-line-image-frames}
\leanok
\lean{EnvelopeProperty.IntegralLineImageModules.exists_affine_frame, EnvelopeProperty.IntegralLineImageModules.imageIdeal_ideal_of_frame}
An actual original invertible module has a genuine original affine frame
near every original point. If $\alpha:M\to\mathcal O_X$ is an original
map, then on every actual affine frame its ENTIRE original image ideal
is generated by the original image of the actual frame vector.
\end{theorem}
\begin{proof}
Refine an original invertible-module trivializing cover by actual affine
opens and restrict the genuine frames. On a frame, every original
module section is its actual coordinate times the actual frame vector.
Original linearity sends it to that coordinate times the image of the
frame vector. Thus the whole original image is contained in the stated
principal ideal, and the frame vector itself supplies the reverse
containment.
\end{proof}

\begin{theorem}[Cartier image derives genuine original injectivity]
\label{thm:fc-original-line-cartier-image-mono}
\leanok
\lean{EnvelopeProperty.IntegralLineImageModules.app_injective, EnvelopeProperty.IntegralLineImageModules.mono_of_cartier_image}
\uses{thm:fc-original-line-image-frames}
On an original integral scheme, an original line map with its actual
Cartier image ideal is injective on EVERY original open and is a whole
original monomorphism. No monomorphism or local-injectivity premise is
supplied.
\end{theorem}
\begin{proof}
A genuine original Cartier ideal has nonzero ideal on every nonempty
original affine open: otherwise its original generic stalk would vanish,
contradicting its actual nonzero regular stalk generator. On an affine
frame the preceding entire-image formula therefore gives a nonzero
image coefficient. The original affine ring is a domain, so multiplication
by this actual coefficient is injective. Frame coordinates are genuinely
invertible, giving injectivity of the original map there.

To compare original sections on an arbitrary original open, cover it by
affine subopens of actual original line frames. The true restriction
square makes their image sections equal. Actual frame injectivity gives
equality on these subopens, and the original module's sheaf axiom gives
equality on the SAME whole open. Pointwise injectivity consequently gives
the true original whole monomorphism.
\end{proof}

\begin{theorem}[The whole dual line is the SAME actual zero-ideal module]
\label{thm:fc-original-line-zero-ideal-module}
\leanok
\lean{EnvelopeProperty.IntegralLineImageModules.lineImageIso, EnvelopeProperty.IntegralLineImageModules.lineImageIso_hom_inclusion, EnvelopeProperty.IntegralLineImageModules.zeroSectionDualIso, EnvelopeProperty.IntegralLineImageModules.zeroSectionDualIso_hom_inclusion}
\uses{thm:fc-original-line-cartier-image-mono, thm:fc-quasicoherent-image-module-iso, thm:line-section-zero-ideal-cartier}
An original line with its actual Cartier image is isomorphic to the SAME
actual image-ideal module, preserving the EXACT original map into the
structure module. In particular, for an original nonzero section
$\sigma:\mathcal O_X\to L$ on an original integral scheme,
\[
 L^\vee\simeq Z(\sigma)^{\sim},
\]
where $Z(\sigma)$ is the EXISTING original single-section zero ideal,
constructed from the original dual map followed by the original dual-unit
isomorphism. The whole inclusion is EXACTLY that original dual evaluation.
No mono, Cartier, image, frame or whole-isomorphism certificate is supplied
for this single-section conclusion.
\end{theorem}
\begin{proof}
The preceding theorem genuinely derives monicity. The true original
quasicoherent image-module theorem then constructs the whole original
isomorphism and its exact inclusion identity. For the asserted original
single section, the existing native nonzero-section theorem proves that
its SAME original zero ideal is Cartier. The actual dual line is invertible
and quasicoherent. Apply the derived monomorphism and whole image-module
construction to the literal original dual evaluation map. This proves
the same whole dual-line isomorphism with its exact original inclusion.
\end{proof}
