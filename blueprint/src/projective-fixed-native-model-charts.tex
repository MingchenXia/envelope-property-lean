\section{All original native coordinate charts agree with one fixed reconstructed model}
\label{sec:projective-fixed-native-model-charts}

\begin{theorem}[One whole-field model retains every original native affine chart {\cite[\S1.2]{BJ22}}]
\label{thm:projective-fixed-native-model-charts}
\lean{EnvelopeProperty.ProjectiveFixedNativeModelCharts.modelChartAlgAt_eq_adjoin_coordinates, EnvelopeProperty.ProjectiveFixedNativeModelCharts.nativeSectionsEquivModelChartAt, EnvelopeProperty.ProjectiveFixedNativeModelCharts.nativeSectionsEquivModelChartAt_apply, EnvelopeProperty.ProjectiveFixedNativeModelCharts.nativeChartIsoAt, EnvelopeProperty.ProjectiveFixedNativeModelCharts.nativeChartIsoAt_structure}
\leanok
\uses{thm:projective-native-model-chart-algebra,thm:projective-chart-generic-transitions}
Fix an actual integral closed embedding $f:X\hookrightarrow\mathbf P^m_k$
and one original nonempty coordinate chart $i$. Reconstruct the single
original homogeneous model $P$ over the entire same native $K(X)$ using
these original $i$th-chart ratios. For every original chart $j$ with
nonempty original inverse image, its entire native section ring is
isomorphic over the original $k$ to the $j$th chart algebra of this same
fixed $P$, and every original section maps to its literal native generic
germ. Its actual original affine open scheme is isomorphic to the
spectrum of this same fixed-model chart algebra. The whole original
coefficient structure triangle is preserved. No chart, scheme or
coordinate comparison is supplied as a premise.
\end{theorem}
\begin{proof}
The fixed model dehomogenizes its original homogeneous coordinate
$c_{i,a}T$ on chart $j$ to $c_{i,a}/c_{i,j}$. The original generic
transition theorem identifies this exactly with the original chart
ratio $c_{j,a}$. Applying dehomogenization to the original generated
homogeneous coordinate algebra therefore identifies the fixed-model
chart algebra with $k[c_{j,a}]$, as a literal subalgebra of the same
native field. The original native whole-section theorem for chart $j$
identifies its section image with this same subalgebra.

Compose the established whole native section equivalence for chart $j$
with this equality of literal original field subalgebras. This gives
the asserted full algebra equivalence and retains the exact generic
germ of every original section. Compose the established original native
affine scheme isomorphism for chart $j$ with the spectrum of the inverse
subalgebra equality equivalence. This gives the actual whole scheme
isomorphism into the fixed model chart. Equality of the original $k$
coefficient maps under this algebra equivalence, together with the
previous native chart coefficient triangle, gives precisely the stated
original structure triangle. The reconstructed $P$ is fixed throughout;
the conclusion controls all original nonempty coordinate charts of
this same model. Global analytic gluing remains a separate producer.
\end{proof}
