\section{The intrinsic localized multiplier formula}

\begin{theorem}[Actual localized leaf contributions without supplied coordinates]\label{thm:sc0-intrinsic-localized-multiplier-formula}
\lean{EnvelopeProperty.Char0.intrinsicDVRMultiplierContribution_eq_monomial_comap_of_localization}
\leanok
\uses{thm:sc0-multiplier-localized-leaf-formula,thm:sc0-valuative-multiplier-membership}
For an actual original-source nonzero ideal, an actual etale monomial
leaf, and an actual DVR localization of that leaf in the original
function field, its intrinsic original-source multiplier contribution
at rational exponent $q$ is exactly the comap of the rounded leaf
monomial extended to this actual DVR. No DVR coordinate presentation,
index matching or determinant-unit data is supplied.
\end{theorem}
\begin{proof}
Actual essential finite type of the DVR constructs a uniformizer and a
finite residue transcendence basis. The actual original function field
identifies the differential rank of that coordinate system with the
etale leaf rank. Invariance of the intrinsic contribution under every
finite presentation identifies it with this internally constructed
coordinate contribution. The exact localized leaf formula now computes
that contribution as the stated rounded monomial comap.
\end{proof}
