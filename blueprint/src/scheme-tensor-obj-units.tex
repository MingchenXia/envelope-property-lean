\section{The same original explicit tensor right unit}

\begin{theorem}\label{sc0-tensor-obj-units:whole-right-unit}
\lean{EnvelopeProperty.SchemeTensorObjMorphisms.tensorObjUnitIso_monoidal}
\leanok
\uses{sc0-tensor-obj-morphisms:natural}
For EVERY original module sheaf, the ORIGINAL explicit sheafified tensor right-unit isomorphism agrees with the SAME native monoidal right unit under the genuine original tensor and structure-unit comparisons. This is equality of ENTIRE original maps, without invertibility, quasicoherence, affineness or comparison assumptions.
\end{theorem}
\begin{proof}
The inverse genuine tensor comparison is the actual cotensorator of original module sheafification followed by tensor of the SAME original counit isomorphisms. Cancel its true inverse to compare the entire original maps. The original structure-unit comparison is exactly the same sheafification counit at the actual original structure module, so those unit factors cancel in the entire tensor map. Genuine native right-unit naturality moves the SAME original module counit to the end. The actual sheafification localization functor has its genuine native monoidal structure and literal identity unit comparison. Its right unitality followed by actual cotensorator/tensorator cancellation leaves sheafification of the ORIGINAL presheaf right unit followed by the SAME original counit. This is exactly the original explicit tensor right-unit isomorphism by definition. No arbitrary replacement unitor, object-only isomorphism or supplied coherence certificate is used.
\end{proof}
