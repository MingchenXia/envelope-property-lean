\section{Whole original DVR trait lifts to the actual native normalization}
\begin{theorem}\label{thm:scheme-dvr-native-normalization-lift}
Every actual dominant map from the spectrum of an original DVR to an original integral scheme uniquely lifts to that scheme's actual normalization in its native function field. The resulting whole original trait map has exactly the same original projection.
\lean{EnvelopeProperty.SchemeDVRNormalizationLift.existsUnique_lift,EnvelopeProperty.SchemeDVRNormalizationLift.lift,EnvelopeProperty.SchemeDVRNormalizationLift.lift_projection}\leanok
\end{theorem}
\begin{proof}
The original DVR is integrally closed. Each actual original spectrum stalk is its literal prime localization, hence is integrally closed. The original whole scheme map is dominant, so on every nonempty original affine chart it induces a genuine injective map into a normal original affine trait chart. Integral closure extends this actual injective map uniquely. These extensions agree on their original chart overlaps by that uniqueness and glue to the actual normalization. The same uniqueness proves uniqueness of the whole lift; its projection is the whole original trait map, with no supplied normal-stalk, local-extension or lift certificate.
\end{proof}
