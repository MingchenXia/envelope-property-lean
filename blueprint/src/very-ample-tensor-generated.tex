\begin{theorem}[An original very ample line times an original generated line is very ample]
\label{thm:fc-original-very-ample-tensor-generated}
\lean{EnvelopeProperty.VeryAmpleTensorGenerated.isVeryAmple_tensor}
\leanok
\uses{thm:fc-original-segre-projective-twist,thm:fc-generated-line-projective-twist-iso}
Let $X$ be an original integral scheme over $R$. If $A$ is geometrically
very ample and $B$ is an original invertible line with actual finite
global generators, then the actual original tensor line $A\otimes B$
is geometrically very ample over the same original base.
\end{theorem}
\begin{proof}
Take the actual closed projective embedding for $A$. The actual finite
generators of $B$ internally give a whole morphism to an original
polynomial projective space with original whole $\mathcal O(1)$
pullback equal to $B$. Combine these two original maps by the true
fiber-product lift. The first projection of this lift is the original
closed embedding; the other projective space is separated over $R$,
so the first product projection is separated. Closed-immersion
cancellation proves that the actual combined map is a closed immersion.
Compose it with the original Segre closed immersion. Its original
coefficient triangle is the original structure morphism. The actual
Segre line comparison, whole pullback composition, and native monoidal
pullback identify its original $\mathcal O(1)$ pullback with the actual
$A\otimes B$. This is precisely the original geometric very ample
criterion, with every embedding and whole line comparison constructed.
\end{proof}
