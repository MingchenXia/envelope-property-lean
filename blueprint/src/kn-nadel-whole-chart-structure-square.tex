\section{The actual whole-chart trace as a native scalar square}

\begin{lemma}[All coefficients of the actual whole-chart structure square]
\label{lem:kn-original-whole-chart-structure-square}
\lean{EnvelopeProperty.Vanishing.NadelGlobalCanonicalTrace.originalStructureTrace_wholeChart_square}
\leanok
For the original geometric cover and any nonempty actual whole free
chart, the published global structure trace followed by the chart's
structural unit equals the SAME native structural-square map followed
by the pushforward of the SAME affine coefficient-algebra trace. The
chart algebra, its entire original basis and all maps are those of the
given actual chart; no coefficient agreement is an extra hypothesis.
\end{lemma}
\begin{proof}
The proved global structure-trace chart theorem identifies
its actual open restriction with the original chart trace. Compose
this equality with the actual structure-unit restriction isomorphism
and cancel its inverse. The result is precisely the original native
cartesian unit comparison followed by the original affine trace.
The existing converse from open restriction to structural-square
naturality is the adjunction mate of that equation. Applying it gives
the required whole morphism equality, so every coefficient is covered.
\end{proof}
