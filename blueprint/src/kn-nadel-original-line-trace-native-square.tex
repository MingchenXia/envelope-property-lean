\section{The exact original line-trace square on arbitrary geometric squares}

\begin{lemma}[The whole native line square with the original unit constraints]
\label{lem:kn-original-line-trace-native-square}
\lean{EnvelopeProperty.Vanishing.NadelGlobalCanonicalTrace.originalLineTrace_nativeSquare_of_structureSquare}
\uses{lem:kn-native-line-trace-square-from-structure}
\leanok
For any commuting scheme square and any invertible original module $M$, suppose
an actual structure trace satisfies the native scalar square. Then the exact
original inverse-projection-formula line trace satisfies the entire native
pulled-line square. The left unitors and original module-square morphism are
those in the original rational trace constructor.
\end{lemma}
\begin{proof}
Apply the proved native line-square theorem before specializing the schemes or
module. Its transported left unitors have precisely the old stored constructors,
so the same ordinary kernel-checked equation retains the original inverse
projection formula on both sides. No new field or monoidal data are introduced.
\end{proof}
