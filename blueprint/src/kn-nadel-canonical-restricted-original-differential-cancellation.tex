\section{Cancel the actual restricted original canonical differential}
\begin{lemma}[Original pushed differential on every actual whole chart]
\label{lem:kn-canonical-restricted-original-differential-cancellation}
\lean{EnvelopeProperty.Vanishing.NadelGlobalCanonicalTrace.wholeFreeChart_restrictedOriginalDifferential_hom_ext}
\leanok
For any actual original whole chart $a:A\to X$, restriction of the original
pushed canonical differential detects equality of maps to the restriction
of every pushforward $\gamma_*N$ from the SAME original generic point.
No comparison, etale factor, or cancellation certificate is supplied.
\uses{lem:kn-canonical-whole-chart-pushed-differential-square}
\end{lemma}
\begin{proof}
Use the already proved internally produced differential comparison and
native cartesian comparison for the original generic target. Conjugate
the two maps by these isomorphisms. Equality after the original
restricted differential then becomes equality after the actual native
whole-chart differential. Its proved dense etale-open cancellation applies;
conjugation back gives equality of the original restricted maps.
The arbitrary compatible line isomorphisms are used only to prove this
cancellation statement, never to define a value-normalized candidate.
\end{proof}
