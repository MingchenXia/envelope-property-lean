\label{sec:smooth-etale-affine-cover}

\begin{lemma}[Standard smooth geometry supplies the actual coordinate tuple]
\label{lem:cartier-standard-smooth-actual-etale-coordinates}
\lean{EnvelopeProperty.Cartier.SmoothEtaleAffineCover.exists_etale_coordinates}
\leanok
For ANY original standard smooth algebra of relative dimension $n$
over its original base ring, there is an actual original tuple of
$n$ elements whose SAME polynomial evaluation map is etale. No
basis, polynomial map or coordinate certificate is supplied.
\end{lemma}
\begin{proof}
The native standard-smooth presentation theorem internally constructs
an actual etale polynomial algebra map with the specified number of
variables. Take its images of the ORIGINAL polynomial generators.
The universal property of the SAME original polynomial algebra
identifies its evaluation map with that actual constructed algebra
map on the entire original algebra. Hence the actual evaluation
map is etale. The native theorem supplies the geometric presentation;
there is no etaleness or coordinate-matching hypothesis left to give.
\end{proof}

\begin{theorem}[Every original smooth point has an actual affine etale-coordinate chart]
\label{lem:cartier-smooth-original-point-etale-chart}
\lean{EnvelopeProperty.Cartier.SmoothEtaleAffineCover.exists_affine_etale_chart}
\leanok
Let $f:X\to\operatorname{Spec}k$ be the SAME original smooth morphism
of relative dimension $n$ over the original field. EVERY original
point belongs to an actual affine open whose original section ring,
with the SAME original structural $k$-algebra action, has genuine
etale polynomial evaluation coordinates of length $n$.
\end{theorem}
\begin{proof}
The actual native smooth chart theorem produces an original affine
neighbourhood whose SAME structural coefficient map is standard
smooth of the specified original dimension. It already retains the
original whole structure morphism and actual spectrum coefficient
isomorphism. The original cotangent-open algebra is precisely that
original structural algebra action. Apply the preceding genuine
coordinate-tuple existence theorem to this actual original algebra.
No chart, algebra-action or tuple comparison certificate is assumed.
\uses{lem:cartier-standard-smooth-actual-etale-coordinates}
\end{proof}

\begin{theorem}[The genuine whole original affine etale-coordinate cover]
\label{thm:cartier-smooth-original-etale-affine-cover}
\lean{EnvelopeProperty.Cartier.SmoothEtaleAffineCover.exists_affine_etale_cover}
\leanok
The SAME original smooth scheme has an actual open cover by actual
affine opens with genuine original etale polynomial coordinate tuples
for their SAME original structural algebra actions. Every original
point lies in its indexed neighbourhood. This construction includes
the original empty scheme internally and requires no nonempty or
finite-cover assumption.
\end{theorem}
\begin{proof}
Choose the actual chart supplied by the preceding theorem for EACH
original point, retaining its proved affineness, original point
membership and actual coordinate tuple. This gives a genuine family
of original opens indexed by the original points. The union contains
every original point because its own indexed neighbourhood contains
it, hence it is the whole original scheme. This proof also covers
the original empty scheme: the same pointwise union equality is
valid there. Every original algebra coefficient action remains the
actual original structural one. No open-cover or coordinate data
are input.
\uses{lem:cartier-smooth-original-point-etale-chart}
\end{proof}
