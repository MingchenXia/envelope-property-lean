\section{Whole original differential naturality for the actual canonical maps}
\label{sec:etale-differential-naturality}

with the SAME original $R$-coefficient maps. Give $A$ and $B$ any actual

\begin{theorem}[The SAME native canonical map is the universal exterior map]
\label{lem:cartier-native-canonical-exterior-map-comparison}

The ENTIRE original native K\"ahler map is semilinear for the SAME original
coefficient map. The existing original native canonical exterior map equals
the actual universal semilinear exterior map of that SAME K\"ahler map on
EVERY original form. It retains every original function wedge and every
original coefficient, and preserves actual left multiplication on EVERY
original homogeneous form.
\end{theorem}
\begin{proof}
Native K\"ahler linearity and the original scalar tower give genuine
semilinearity with the SAME actual coefficient map. The existing native
canonical exterior map carries each actual decomposable wedge to the wedge
of the SAME native K\"ahler images. The genuine universal semilinear exterior
map has precisely the same actual formula. The actual original finite
exterior cotangent basis of $A$, its true entire original coefficient
expansion, and the original scalar-tower action identify the two ENTIRE
maps. No exterior, coefficient or vector-map comparison is supplied.
Their equality and the proved true universal exterior left-product formula
give the whole original left-multiplication identity. Native K\"ahler
naturality on EVERY original universal differential gives the exact
original-function and coefficient formulas.
\uses{lem:cartier-exterior-semilinear-left-wedge}
\end{proof}

\begin{theorem}[Entire original differential commutes with the SAME actual native map]
\label{thm:cartier-native-canonical-differential-naturality}
\lean{EnvelopeProperty.Cartier.EtaleDifferentialNaturality.differential_canonicalMap,EnvelopeProperty.Cartier.EtaleDifferentialNaturality.complexMap,EnvelopeProperty.Cartier.EtaleDifferentialNaturality.frobeniusFormMap,EnvelopeProperty.Cartier.EtaleDifferentialNaturality.frobeniusFormMap_apply,EnvelopeProperty.Cartier.EtaleDifferentialNaturality.frobeniusComplexMap}

The SAME original native canonical exterior maps commute with the ENTIRE
actual original etale differentials in every degree and on every original
form. Thus these SAME actual native maps give a genuine WHOLE morphism of
the original additive de Rham complexes for ANY actual original algebra tower.
In genuine prime characteristic the SAME actual maps are linear between
the original Frobenius-restricted source modules and the ACTUAL restricted
target Frobenius modules, and give a WHOLE native cochain morphism.
\end{theorem}
\begin{proof}
The source's genuine original finite exterior cotangent basis consists of
actual universal differential wedges. Expand EVERY original form in that
SAME actual basis. The first theorem retains each original coefficient and
universal wedge under the actual native map.
The already proved intrinsic generator formula applies to both actual
differentials, including the target's images of arbitrary source functions.
The actual whole left-product comparison and the SAME native K\"ahler map's
original universal differential identity make the two entire composites
identical on each original coefficient times each original basis wedge.
Actual additivity and the original full basis expansion prove equality for
EVERY original form. The SAME original maps in every degree then give the
true native cochain morphism, with commutation derived rather than supplied.
For native Frobenius restriction, restrict the SAME original native map
along the source Frobenius. Actual coefficient-map naturality on original
$p$th powers proves the real Frobenius coefficient square. The native
scalar-restriction composition and equality isomorphisms then give the SAME
map with its actual restricted target Frobenius module; their EVERY original
element map is the identity. No Frobenius-linearity certificate is supplied.
The entire derived differential commutation gives the whole
native restricted-target Frobenius cochain morphism, retaining every original
module, form and scalar map.
\uses{lem:cartier-native-canonical-exterior-map-comparison,lem:cartier-etale-intrinsic-generator-formula}
\end{proof}
