\begin{theorem}[Genuine tensor additivity for EVERY original line]
\label{thm:fc-original-curve-line-degree-tensor}
\leanok
\lean{EnvelopeProperty.CurveLineDegrees.degree_tensor, EnvelopeProperty.CurveLineDegrees.degree_dual}
\uses{def:fc-original-curve-line-degree, thm:fc-original-projective-line-cartier-ratio, thm:fc-curve-cartier-ideal-degrees}
On ANY original integral projective curve over ANY original field, for
EVERY pair of original invertible modules,
\[
 \deg_p(L\otimes M)=\deg_pL+\deg_pM,
 \qquad \deg_p L^\vee=-\deg_p L.
\]
No normality, chosen Cartier representation, local frame, degree
additivity, vanishing or Riemann--Roch premise is assumed.
\end{theorem}
\begin{proof}
The original projective geometry derives properness, compactness and
separatedness. The actual projective-line Cartier-ratio producer constructs
original effective Cartier ideals $I,J$ and a WHOLE original isomorphism
$L\simeq I^{\sim}\otimes(J^{\sim})^\vee$. Their actual original closed
subschemes are finite over the original field, by genuine Cartier support
and original curve dimension.

The established true finite-closed-ideal Euler sequence, tensored by ANY
original line, gives degree additivity for an original ideal factor.
Genuine evaluation and this same identity give additivity for the actual
dual of an original Cartier ideal. Original associativity consequently
gives it for the SAME original Cartier ratio tensored by $M$. The true
whole original representation and Euler isomorphism invariance yield the
claimed equality for the original arbitrary $L,M$. Apply it to
$L\otimes L^\vee$, and use the genuine original evaluation isomorphism
with the structure line, to obtain the dual formula. This argument proves
the true degree identities without claiming a general Riemann--Roch theorem.
\end{proof}

\begin{theorem}[Degree retains the SAME original line pullbacks]
\label{thm:fc-original-curve-line-degree-pullback-tensor}
\leanok
\lean{EnvelopeProperty.CurveLineDegrees.degree_pullback_tensor}
\uses{thm:fc-original-curve-line-degree-tensor}
For ANY actual original map $i:C\to Z$ from the original integral
projective curve and ANY original invertible modules $L,M$ on the SAME
original $Z$,
\[
 \deg_p i^*(L\otimes M)=\deg_p i^*L+\deg_p i^*M.
\]
The map $i$ need not be proper, flat or a supplied curve immersion.
\end{theorem}
\begin{proof}
Native whole original monoidal pullback gives the actual original
isomorphism between $i^*(L\otimes M)$ and $i^*L\otimes i^*M$.
The SAME actual pulled original factors are invertible. True Euler
isomorphism invariance and the preceding ALL-line tensor additivity
therefore give the formula on the original curve with its original
coefficient structure.
\end{proof}

\begin{theorem}[Actual section zeros compute the SAME arbitrary line degree]
\label{thm:fc-original-curve-line-degree-zero-section}

\]

be normal or smooth, and no zero divisor, support, local-equation,
degree or section-to-line comparison certificate is supplied.
\end{theorem}
\begin{proof}
The actual whole original module of $Z(s)$ is the original dual line,
by the genuine single-section image isomorphism. Its full normalized
Euler degree is minus its original residue-weighted native-order sum,
by the true original Cartier degree theorem; all actual support finiteness
follows from original projective curve geometry. The dual degree is
minus the SAME original line degree by genuine ALL-line tensor additivity
and original evaluation. Equating these actual degrees proves the formula.
The ratio statement is the existing genuine original Cartier-ratio
weighted-order formula on these same actual objects.
\end{proof}
