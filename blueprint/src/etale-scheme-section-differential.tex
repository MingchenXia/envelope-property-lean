\section{The actual original exterior section differential commutes with restriction}
\label{sec:etale-scheme-section-differential}

Fix the original field $k$, actual structural morphism
$f:X\to\operatorname{Spec}k$, and an actual original open inclusion
$U\subseteq V$. All section algebras below are the SAME original
$\Gamma(X,U)$ and $\Gamma(X,V)$ with their structural $k$-actions.

\begin{lemma}[Whole original raw restriction is the canonical exterior map]
\label{lem:cartier-original-raw-section-restriction}
\lean{EnvelopeProperty.Cartier.EtaleSchemeSectionDifferential.restrictionAlgebraHom,EnvelopeProperty.Cartier.EtaleSchemeSectionDifferential.cotangent_restrict,EnvelopeProperty.Cartier.EtaleSchemeSectionDifferential.exterior_restrict}
\leanok
The actual original ring restriction is a $k$-algebra homomorphism.
The actual cotangent presheaf restriction equals the canonical
K\"ahler map on EVERY original differential. In every exterior
degree, the ENTIRE original exterior presheaf restriction equals
the canonical exterior map of this SAME original section algebra
homomorphism. No affine, nonempty, flatness or map-comparison
premise is supplied.
\end{lemma}
\begin{proof}
Naturality of the SAME original structural constant map proves
that the actual ring restriction preserves every original constant.
It supplies the actual scalar tower on the original section modules.
The original universal derivation commutes with the native
cotangent restriction on every original function. The spanning
property of universal differentials therefore gives equality of
the entire linear maps. The actual exterior presheaf restriction
is the universal semilinear exterior map of that actual cotangent
restriction. Equality on the spanning pure wedges proves the
whole exterior map equality, including degree zero and zero rings.
\end{proof}

\begin{theorem}[Intrinsic differential naturality on original coordinate opens]
\label{thm:cartier-original-section-differential-restriction}
\lean{EnvelopeProperty.Cartier.EtaleSchemeSectionDifferential.differential_restrict}
\leanok
If the two original section algebras admit actual \emph{\'etale}
coordinate tuples over $k$, the SAME actual exterior presheaf
restriction commutes with the entire intrinsic de Rham differential
on EVERY original form and in EVERY degree. The intervening
restriction map is not assumed flat or \emph{\'etale}. Each tuple
is ordinary coordinate data; eventual smooth-scheme assembly
must derive its coordinate opens from the original geometry.
\uses{lem:cartier-original-raw-section-restriction,thm:cartier-native-canonical-differential-naturality}
\end{theorem}
\begin{proof}
Apply the genuine intrinsic algebraic differential naturality to
the actual section-ring restriction and its internally derived
scalar tower. Replace both canonical exterior maps by the
preceding ENTIRE original presheaf restrictions. This retains
every original coefficient, wedge and section, with no supplied
matching certificate. The original empty-open zero algebras are
included. This provides the actual restriction square needed
for sheaf descent; it does not yet claim global Cartier or DI.
\end{proof}
