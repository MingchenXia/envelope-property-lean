\begin{theorem}[The original very ample line tensored with original finite generators]
\label{thm:general-native-veryample-tensor-original-finite-generators}

\lean{EnvelopeProperty.SchemeVeryAmpleTensorGeneratingSections.isVeryAmple_tensor}
\leanok

scheme, and $p:X\to\operatorname{Spec}R$ the same original morphism.
If the original module $H$ is very ample in the native closed-embedding
sense and the original invertible module $B$ has actual finite generating
sections, then the same original module $H\otimes B$ is natively very
ample over the same $p$. No integrality or reducedness of $R$ or $X$, and
no desired embedding or whole line-comparison certificate is supplied.
\end{theorem}
\begin{proof}
Unpack native very ampleness of the same $H$, retaining its actual closed
embedding $i$, actual base triangle and whole original $O(1)$ isomorphism.
The given finite generation supplies an actual finite index type. Use
the existing original generated morphism $j$ for the same $B$ and the
proved arbitrary-base whole original $O(1)$ comparison. Its base triangle
is the already proved actual original triangle. These two actual
triangles define the original product lift of $i$ and $j$. Its first
projection is the original closed embedding. The second projective
factor is proper and hence separated, so the existing closed-graph
cancellation theorem makes this actual product lift a closed immersion.
Compose it with the already proved original Segre closed immersion.
The existing Segre base identity gives the original $p$. Pull back the
already proved whole Segre $O(1)$ comparison and apply the native monoidal
pullback tensor comparison. The two original projection triangles,
the original comparison for $H$ and the constructed comparison for $B$
identify this whole module with exactly $H\otimes B$. These are the
literal witnesses required by native very ampleness. The closed-anchor
argument and Segre result are existing mathematics; the stronger input
producer here removes the former domain assumption on the base ring.
\end{proof}

\begin{theorem}[Actual inverse-twist generators give the original very ample line]
\label{thm:general-native-veryample-original-inverse-twist-generators}
\uses{thm:general-native-veryample-tensor-original-finite-generators}
\lean{EnvelopeProperty.SchemeVeryAmpleTensorGeneratingSections.isVeryAmple_of_inverse_twist_generated}
\leanok

$B$ an original invertible module. Actual finite generating sections of
the same original $H^\vee\otimes B$ imply native very ampleness of the
same original $B$. In particular the cohomological consumer can use

\end{theorem}
\begin{proof}

and tensor invertibility therefore derive invertibility of the original

and whole $O(1)$ comparison for $H\otimes(H^\vee\otimes B)$ from precisely
the supplied original finite generators. The inverse associator,
the genuine evaluation isomorphism $H\otimes H^\vee\simeq\mathcal O$
and the native left unitor give the canonical whole isomorphism to $B$.
Unpack the native embedding witnesses and compose their actual original
line comparison with this whole isomorphism. The same closed morphism
and original base triangle then witness native very ampleness of $B$.
This is the existing inverse-twist cancellation argument with the
arbitrary-base tensor producer; no generator-lifting or matching
certificate is added.
\end{proof}
