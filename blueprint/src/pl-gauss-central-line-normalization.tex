\section{The prescribed central section normalizes the same ambient line at the true vertex}

Let $Y$ and $C$ be integral, let $i:C\hookrightarrow Y$ be an actual closed
immersion, and write $\xi=\eta_C$, $\eta=i(\xi)$. Let $L$ be the actual
original invertible module sheaf on $Y$. Its prescribed section
\[
 \sigma_C\ne0,\qquad
 \sigma_C\in\Gamma\!\left(\operatorname{Spec}\kappa(\xi),
   (\operatorname{Spec}\kappa(\xi)\to C)^*i^*L\right)
\]
is a section in that literal original carrier. No rational restriction
through a closed immersion is presumed for arbitrary ambient sections.

\begin{definition}[Canonical generic-support carrier transport]
\label{def:gauss-central-line-original-generic-carrier}
\uses{lem:scheme-line-actual-center-frame}
\lean{EnvelopeProperty.GaussCentralLineNormalization.genericSectionAt}
\leanok
For an actual point $p\in Y$ with an actual proof $p=\eta_Y$, transport
an original section of $L$ over the actual generic residue-field spectrum
to the actual residue-field pullback at $p$ along this equality. This is
only equality transport on the SAME original line and residue morphism;
it chooses no field, line or norm comparison. Fix first the actual
point-indexed module, as a module on the exact native spectrum
$\operatorname{Spec}(\operatorname{of}\kappa(p))$; its object is the literal
original residue pullback. Its equality with the old native generic-line
module at a valued point is reflexivity. A single pure-point identity
bridge retains the raw generic-section carrier supplied by the old lift.
\end{definition}
\begin{proof}
The native generic-line module at a valued point with support $p$ is
exactly the pullback of $L$ by $Y.\operatorname{fromSpecResidueField}(p)$.
Substitution of the proved support equality therefore gives the required
original carrier. Equality elimination defines the map and makes it
independent of the proof of the equality.
\end{proof}

\begin{lemma}[A genuine local section isomorphism at the true center has unit norm]
\label{lem:gauss-central-line-true-center-generator-unit-norm}
\uses{def:actual-line-frame-via-factor,cor:actual-line-model-norm-local-frame,thm:fc-line-section-factorization,lem:fc-original-line-section-frame-naturality,lem:fc-original-line-section-fibre}
\lean{EnvelopeProperty.GaussCentralLineNormalization.localSectionAt,EnvelopeProperty.GaussCentralLineNormalization.modelLineNorm_localGenerator}
\leanok
Let $f:Y\to\operatorname{Spec}R$ be proper with the actual bounded base
valuation, let $q$ be an original native point, and let $V$ contain its
TRUE proper center. If the original whole section
$\delta:O_V\to L|_V$ is an isomorphism, its actual generic-fibre pullback
through the original residue-field map has model norm exactly $1$.
\end{lemma}
\begin{proof}
The true center gives the actual factor of its valua\-tion-ring map
through $V$; hence the original residue-field map also factors through
$V$. Every other factor of this same map agrees with it because $V\to Y$
is a monomorphism. Use the inverse of the SAME actual isomorphism
$\delta$ as the local frame. The old model-norm local-frame theorem
computes the actual norm in that frame.

The actual pulled generator is the native structure-unit comparison
inverse, followed by the actual pullback of $\delta$, followed by the
native factor-composition comparison. Its frame is the inverse composite.
The whole original section therefore has frame coefficient $1$: the
factor-comparison inverse cancels, the pullback of $\delta$ cancels its
actual inverse, and the structure-unit comparison cancels. The affine
residue-field global-section map sends $1$ to $1$, and its actual
valuation sends $1$ to $1$. Thus the genuine model norm is exactly $1$.
The center-neighborhood condition is used before this computation; an
arbitrary support-open generator does not supply it.
\end{proof}

\begin{theorem}[The prescribed central section produces the same ambient section normalized at the common vertex]
\label{thm:gauss-central-line-prescribed-section-unit-norm}
\uses{thm:gauss-common-one-original-vertical-point,cor:central-generic-prescribed-section-same-rational-lift,def:central-generic-original-local-section-value,def:gauss-central-line-original-generic-carrier,lem:gauss-central-line-true-center-generator-unit-norm}
\lean{EnvelopeProperty.GaussCentralLineNormalization.exists_prescribed_section_unit_norm_at,EnvelopeProperty.GaussCentralLineNormalization.exists_prescribed_section_unit_norm}
\leanok
Assume the actual proper dominant $f:Y\to\operatorname{Spec}k[t]$, the
actual verticality of $\eta$, and one genuine original Noetherian stalk
with a prime component equation and its true closed-immersion stalk-map
kernel. At the prescribed paper Gauss radius there are an internally
constructed original native point $q_C$, an actual $\eta$-neighborhood
$V$, an original section isomorphism $\delta:O_V\to L|_V$, and a nonzero
original ambient generic section $\rho$ such that:
\begin{enumerate}
\item $q_C$ has the original generic support and TRUE center $\eta$;
\item the SAME actual central generic pullback of $\delta$ is exactly
  the prescribed $\sigma_C$ in its unchanged original carrier;
\item $\rho$ is the SAME original generic pullback of that SAME $\delta$;
\item the actual model norm at $q_C$ of the canonical support-equality
  transport of this SAME $\rho$ is exactly $1$.
\end{enumerate}
The same section-lifting and norm conclusion holds at ANY given actual
native point with proved original generic support and true center $\eta$;
the final stated existence theorem supplies these geometric laws internally.
Neither a local frame, a metric equation, a residue-field identification,
a section-matching certificate nor a normalized rational section is an
input. The original $L$ and the originally prescribed $\sigma_C$ are retained.
\end{theorem}
\begin{proof}
Use the frozen common-point theorem on the actual original $f,i$ and the
one genuine local component witness. It supplies the SAME $q_C$, its
original generic support and its true center $\eta$ internally.
Use the frozen prescribed-central-section lift on the actual nonzero
$\sigma_C$. It supplies the original $V,\delta$, the full central-section
equality, and the actual nonzero ambient generic $\rho$ from that same
local section. Retain all those whole objects and equations.

The true center of $q_C$ belongs to $V$, since it is exactly $\eta$.
The actual generic-support law places its residue-field pullback in the
canonical carrier of the first definition. After that equality transport,
the generic-section lift and the direct original residue-field factor
through $V$ are the SAME: both compose with $V\to Y$ to the same original
residue-field morphism, so monomorphism cancellation identifies the factors.
The genuine native factor-composition comparison consequently identifies
these whole sections, rather than merely their norms. Apply the preceding
local-generator lemma to this SAME $\delta$ at the actual true center.
It gives the asserted model norm $1$ for this SAME transported $\rho$.
No norm is asserted for an unrelated support-open frame.
\end{proof}

This result supplies the normalization of one prescribed central generic
section at the already constructed common vertex. It does not assert
convexity for arbitrary rational sections, identify local leading functions
across component equations, prove principal balances or weighted degrees,
or construct a global surface, SNC pair, nefness or LocalPositivity.
