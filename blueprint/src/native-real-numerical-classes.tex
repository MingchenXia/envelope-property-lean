\section{Genuine original real numerical classes from actual closed-curve degrees}
\label{sec:native-real-numerical-classes}

\begin{theorem}[The same original numerical quotient and actual finite line representatives {\cite[\S1.2]{BJ22}}]
\label{thm:native-real-numerical-classes}
\lean{EnvelopeProperty.NativeRealNumericalClasses.degreeVector, EnvelopeProperty.NativeRealNumericalClasses.trivialSubmodule, EnvelopeProperty.NativeRealNumericalClasses.Space, EnvelopeProperty.NativeRealNumericalClasses.projection, EnvelopeProperty.NativeRealNumericalClasses.projection_surjective, EnvelopeProperty.NativeRealNumericalClasses.lineClass, EnvelopeProperty.NativeRealNumericalClasses.curveDegree, EnvelopeProperty.NativeRealNumericalClasses.curveDegree_projection, EnvelopeProperty.NativeRealNumericalClasses.projection_eq_iff, EnvelopeProperty.NativeRealNumericalClasses.curveDegree_lineClass, EnvelopeProperty.NativeRealNumericalClasses.ext, EnvelopeProperty.NativeRealNumericalClasses.exists_finite_line_sum}
\leanok
\uses{thm:native-closed-curve-degrees, thm:native-real-picard}
For every original native-projective $X$ over the original field,
form the real numerical quotient of its same native real Picard
space by vanishing of every true degree on every actual original
closed integral curve. The original quotient map is a genuine
surjective real linear map. Each original curve degree descends
to this same numerical quotient, evaluates every actual original
line by the true full Euler degree of its same original pullback,
and these actual degrees jointly detect equality of original
numerical classes. Every numerical class is an actual finite
real sum of classes of actual original invertible lines. No
numerical comparison, line-realization, or finite-family
certificate is supplied.
\end{theorem}

\begin{proof}
Collect all the actual real linear closed-curve degree functionals
of the preceding theorem into their original product linear map.
Its genuine kernel is exactly the subspace of original real
Picard classes of degree zero on every original closed integral
curve. Take the native module quotient by this actual kernel.
The native quotient map is surjective. Every original curve's
functional vanishes on that same kernel, so the actual quotient
universal property descends it to the original numerical space.
Its evaluation on the original quotient map is the unchanged
original curve functional, hence its value on each original line
is the true whole Euler degree already proved.

Two original real Picard classes give the same quotient element
exactly when their difference is in the actual kernel, which
is equivalent to equality of every original closed-curve degree.
Every quotient element has an actual original real Picard
preimage by surjectivity, so the descended original functionals
jointly detect equality on the whole quotient. Choose an actual
preimage of any original numerical class and apply the genuine
finite original invertible-line sum theorem in the real Picard
space. Map that actual finite sum through the same native
quotient linear map. Its true additivity and homogeneity give
the claimed actual finite original line representation.

This construction treats exactly the source closed integral
curve tests. It does not assert finite dimensionality,
topological ample-cone properties, comparison with arbitrary
curve-map tests, or invariance of the model analytic psh
presentations under numerical equivalence. Those remain genuine
subsequent geometric obligations rather than added hypotheses.
\end{proof}
