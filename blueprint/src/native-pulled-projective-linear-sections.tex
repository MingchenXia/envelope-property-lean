\begin{theorem}[The literal original generic coefficient is linear over the original base field]
\label{thm:native-pulled-projective-linear-sections}

\leanok
\uses{thm:native-pulled-projective-model-sections,thm:native-pulled-projective-section-equivalence,lem:fc-scheme-scalar-module-presheaf,sc0-line-section-ratios:every-original-section,def:sc0-scheme-sections-function-field-map}
\source{bj22-trivval:sec:tc}
Assume throughout this statement that the original scheme $X$ is integral.
The whole actual original global section module of the original pulled
$O(d)$ line, with the literal action of the original base field through
the original structure morphism, is linearly equivalent to the whole
same fixed-model degree-$d$ section module. Its forward linear map is
exactly the actual original generic coefficient, and its underlying
set equivalence is the preceding whole original section equivalence.
No scalar-action comparison or section-realization premise is supplied.
\end{theorem}
\begin{proof}
Use the original structure morphism to give every original global section
its actual original field action. The genuine canonical section ratio is
semilinear over the actual generic structure-ring germ. Its identity with
the actual original coefficient therefore proves additivity. On an actual
original field scalar, the whole generic germ commutes with the original
field coefficient map, by the original structure-morphism stalk triangle.
Thus the same coefficient map is linear over the actual original field.
Its whole model-section membership allows restriction of the codomain to
the genuine section submodule. The preceding actual injection and genuine
sheaf-gluing surjection make this entire linear map bijective. The produced
linear equivalence has the literal coefficient forward map, so its underlying
set equivalence agrees pointwise with the already proved actual equivalence.
\end{proof}
