\section{The intrinsic differential on the same original affine sheaf sections}
\label{sec:etale-affine-section-differential}

Fix an actual affine open $V$ of the original $X/k$, and an actual
\emph{\'etale} coordinate tuple in its SAME original structural
section algebra. No section or sheaf comparison is supplied.

\begin{lemma}[The original exterior sheafification unit is a whole section equivalence]
\label{lem:cartier-original-affine-section-unit}
\lean{EnvelopeProperty.Cartier.EtaleAffineSectionDifferential.unitEquiv,EnvelopeProperty.Cartier.EtaleAffineSectionDifferential.unitEquiv_apply}
\leanok
In EVERY exterior degree, the actual original sheafification unit
from the raw exterior cotangent sections on $V$ to the SAME original
exterior cotangent sheaf sections on $V$ is a genuine linear
equivalence for $\Gamma(X,V)$. Its value is exactly the original
unit on EVERY original form, including zero algebras.
\uses{sc0-open-immersion-sheaf-units:original-chart}
\end{lemma}
\begin{proof}
The actual \emph{\'etale} coordinates derive the true original
K\"ahler basis. The already proved affine-chart unit theorem,
using the SAME original structural algebra and native open-immersion
comparison, proves the ENTIRE original unit bijective. Its genuine
linear inverse therefore supplies both whole section identities.
\end{proof}

\begin{theorem}[Original affine sheaf-section differential]
\label{thm:cartier-original-affine-section-differential}
\lean{EnvelopeProperty.Cartier.EtaleAffineSectionDifferential.rawDifferential,EnvelopeProperty.Cartier.EtaleAffineSectionDifferential.differential,EnvelopeProperty.Cartier.EtaleAffineSectionDifferential.differential_unit,EnvelopeProperty.Cartier.EtaleAffineSectionDifferential.differential_square}
\leanok
Conjugating the actual intrinsic raw differential by those SAME
original units gives an additive map between the original entire
exterior sheaf-section groups. On EVERY original raw form its
value is the original target unit applied to the SAME original
raw differential. Consecutive differentials compose to zero.
\uses{lem:cartier-original-affine-section-unit}
\end{theorem}
\begin{proof}
Use the actual inverse unit on the entire original source, the
intrinsic original de Rham differential, and the actual original
target unit. The true inverse identity proves the EVERY-form
formula. In two consecutive maps the intervening inverse unit
cancels the same original unit. The genuine raw $d^2=0$ and
additivity of the target unit give zero, also in degree zero.
\end{proof}

\begin{lemma}[Actual prime-power linearity on original sheaf sections]
\label{lem:cartier-original-affine-section-power-linearity}
\lean{EnvelopeProperty.Cartier.EtaleAffineSectionDifferential.differential_pow_smul}
\leanok
If the original field has prime characteristic $p$, this actual
section differential satisfies $d(a^p s)=a^p d(s)$ for EVERY
original scalar and original sheaf section. No target nonzero or
characteristic certificate is added.
\uses{thm:cartier-original-affine-section-differential,lem:cartier-original-algebra-zero-frobenius-linearity}
\end{lemma}
\begin{proof}
Both original units and their actual inverses are genuinely
$\Gamma(X,V)$-linear. The actual raw differential kills every
original $p$th-power universal derivative and satisfies the full
intrinsic scalar Leibniz rule, even for zero algebras. Transport
that true prime-power linearity through the SAME original units.
This provides the concrete Frobenius-linearity needed by global
module-sheaf descent; global Cartier and DI remain downstream.
\end{proof}

\begin{theorem}[Whole original affine sheaf-section restriction square]
\label{thm:cartier-original-affine-section-differential-naturality}
\lean{EnvelopeProperty.Cartier.EtaleAffineSectionDifferential.unitEquiv_restrict,EnvelopeProperty.Cartier.EtaleAffineSectionDifferential.differential_restrict}
\leanok
For ANY actual inclusion of two original affine coordinate opens,
the ENTIRE actual original sheaf-section differential commutes
with the SAME original sheaf restriction in EVERY degree, on
EVERY original sheaf section. The two coordinate tuples may have
different lengths; no map, unit or section matching premise is input.
\uses{thm:cartier-original-affine-section-differential,thm:cartier-original-section-differential-restriction}
\end{theorem}
\begin{proof}
Naturality of the SAME actual sheafification unit gives its ENTIRE
original raw/sheaf restriction square. Every original source sheaf
section is the original unit of an actual raw form, by the derived
whole unit bijection. Apply the exact unit formula for both original
section differentials and the proved intrinsic differential
naturality of the SAME raw restriction. These whole actual squares
compose to the stated original section identity. Empty opens and
zero rings are included. No supplied overlap comparison is used.
\end{proof}
