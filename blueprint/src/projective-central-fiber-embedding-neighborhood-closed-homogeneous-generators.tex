\section{Actual original homogeneous forms with diagonal powers generate the same twist}

Let $R$ be an arbitrary commutative ring, let the actual source be the original
$\mathbf P^m_R$, and fix its original $O(d)$, for $d\ge0$. Use the actual finite
index $I$ and actual homogeneous forms $F_a$ of degree $d$. Retain an actual
index selection $b:\operatorname{Fin}(m+1)\to I$ for which
$F_{b(i)}=X_i^d$ is a literal original polynomial equality. These are concrete
polynomial data. No local frame, epimorphism or projective-map certificate is input.

\begin{definition}[The actual original homogeneous generating family]
\label{def:central-embedding-original-homogeneous-forms-generating-family}
\lean{EnvelopeProperty.ProjectiveCentralFiberEmbeddingNeighborhoodClosedHomogeneousGenerators.homogeneousGeneratingSections}
\leanok
The SAME actual original homogeneous section morphisms of all $F_a$ form an
actual generating family of the ORIGINAL $O(d)$, with exactly the original index $I$.
\end{definition}
\begin{proof}
Use the actual free-Hom/section equivalence to form the ORIGINAL evaluation map
from the original free module indexed by $I$. On the original $X_i$ coordinate
open, choose the original twist frame. The actual coefficient of the original
section of $F_{b(i)}=X_i^d$ is $X_i^d/X_i^d=1$. This equality holds in the original
homogeneous localization, by the native ordinary-localization self-fraction
identity, over arbitrary coefficient rings including zero rings. The native
homogeneous-section coefficient formula identifies this with the actual whole
original scheme section in that frame. The original section-Hom restricts to an
isomorphism there. It is the original evaluation map preceded by the SAME basis
inclusion indexed by $b(i)$; hence that evaluation map is epimorphic on this
original coordinate open. The original coordinate opens cover the entire
original projective space. Native sheaf-module epimorphism detection on this
actual cover proves that the WHOLE original evaluation map is epimorphic.
Thus the constructed family genuinely generates, without an incoming epi proof.
\end{proof}

\begin{lemma}[Its original generator morphisms are exactly the prescribed forms]
\label{lem:central-embedding-original-homogeneous-generators-actual-homs}
\uses{def:central-embedding-original-homogeneous-forms-generating-family}
\lean{EnvelopeProperty.ProjectiveCentralFiberEmbeddingNeighborhoodClosedHomogeneousGenerators.homogeneousGeneratingSections_generatorHom}
\leanok
Every SAME original generator-Hom of this family is the actual original
homogeneous section-Hom of $F_a$, as an equality of entire module morphisms.
\end{lemma}
\begin{proof}
Compose the original free evaluation map with its actual original basis inclusion.
The original free-Hom/section equivalence evaluates this SAME original summand to
the SAME original homogeneous section morphism. Injectivity of the original
unit-Hom/section equivalence gives equality of the whole original morphisms.
\end{proof}

\begin{lemma}[The actual original family is finite]
\label{lem:central-embedding-original-homogeneous-generators-finite}
\uses{def:central-embedding-original-homogeneous-forms-generating-family}
\lean{EnvelopeProperty.ProjectiveCentralFiberEmbeddingNeighborhoodClosedHomogeneousGenerators.homogeneousGeneratingSections_isFiniteType}
\leanok
The actual original homogeneous generating family is of finite type.
\end{lemma}
\begin{proof}
Its original index is exactly the original finite $I$, without any enlargement.
This gives the original finite-type witness for the actual generating family.
\end{proof}

\begin{lemma}[Every same original coefficient is the actual original homogeneous ratio]
\label{lem:central-embedding-original-homogeneous-generators-local-coefficient}
\uses{lem:central-embedding-original-homogeneous-generators-actual-homs}
\lean{EnvelopeProperty.ProjectiveCentralFiberEmbeddingNeighborhoodClosedHomogeneousGenerators.localCoefficient_eq_fraction}
\leanok
In the original coordinate frame on the original $X_i$ affine open, every original
generator has coefficient equal to the actual original whole section $F_a/X_i^d$.
The comparison uses the original pullback/restriction frame isomorphism.
\end{lemma}
\begin{proof}
The preceding generator-Hom formula identifies the original generator with the
original homogeneous section-Hom. Its genuine original whole frame coefficient
is the original homogeneous ratio by the native homogeneous-section theorem.
The original section-Hom scalar identity therefore gives multiplication by the
original top-section image of $F_a/X_i^d$. The definition of the original generated
family's local coefficient gives the same unit-module map. Evaluation at the
actual original unit section identifies their entire original coefficients.
No pointwise or reducedness argument is used.
\end{proof}

For degree one select $I=\operatorname{ULift}(\operatorname{Fin}(m+1))$ and the
SAME original $F_a=X_{a.\mathrm{down}}$. For a large positive degree, use the
actual original mixed monomials $X_i^{d-1}X_j$, indexed by the corresponding
original lifted pair index. The diagonal identities supply the inputs above.
In both cases all central generators are actual pullbacks of prescribed original
ambient forms. No complete linear system, linear normality or projective normality
is assumed. The actual universal generated-map/padding comparison, its closedness
for large mixed degree, and final relative ampleness remain further obligations.
