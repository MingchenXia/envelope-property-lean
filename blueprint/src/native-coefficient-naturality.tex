\subsection{Whole actual native projective naturality under coefficient maps}

\begin{theorem}[Every actual coefficient map commutes with whole native points]
\label{projective:actual-whole-native-coefficient-naturality}
\lean{EnvelopeProperty.Berkovich.NormalizedProjectiveSpectrum.nativePoint_coefficientComap}
\leanok
\uses{projective:actual-normalized-coefficient-pullback}
For arbitrary commutative rings $R,S$, any actual homomorphism $f:R\to S$
and ANY actual normalized projective point $x$ over $S$, the entire native
residue-field-valued point of its actual coefficient restriction is exactly
the native scheme image of the SAME entire point $x$ under the actual
polynomial-projective coefficient morphism. No field, boundedness,
coefficient injectivity, normality or point-comparison premise is imposed.
\end{theorem}
\begin{proof}
Choose an ORIGINAL coordinate with actual value one; the original
normalization proves it exists. Actual coefficient restriction retains
this same coordinate value, and the actual native coefficient morphism
has precisely the same coordinate-open preimage. Compare both native
points using the injective whole actual affine-coordinate homeomorphism.
For every ORIGINAL coordinate-ring polynomial, choose a genuine original
homogeneous numerator using the true homogeneous fraction chart. The
whole dehomogenization reconstruction identity and selected coordinate
value one compute its original chart value. Coefficient maps preserve
homogeneity and commute with actual dehomogenization, so the restricted
and mapped chart values agree for EVERY original coordinate polynomial.

On the native side, actual evaluation naturality and restriction to the
same original affine coordinate open identify pullback section values
with the actual coefficient map on coordinate sections. The already
proved whole native coordinate-section identity supplies exactly that
map. The canonical native point's actual coordinate-section values are
its genuine original chart seminorm values. Thus the two WHOLE affine
seminorms agree on every polynomial, not just variables. Injectivity of
the actual native chart homeomorphism gives equality of the entire
original native points, including the original residue valuation.
\end{proof}

actual compatibility $w(f(a))=v(a)$ for every original coefficient,
restrict the whole normalized point along $f$. The result is an actual

\begin{proof}

prescribed-coefficient condition and the stated genuine base valuation
compatibility give the original relative coefficient condition, for
every original coefficient. All form values are retained by the actual
whole ring map itself. No separate comparison certificate is supplied.
\end{proof}

\begin{theorem}[Actual whole relative and polynomial-restriction naturality]

coefficient map on relative native points over compatible prescribed

\end{theorem}
\begin{proof}

and the resulting generic coefficient restriction have the SAME entire
underlying normalized point, so proof irrelevance gives the same genuine
relative point. No boundedness or positive radius is needed.
\end{proof}
