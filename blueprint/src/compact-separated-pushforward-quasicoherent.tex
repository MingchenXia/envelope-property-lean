\section{The entire original compact separated pushforward is quasicoherent on an affine base}
\label{sec:compact-separated-pushforward-quasicoherent}

\begin{theorem}[Every original pushed basic-open restriction localizes]
\label{sc0-compact-pushqc:original-basic-restrictions}
\lean{EnvelopeProperty.CompactSeparatedPushforwardQuasicoherent.pushforward_restriction_isLocalizedModule}
\leanok
Let $Y$ be the original quasi-compact separated scheme, let
$g:Y\to X$ be ANY original scheme morphism, and let $M$ be an
actual original quasicoherent module. The ENTIRE original
pushforward module restriction to EVERY original intrinsic
basic open $D(r)\subset X$ is localization at the SAME
$r\in\Gamma(X,\mathcal O_X)$, with BOTH original native global
coefficient actions. No pushforward-quasicoherence premise is given.
\end{theorem}
\begin{proof}
The genuine whole-section principal-localization theorem applies
to the actual original $Y$, $M$ and composite $g\gg\mathrm{id}_X$.
Original inverse image of the whole open is the whole $Y$;
transport along this proved equality gives the SAME restriction
between the actual preimages of $X$ and $D(r)$.

The native original pushforward/base-module comparison on each
original open has identity underlying sections, with its actual
linear coefficient square proved by original scheme section-map
composition. Thus these SAME whole isomorphisms genuinely commute
with restriction. Transport of actual localization along BOTH
bijective native comparisons makes the original pushed restriction
itself localization. No coefficient, inverse-image or map-square
certificate is supplied, including empty targets and $r=0$.
\uses{thm:scheme-module-whole-principal-localization}
\end{proof}

\begin{theorem}[The actual whole pushforward is quasicoherent over an affine scheme]
\label{sc0-compact-pushqc:whole-original-pushforward}
\lean{EnvelopeProperty.CompactSeparatedPushforwardQuasicoherent.isQuasicoherent_pushforward}
\leanok
If the SAME original $X$ is affine, the ENTIRE actual $g_*M$
is quasicoherent. No properness, flatness, Noetherianity,
chosen affine cover, localized-target, or full pushforward
quasicoherence certificate is assumed.
\end{theorem}
\begin{proof}
Apply the native affine-module quasicoherence criterion to the
SAME entire original pushforward. The preceding theorem derives
its true basic-open section localizations for EVERY original
global function, using the EXACT original base-module presheaf
over the identity of $X$. The native criterion derives actual
quasicoherence; no surrogate sheaf or supplied comparison is used.
\uses{sc0-compact-pushqc:original-basic-restrictions}
\end{proof}

Original proper geometry over an affine base derives the required
quasi-compactness and separatedness internally. This supplies
genuine pushforward quasicoherence for the separate full rounded
canonical module comparison; it asserts no vanishing conclusion.
