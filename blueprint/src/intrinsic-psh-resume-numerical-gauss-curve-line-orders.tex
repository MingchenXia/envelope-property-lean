$i:C\hookrightarrow Y$ is the actual closed immersion, $\xi=\eta_C$,
$\eta=i(\xi)$, and $L$ is the actual invertible module on $Y$.

\begin{theorem}[Two genuine local frames produce both original generic coefficient squares]
\label{thm:intrinsic-numerical-two-frame-original-coefficient-squares}

identify these values with the already defined $\rho,\rho_x,\sigma,\sigma_x$.
The actual scalar appLE formula and original germ--stalk-map naturality give
precisely the residue scalars of $f_x$ and $b_x$, respectively. This derives
both fibre equalities in their same original modules.
\end{proof}
