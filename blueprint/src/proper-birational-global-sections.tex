ACTUAL field-valued scheme point $q:\operatorname{Spec}K\to Y$ whose WHOLE

\[

\]
by the ACTUAL global section map of $q$ followed by the original
$\Gamma\operatorname{Spec}$ isomorphism. For EVERY valuation subring
$V\subset K$ containing the image of EVERY original element of $A$, and
EVERY original global section $s$, prove
$\operatorname{ev}_q(s)\in V$.
No domain, reducedness, Noetherianity, rank-one or real norm condition is
imposed on $A,Y,V$; no valuation lift is an input.
\end{lemma}
\begin{proof}

given whole triangle construct a genuine valuative square for $f$.
The actual proper valuative criterion supplies a REAL
$\ell:\operatorname{Spec}V\to Y$ with BOTH entire scheme triangles, in
particular $q=\ell\circ\operatorname{Spec}(V\hookrightarrow K)$ in
conventional function-composition notation.

Apply genuine global-section functoriality and the actual
$\Gamma\operatorname{Spec}$ naturality square. The original field element
$\operatorname{ev}_q(s)$ is EXACTLY the inclusion into $K$ of the original
element $(\Gamma\operatorname{Spec}V)(\ell^*s)\in V$.
This ELEMENT identity proves the asserted membership for EVERY $s$.
No equality of section values is inferred from norm bounds or support.
\end{proof}

\begin{theorem}[Normal original coefficients contain every actual generic global-section value]
\label{scheme:actual-normal-proper-global-section-image}
\leanok
\lean{EnvelopeProperty.ProperBirationalSections.globalSectionMap_mem_range}
\uses{scheme:actual-proper-global-section-valuation-membership}
Now let $A$ be an ACTUAL integrally closed domain and $K$ its genuine
fraction field, retaining the same proper $f$ and original $q$.
For EVERY original $s\in\Gamma(Y,\top)$ there is an original $a\in A$
whose image in $K$ is EXACTLY $\operatorname{ev}_q(s)$.
The source $Y$ need not be reduced for this field-image conclusion.
No normality or integrality of the source and no finite-type algebra
presentation of its section ring is required.
\end{theorem}
\begin{proof}
Let $R\subset K$ be the ACTUAL image subring of the original $A\to K$.
The actual range-restricted coefficient map $A\to R$ is surjective and
therefore integral. Its composite with the literal $R\hookrightarrow K$
is the ORIGINAL $A\to K$ on EVERY element, defining a true scalar tower.
Any original $z\in K$ integral over $R$ is therefore integral over $A$.
Actual normality of $A$ in its SAME fraction field puts $z$ in the original
coefficient image. This proves genuine integral closedness of $R$ in $K$
without introducing another fraction-field identification.

Mathlib's genuine valuation-subring intersection theorem identifies an
integrally closed subring of a field with the intersection of ALL valuation
subrings containing it. Equivalently, if the original
$\operatorname{ev}_q(s)$ were outside $R$, the proved valuation-domination
construction would provide an ACTUAL valuation subring containing $R$
but excluding that element. This contradicts the preceding theorem.
Thus the element lies in the ORIGINAL image $R$, giving a genuine $a\in A$.
The argument does not identify an original section with its generic value
when the source is nonreduced.
\end{proof}
