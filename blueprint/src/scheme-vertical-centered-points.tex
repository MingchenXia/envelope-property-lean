\subsection{Actual prescribed-Gauss points over every original vertical center}

\begin{theorem}[Every original vertical point is the TRUE center of an actual prescribed point]
\label{berkovich:original-vertical-point-prescribed-gauss-center}
\lean{EnvelopeProperty.Berkovich.RelativeSchemeValuedPoint.exists_gaussPoint_center_of_vertical}
\leanok
\uses{alggeom:original-stalk-essentially-finite-type,alggeom:original-stalk-coefficient-center,alggeom:original-stalk-coefficient-injective,algebra:actual-essentially-finite-type-centered-dvr-exists,berkovich:actual-dvr-prescribed-gauss-model-point}
Let $k$ be any original field and let $f:X\to\operatorname{Spec}k[t]$ be an
ACTUAL proper dominant morphism from an ACTUAL integral scheme. Every original
point $x$ of its ORIGINAL special fiber $t=0$ is the TRUE valuative model
center of an ACTUAL original relative native point over the SAME prescribed
trivial-coefficient Gauss valuation of radius $e^{-1}$.
No point, DVR, center, parameter nonvanishing, local nonfield structure,
coefficient-factorization or Gauss-base comparison is supplied. No normality,
smoothness, resolution or alteration is required.
\end{theorem}
\begin{proof}
The original coefficient map $k[t]\to\mathcal O_{X,x}$ is genuinely injective:
properness gives quasi-compactness, dominance over the actual reduced base gives
scheme-theoretic dominance, and the actual integral source has injective germs.
Consequently the ORIGINAL parameter is nonzero in the SAME stalk. The exact
coefficient-center contraction identifies its membership in the SAME stalk
maximal ideal with the original special-fiber condition on $f(x)$.
Thus this actual stalk is not a field.

The actual original scheme is locally finite type over $k$, by composing the
actual proper $k[t]$ structure map with the original polynomial coefficient
map. Its SAME original stalk is therefore essentially finite type over $k$.
The genuine centered DVR theorem constructs an actual subalgebra $V$ of the
ORIGINAL function field, with the EXACT original stalk maximal center.
Its actual spectrum map followed by the ORIGINAL stalk morphism gives a whole
$q:\operatorname{Spec}V\to X$ whose closed point maps EXACTLY to $x$.

Compose the original coefficient map with the literal inclusion of the stalk
into $V$. The whole stalk coefficient triangle gives the actual whole map
$qf=\operatorname{Spec}\phi$. Give $V$ its field-algebra structure through the
ORIGINAL composite $k\to k[t]\to V$. The polynomial universal property proves
that this SAME original $\phi$ is evaluation at its actual original parameter
$t_V=\phi(t)$. Injectivity of the original stalk-to-$V$ map makes $t_V\ne0$,
and the exact original center contraction puts $t_V$ in $\mathfrak m_V$.
Apply the actual prescribed-Gauss native-point producer to these derived data.
Its TRUE center is $q(\mathfrak m_V)=x$, proving the assertion with every
existence and comparison derived from the original geometric hypotheses.
\end{proof}
