\section{Genuine model norms of original global generating sections}

\begin{theorem}[An original global generator has actual model norm one]
\label{thm:actual-model-line-generator-norm-one}
\lean{EnvelopeProperty.Berkovich.RelativeSchemeValuedPoint.exists_modelLineNorm_generatorHom_eq_one}
\leanok
\uses{thm:actual-local-unit-generator,def:actual-generating-section-hom,lem:actual-line-fiber-section-model-norm}
Let $X$ be an actual proper model over a bounded valued coefficient ring,
$y$ an ORIGINAL relative valued point, and $M$ an actual invertible module
on $X$ with an original genuine global generating family $G$. Then some
SAME original generator, evaluated as its actual generic-fiber section at
$y$, has actual proper-model norm exactly $1$. The family need not be finite.
\end{theorem}
\begin{proof}
Properness constructs the TRUE original center lift from the actual residue
valuation ring of $y$. Pull the SAME original generating family back along
this actual lift and apply an actual whole valuative frame of $M$, whose
existence follows from invertibility. The actual unit-generator theorem
gives a generator with unit coefficient in this SAME original valuation
ring. The exact native generator pullback identity identifies this
coefficient with the actual center coefficient of the SAME original
generator morphism. The genuine fiber-section norm equals its model
morphism norm, and the latter is computed by this ACTUAL center frame.
The original residue valuation of an actual unit of its valuation ring is
$1$, proving the claim without an assumed norm or generation formula.
\end{proof}

\begin{corollary}[The actual supremum of generator norms is one]
\label{cor:actual-model-line-generators-sup-norm-one}
\lean{EnvelopeProperty.Berkovich.RelativeSchemeValuedPoint.iSup_modelLineNorm_generatorHom_eq_one}
\leanok
\uses{thm:actual-model-line-generator-norm-one}
Under the same assumptions, the supremum in $[0,+\infty]$ of the ACTUAL
model norms of ALL original generic-fiber generating sections is exactly
$1$. In particular this is the actual finite maximum for finite $G$.
\end{corollary}
\begin{proof}
Every actual original model morphism has norm at most one, since its
actual center-frame coefficient belongs to the TRUE valuation ring.
The preceding theorem supplies one of the SAME actual generator sections
with norm exactly one. These give the two required inequalities.
\end{proof}
