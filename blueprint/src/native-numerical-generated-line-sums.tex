\label{thm:native-numerical-generated-line-sums}

For every original native-projective $X$, its genuine original real
numerical line classes preserve whole original line isomorphisms,
actual tensor products and actual duals. Every original numerical
class admits an actual finite real expression
\[
 \theta=\sum_i a_i\bigl([L_i\otimes T]-[T]\bigr),
\]
where all $L_i$ are actual original invertible lines, a single
actual original denominator $T$ and every actual numerator
$L_i\otimes T$ have genuine internally produced finite global
generators. No global-generation, numerical-class, finite-family,
or numerator/denominator comparison certificate is supplied.
\end{theorem}

\begin{proof}
Map the genuine original real Picard line arithmetic through the
same actual numerical quotient linear map. Its actual additivity
and homogeneity preserve the original line-isomorphism, unit,
tensor and dual identities, so an actual whole quotient
isomorphism gives precisely subtraction of actual numerical
line classes.

Take the actual finite original invertible-line representation
of the given numerical class proved above. The native original
projectivity of $X$ internally supplies its finite polynomial
closed embedding over the same original coefficient field.
Apply the genuine simultaneous projective global-generation
theorem to that same finite family of original lines. It
constructs a single actual original invertible denominator $T$,
actual finite global generators of $T$, and actual finite global
generators of every original numerator $L_i\otimes T$. It also
constructs the entire original line isomorphism
$L_i\simeq(L_i\otimes T)\otimes T^\vee$. Apply the proved genuine
numerical quotient identity to this actual same-line
isomorphism, then substitute in the original finite expression.
The result is the stated exact expression for the original
numerical class, retaining every original line and the same
single actual denominator. These are globally generated lines;
no ample-cone comparison or model analytic psh invariance is
asserted or assumed by this theorem.
\end{proof}
