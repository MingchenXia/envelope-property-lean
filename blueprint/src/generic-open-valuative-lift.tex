\label{sec:generic-open-valuative-lift}

\begin{theorem}[The entire original generic point and its original affine triangle]
\label{sc0-generic-valuative:original-generic-point}
\lean{EnvelopeProperty.GenericOpenValuativeLift.genericFieldPoint,EnvelopeProperty.GenericOpenValuativeLift.genericFieldPoint_structure}
\leanok
There is an ACTUAL original field-valued point
$\operatorname{Spec}F\to Y$ constructed from the SAME native
generic stalk and the SAME coefficient-preserving original field
equivalence. Its ENTIRE composite with the original $p$ is exactly
the prescribed original map
$\operatorname{Spec}F\to\operatorname{Spec}R$.
No generic-point or coefficient-matching certificate is supplied.
\end{theorem}
\begin{proof}
The preceding theorem constructs the actual whole equivalence from
the SAME original native field $K(Y)$ to the SAME specified original
$F$. Apply the actual spectrum functor to its forward ring map and
then the SAME original generic-stalk point of $Y$. This gives the
actual original field-valued point.

The native original stalk coefficient map induced by $p$ is exactly
the original spectrum global coefficient followed by the actual
pullback and generic germ. The preceding field comparison preserves
EVERY original coefficient, so its composite with that entire native
stalk coefficient map is precisely the original map $R\to F$.
The already proved actual generic-stalk structural triangle and
contravariant spectrum composition therefore prove equality of the
ENTIRE original scheme maps, not just agreement at selected points.
\uses{sc0-generic-open-field:specified-original-fractions}
\end{proof}

\begin{theorem}[Actual lifts of every original valuation-ring diagram]
\label{sc0-generic-valuative:actual-whole-lifts}
\lean{EnvelopeProperty.GenericOpenValuativeLift.exists_valuative_lift}
\leanok
Suppose the original $p$ is universally closed. Let $V$ be ANY
actual original valuation ring over $R$ in the SAME specified
fraction field $F$, with its actual original coefficient tower
and actual fraction-field structure. There is an actual morphism
$\operatorname{Spec}V\to Y$ whose generic restriction is the SAME
original field-valued point above and whose ENTIRE composite with
$p$ is the prescribed original map from $R$ to $V$.
Both whole original triangles are DERIVED. No chosen lift, desired
localness, dominance, point or coefficient compatibility certificate
is supplied.
\end{theorem}
\begin{proof}
The actual original scalar tower makes the original maps from $R$
through $V$ into $F$ agree. Their genuine contravariant spectrum
composition and the preceding entire original generic-point triangle
construct the native original valuative commutative square for
$p$. Actual universal closedness gives the existence part of the
native valuative criterion. Apply it to this SAME actual square.
Its actual lift structure supplies a genuine original scheme map
and BOTH original equalities. No new comparison or geometric
regularity premise enters this construction.
\uses{sc0-generic-valuative:original-generic-point}
\end{proof}
