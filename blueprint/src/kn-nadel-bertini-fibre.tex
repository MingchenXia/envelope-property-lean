\section{Actual parameter fibres retain the original selected-section zero ideal}

The universal incidence is the original whole zero-ideal subscheme. To use
a good coefficient parameter for a divisor on the same original source,
one must retain the entire scheme structure through its parameter fibre.
This section constructs that comparison without a flatness assumption.

\]

\begin{proof}
