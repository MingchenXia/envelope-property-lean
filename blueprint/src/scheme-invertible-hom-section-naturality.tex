\section{Actual whole-map naturality of the invertible Hom--section correspondence}

\begin{theorem}\label{sc0-hom-section-naturality:composition}
\lean{EnvelopeProperty.SchemeInvertibleHomSection.equiv_comp}
\leanok
\uses{sc0-tensor-obj-morphisms:natural}
Let $A$ be the SAME actual original invertible module sheaf. Under the genuine original bijection between maps $A\to B$ and sections of $B\otimes A^\vee$, composition of the ENTIRE original map by $\psi:B\to C$ is exactly the SAME explicit original tensor map $\psi\otimes1_{A^\vee}$ applied to its original tensor-dual section.
\end{theorem}
\begin{proof}
The genuine original Hom--section bijection is the adjunction of the actual tensor equivalence obtained from the SAME invertible module and its true sheaf dual, with the original unit and explicit/monoidal tensor comparisons. The actual adjunction's right naturality identifies composition by the SAME original map with its image under the actual inverse tensor functor. That inverse functor is literally native tensor by the SAME original dual. The preceding entire-map naturality of the genuine tensor comparison identifies this actual native map with the SAME explicit sheafified tensor morphism. Composing the genuine unit and tensor comparisons gives precisely the asserted equality of entire original sections, without supplying a map-matching or naturality certificate.
\end{proof}

\begin{theorem}\label{sc0-hom-section-naturality:lift-factorization}
\lean{EnvelopeProperty.SchemeInvertibleHomSection.equiv_lift_iff}
\leanok
\uses{sc0-hom-section-naturality:composition}
The original tensor-dual section of an ENTIRE original map $\varphi:A\to C$ has an actual lift along the SAME original tensor map induced by $\psi:B\to C$ exactly when the ENTIRE original map $\varphi$ factors through that SAME original $\psi$.
\end{theorem}
\begin{proof}
An actual lifted original section corresponds, by the genuine original Hom--section bijection, to an actual original map $A\to B$. The preceding entire-map naturality and actual bijection injectivity identify its composite with the SAME original map $\varphi$. Conversely apply the same genuine bijection to any actual original factorization and use the same whole naturality identity. These are equivalent conclusions; no lift, factorization, local frame or image certificate is assumed as a premise.
\end{proof}
