\subsection{The same original paper modification on whole native points}

\begin{theorem}[The actual original paper projection is native-proper]
\label{scheme:paper-rees-native-proper}
\leanok
\uses{scheme:original-finite-rees-native-proper,scheme:paper-rees-proper-surjective-witness}
For ANY commutative ring $A$ and any actual finite set $s\subset A$, the
SAME original $\mu_s:\mathcal B_s\to\operatorname{Spec}A$ induces a proper,
hence closed native map. For ANY actual common coefficient structure
$\operatorname{Spec}A\to\operatorname{Spec}R$ and ANY prescribed valuation
of $R$, the actual exact-base relative map is also proper and closed.
In particular its genuine fixed-$v$ fibre for ANY valuation on $A$ is compact.
No domain, nonzero element, coefficient bounds, Noetherianity, or point
existence is assumed; empty original modifications remain allowed.
\end{theorem}
\begin{proof}
The original finite-set family is genuinely finite. Its literal original
Rees quotient closed immersion and the proved finite-index polynomial-Proj
native properness give the actual original Rees native projection properness.
The existing paper scheme and projection are the SAME family construction,
so no comparison or replacement of the scheme is needed. Properness gives
closedness. For the common prescribed base, use the genuine closed source
fixed-base inclusion, whole absolute proper map and continuous injective
target inclusion cancellation. The actual coefficient composition gives
membership, retaining the original native maps on every whole point.
The fixed-$v$ source is exactly the preimage of the singleton whole native
basepoint, so true properness gives its compactness.
\end{proof}

\begin{theorem}[Actual scheme surjectivity supplies every whole original valued lift]
\label{scheme:paper-rees-native-surjective}
\leanok
\uses{scheme:paper-rees-proper-surjective-witness,scheme:native-locally-finite-type-surjective,scheme:relative-native-locally-finite-type-surjective}
If $A$ is a domain and $s$ contains an actual nonzero original element, the
SAME native map of $\mu_s$ is surjective. The exact common prescribed-base
relative map is likewise surjective for ANY further coefficient structure
and prescribed valuation. The conclusions concern ENTIRE original points,
not just their supports. The fixed-$v$ fibre over each valuation on $A$ is genuinely nonempty.
No native lift or scalar-extension certificate is supplied.
\end{theorem}
\begin{proof}
The genuine original generic lift and proper closed image derive actual
scheme surjectivity of $\mu_s$ from the original domain and nonzero element.
Its actual algebraic properness includes locally finite type; no extra
finite-type hypothesis is inserted. Apply the proved locally-finite-type
native surjectivity theorem: the actual completed residue field of the
original whole target point, its real finite field point in the genuine
scheme fibre, and true complete-field norm extension give an entire native
source point whose whole image is the original target point. Exact
common-base membership follows from the entire commuting structure map,
so the relative lift retains ALL prescribed original coefficient values.
No separately prescribed source coefficient valuation is extended here.
Apply whole surjectivity to the genuine original basepoint $v$ to derive
nonemptiness of that exact fixed-$v$ fibre.
\end{proof}

\begin{theorem}[The original generator good open gives a genuine native isomorphism]
\label{scheme:paper-rees-native-good-open}
\leanok
\uses{scheme:actual-rees-good-open-isomorphism,scheme:native-base-open-modification}
For ANY commutative $A$, actual $j\in s$, and ANY valuation $v$ on $A$
with $v(j)\ne0$, the SAME original projection on the exact $v$ loci is a
homeomorphism, with its original whole point map, and each target has a
unique entire original source lift. No domain or nonzero-divisor hypothesis
is needed for this good-open assertion; $v(j)\ne0$ already excludes empty
cases at that prescribed point.
\end{theorem}
\begin{proof}
The checked actual original good-open lift identifies the ENTIRE inverse
image of $D(j)$ and its whole original coefficient triangle. Genuine open
immersion range isomorphisms identify its source with that true inverse
image, and the original localization spectrum with $D(j)$. The whole
triangle identifies the actual restricted projection with the composite
of these real isomorphisms, proving it is an actual scheme isomorphism,
not a supplied isomorphism certificate. The original basepoint has support
in $D(j)$ exactly because $v(j)\ne0$. The genuine base-open modification
homeomorphism therefore applies to this real restricted isomorphism.
Its whole point formula is exactly the original relative map, giving
both inverses and unique lifts while preserving every section value.
This does not assert injectivity over the original exceptional locus or
infer native density from scheme density.
\end{proof}
