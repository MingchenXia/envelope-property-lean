\subsection{An actual proper-surjective scheme for the paper's original blowup charts}
\begin{theorem}[The original finite-set blowup charts form an actual scheme cover]
\label{scheme:paper-rees-original-chart-cover}
\leanok
\uses{scheme:actual-rees-coordinate-cover,scheme:actual-rees-projection-surjective,paper:actual-rees-original-blowup-chart}
Let $A$ be any domain and $s\subset A$ any original finite set. The ORIGINAL
rings $A[s/g]$, indexed by $g\in s$ with $g\ne0$, form a genuine affine open
cover of the actual homogeneous Rees kernel-quotient scheme. The entire
structure morphism on each chart is exactly the original coefficient map
$A\to A[s/g]$. No enumeration, alternate ideal or comparison certificate is
supplied.
\end{theorem}
\begin{proof}
Use the actual finite-set subtype inclusion as the generator family. The
previous genuine nonzero-coordinate affine cover has exactly this index
type. The whole proved chart equivalence identifies each original homogeneous
degree-zero localization with the SAME original fractional algebra $A[s/g]$.
Apply Spec to this actual ring isomorphism and compose with the original
coordinate-chart immersion. Both morphisms are open immersions. Their ranges
are the same as the original chart ranges, because the Spec isomorphism is
surjective on the whole chart. Transport the actual cover through these real
isomorphisms; this gives actual rings, morphisms and pointwise coverage of the
SAME original scheme.

For the coefficient triangle, the genuine original Rees chart projection is
the Spec map of its full coefficient homomorphism. Composition with the true
Spec chart isomorphism is the original map $A\to A[s/g]$, since the actual
algebra equivalence preserves EVERY original coefficient. This proves equality
of whole scheme morphisms, including their section maps, not merely equality
of underlying scheme points.
\end{proof}

\begin{theorem}[A genuine proper-surjective scheme witness]
\label{scheme:paper-rees-proper-surjective-witness}
\leanok
\uses{scheme:paper-rees-original-chart-cover,scheme:actual-rees-projection-surjective}
If the original finite set contains a nonzero element, the SAME scheme
projection is proper and surjective onto $\operatorname{Spec}A$. It has the
actual affine cover by the original paper blowup rings and their entire
original coefficient triangles. This works over every domain, with no
Noetherianity, field, perfectness or completeness assumption.
\end{theorem}
\begin{proof}
The original subtype family is finite, so the actual polynomial Proj/Rees
quotient projection is proper. The given actual nonzero element determines
an actual subtype index with nonzero coefficient. The genuine fraction-field
generic lift constructed through its degree-zero chart and the proper closed
image argument give scheme surjectivity of this SAME original projection.
The preceding actual chart cover is retained unchanged. The subsequent
good-open isomorphism and birationality, and analytic curve pullback/descent,
are separate theorems and are not assumed as witness data.
\end{proof}
