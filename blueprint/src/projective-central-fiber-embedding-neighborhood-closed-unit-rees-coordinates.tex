\section{The actual unit-Rees homogeneous chart retains nilpotent coefficients}

Let $A$ be an arbitrary commutative ring, including the zero ring. In particular,
$A$ is not assumed a domain or reduced. All Rees algebras, gradings, projective
spectra, coefficient maps and chart inclusions below are the actual original ones.

\begin{lemma}[The original coefficient map identifies the whole actual unit chart]
\label{lem:central-embedding-generic-unit-rees-homogeneous-coefficient-equiv}
\lean{EnvelopeProperty.ProjectiveCentralFiberEmbeddingNeighborhoodClosedUnitReesCoordinates.homogeneousCoefficientEquiv}
\leanok
The actual coefficient homomorphism
$A\to\operatorname{Away}(\operatorname{Rees}(\top),T)$ is bijective and defines
an actual ring equivalence, retaining the SAME original coefficient map.
Here $T$ is the actual original degree-one Rees element associated to $1\in A$.
\end{lemma}
\begin{proof}
The original singleton unit presentation is an actual graded isomorphism from
the original one-variable homogeneous polynomial ring onto the actual unit-Rees
algebra, over arbitrary $A$. Its native Proj map identifies the actual unit
blowup with projective zero-space. The only actual coordinate open in projective
zero-space is the whole scheme. Actual native Proj inverse-image of that original
coordinate open is the actual $T$ basic open. Consequently the original $T$
basic open is the whole actual blowup, and its original homogeneous-chart
inclusion is an isomorphism.
The original structure map of the unit blowup is an isomorphism over arbitrary
$A$. Thus the actual chart inclusion composed with this SAME original structure
map is an isomorphism. Native homogeneous chart/degree-zero structure naturality
identifies this actual composite with Spec of the actual original coefficient
homomorphism above, including the original Rees constant map. Spec reflects
isomorphisms of these actual affine schemes, so that actual coefficient map is
bijective. Form its genuine ring equivalence from this proved bijectivity.
No fraction field, domain hypothesis or coefficient-isomorphism certificate is input.
\end{proof}

\begin{lemma}[The actual original unit-chart fraction retains every coefficient]
\label{lem:central-embedding-generic-unit-rees-inverse-generator}
\uses{lem:central-embedding-generic-unit-rees-homogeneous-coefficient-equiv}
\lean{EnvelopeProperty.ProjectiveCentralFiberEmbeddingNeighborhoodClosedUnitReesCoordinates.homogeneousCoefficientEquiv_symm_generator}
\leanok
For every SAME original $a\in A$, the original inverse ring equivalence sends
the actual original degree-zero homogeneous fraction $(aT)/T$ to $a$.
\end{lemma}
\begin{proof}
Apply the proved forward equivalence. Its actual value at $a$ is the original
homogeneous-localization image of the original degree-zero constant $a$.
In the ordinary localization underlying the actual homogeneous localization,
this equals the original fraction $(aT)/T$: cross multiplication gives the
literal original Rees equality $a\cdot T=aT$, with multiplier $1$.
The original homogeneous-localization value map is injective, so the equality
holds in the actual degree-zero homogeneous ring. Applying the actual inverse
equivalence proves the claimed original coefficient equality. The argument
retains nilpotents and uses no cancellation by a nonzero divisor or fraction field.
\end{proof}

\begin{lemma}[The same original blowup inverse has its true whole homogeneous-chart formula]
\label{lem:central-embedding-generic-unit-rees-original-inverse-chart}
\uses{lem:central-embedding-generic-unit-rees-homogeneous-coefficient-equiv}
\lean{EnvelopeProperty.ProjectiveCentralFiberEmbeddingNeighborhoodClosedUnitReesCoordinates.inverse_homogeneousChart}
\leanok
The inverse of the SAME actual unitIdealBlowupIso is Spec of the actual inverse
coefficient ring equivalence followed by the SAME actual $T$ homogeneous-chart
inclusion, as an equality of entire original scheme morphisms.
\end{lemma}
\begin{proof}
Compose both proposed original maps with the original unit blowup structure
