\section{Actual geometric fibre cohomology specialization}

\begin{lemma}[The actual geometric fibre group is the original tensor homology]
\label{lem:kn-derived-geometric-fibre-cohomology}
\uses{lem:kn-derived-original-scalar-coefficients,lem:kn-derived-original-scalar-sheaf-cohomology,thm:kn-geometric-cech-base-change}
\lean{EnvelopeProperty.Vanishing.SpecializationDerivedGeometricCohomology.fibre_H_iff_tensor_homology_zero}
\leanok
On an actual finite ordered affine cover of a separated original
scheme, positive native sheaf cohomology of the actual scalar-base-change
pullback of an invertible module vanishes if and only if the native
homology of the scalar-extended original ordered section complex
vanishes.  The base ring and scalar map are the literal original
$R\to S$, including nonflat residue maps.
\end{lemma}
\begin{proof}
Use the independently constructed whole ordered \v{C}ech tensor-complex
isomorphism from canonical affine Cartesian section comparisons.
The actual inverse-image cover is finite, affine and covering.
The actual pulled-back invertible module is quasicoherent.  The
proved affine-cover \v{C}ech/sheaf-cohomology comparison identifies
its positive native sheaf cohomology with the target ordered
homology.  The actual coefficient restriction and actual
positive-degree segment isomorphisms give the asserted equivalence.
\end{proof}

\begin{theorem}[Original proper flat fibre cohomology specializes]
\label{thm:kn-derived-geometric-cohomology-specialization}
\uses{lem:kn-derived-geometric-fibre-cohomology,lem:kn-derived-projective-coordinate-complex,thm:kn-derived-natural-cochain-specialization}
\lean{EnvelopeProperty.Vanishing.SpecializationDerivedGeometricCohomology.exists_fibre_cohomology_zero_neighborhood,EnvelopeProperty.Vanishing.SpecializationDerivedGeometricCohomology.generic_fibre_cohomology_subsingleton_of_closed_fibre}
\leanok
Let $f:X\to\operatorname{Spec}R$ be an actual flat projectively
factored morphism over a Noetherian ring, and $M$ an actual invertible
module on $X$.  If the actual positive-degree sheaf cohomology of
its pullback to an original closed residue fibre vanishes, the same
group vanishes on the actual fibres over all field-valued points
of a produced original principal neighborhood.  Over an original
domain this yields vanishing on the actual original generic fibre.
\end{theorem}
\begin{proof}
Produce an actual ordered coordinate cover, bounded flat section
complex and independently finite native homology from projectivity.
Restrict its coefficients along the canonical ring isomorphism,
retaining the original $R$ action.  Convert the given actual
residue sheaf group into original tensor homology by the proved
geometric comparison.  Apply the constructed finite-free
specialization producer and convert its field outputs back to
actual fibre sheaf cohomology.  Beyond the cover bound the actual
middle section term is zero.  The original domain embeds into its
actual fraction field, which gives the generic-fibre case.
\end{proof}

\begin{corollary}[A prescribed original ambient field]
\label{cor:kn-derived-geometric-cohomology-injective-field}
\uses{thm:kn-derived-geometric-cohomology-specialization}
\lean{EnvelopeProperty.Vanishing.SpecializationDerivedGeometricCohomology.fibre_cohomology_subsingleton_of_closed_fibre_of_injective}
\leanok
The same vanishing reaches any prescribed field $F$ into which the
original arithmetic ring embeds.  In particular, the original
characteristic-zero field need not equal the arithmetic ring's
fraction field.
\end{corollary}
\begin{proof}
The produced original scalar $r\notin\mathfrak p$ is nonzero.
Its image remains nonzero under the actual injective coefficient
map $R\to F$, so the field-valued principal-open conclusion applies
directly to that actual original fibre.
\end{proof}

\begin{remark}[Arithmetic model application]
This is a specialization producer for an original invertible module.
The characteristic-zero Kodaira application must still construct its
arithmetic model, compare the original top exterior/canonical module
under the prescribed residue and generic pullbacks, and obtain the
residue vanishing from the positive-characteristic DI deduction.
None of those conclusions is an assumption disguised as a
cohomology base-change comparison here.
\end{remark}
