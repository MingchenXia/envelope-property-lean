\subsection{Original analytic restriction is the literal original scheme projection}

\begin{definition}[Literal original variety-product projection]
\label{local:actual-original-product-scheme-projection}
\lean{EnvelopeProperty.ProjSubvariety.nativeProductOriginalProjection, EnvelopeProperty.ProjSubvariety.nativeProductOriginalProjection_inclusion, EnvelopeProperty.ProjSubvariety.nativeProductOriginalProjection_over_base}
\leanok
\uses{local:actual-product-original-analytic-restriction}
For the SAME original native variety and original product ideal subscheme,
use the actual ideal-comap pullback isomorphism and its original second
projection to define the literal scheme map from the original product to
the original variety. Its composite with the SAME original closed
inclusion is exactly the ambient original product first projection after
the original product inclusion. Its original field-base square commutes
with the literal coefficient inclusion $k\to k[t]$.
\end{definition}
\begin{proof}
The actual ideal-comap object is the native pullback of the original
closed subscheme along the ambient product first projection. Compose
its actual pullback isomorphism with the native second projection.
The genuine pullback condition and the actual ideal-comap isomorphism
first-projection identity prove the whole closed-inclusion square.
Compose it with the original polynomial projective structure morphism
and use the original ambient product pullback condition to prove the
whole original field-base square. These are equalities of actual scheme
morphisms, not conditions supplied with a new projection datum.
\end{proof}

\begin{theorem}[Whole original analytic restriction equals actual scheme projection]
\label{local:actual-product-restriction-native-projection}
\lean{EnvelopeProperty.ProjSubvariety.nativeAnalyticHomeomorph_nativeProductBaseRestriction}
\leanok
\uses{local:actual-original-product-scheme-projection, projective:actual-relative-native-coefficient-naturality, local:actual-product-original-analytic-restriction}
For EVERY actual relative point $y$ of the SAME original variety product
over the prescribed polynomial Gauss valuation, apply the actual original
variety analytic/native homeomorphism to the derived original analytic
restriction. The result is EXACTLY the WHOLE native point obtained by
the literal original scheme projection over $k\to k[t]$. Thus the same
original residue valuation and entire scheme point are preserved,
without a coordinate-only comparison or additional preservation premise.
\end{theorem}
\begin{proof}
Map both candidate original variety points through the actual original
closed inclusion. Its whole native point map is injective. The actual
original analytic/native comparison preserves the SAME whole inclusion
point, so the first side becomes the whole native point of the actual
normalized coefficient restriction. The preceding generic whole native
coefficient-naturality theorem identifies this with the actual native
coefficient morphism on the entire original normalized polynomial point.
The true first-projection identity for the whole polynomial-product
isomorphism identifies it with the ambient original product projection
of the SAME entire original product point. Finally the literal original
projection/inclusion square identifies this with the closed-inclusion
image of the actual original variety projection of $y$. Injectivity of
the whole original closed-inclusion point map finishes the equality,
retaining the original residue valuations through every actual map.
\end{proof}
