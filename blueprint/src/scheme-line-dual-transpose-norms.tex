\begin{theorem}[True original transpose model norm]
\label{thm:actual-dual-transpose-model-norm}
\lean{EnvelopeProperty.Berkovich.RelativeSchemeValuedPoint.modelHomNorm_dualTranspose}
\leanok
\uses{lem:actual-invertible-dual-transpose-pairing,lem:actual-model-tensor-hom-norm,lem:actual-model-hom-norm-composition,cor:actual-model-hom-norm-identity-isomorphism}
The genuine model morphism norm of the actual canonical original
dual transpose of $\alpha:M\to\mathcal O_X$ equals the genuine
model morphism norm of the original $\alpha$ itself.
\end{theorem}
\begin{proof}
Tensor the actual transpose with the original identity of $M$.
Actual tensor morphism norm multiplicativity and the original
identity norm one say that this tensor morphism has norm equal to
the original transpose norm. The actual whole transpose pairing
identity says that following it by actual canonical evaluation
is the true original right-unit comparison followed by $\alpha$.
Both the actual canonical evaluation and the actual right-unit
comparison are whole original line-module isomorphisms, hence
have genuine model morphism norm one. True original composition
norm multiplication therefore says that the same tensor morphism
norm is exactly the model norm of $\alpha$. These two equalities
prove the assertion without a dual metric compatibility input.
\end{proof}
