\section{The actual coefficient-open cover of original unit-module generators}

\begin{definition}[The original generator coefficient]
\label{def:fc-original-generator-coefficient-opens}
\leanok
\lean{EnvelopeProperty.SchemeGeneratorCoefficientOpens.coefficient, EnvelopeProperty.SchemeGeneratorCoefficientOpens.coefficient_eq, EnvelopeProperty.SchemeGeneratorCoefficientOpens.generatorHom_pullback_unitScalar, EnvelopeProperty.SchemeGeneratorCoefficientOpens.coefficient_pullback}
\uses{def:fc-original-section-whole-frame-scalar}
For an actual original generating family $G$ of $O_X$, its original
$i$-th generator is the same free basis inclusion followed by the
original evaluation epimorphism. Its coefficient $c_i$ is the actual
original top-open value at one. Under any literal original pullback,
followed by the actual structure-line comparison, this same original
generator is multiplication by the actual pulled coefficient.
\end{definition}
\begin{proof}
The original generating family pulls back with its same original
basis indices and unit comparison. Native unit scalar naturality
therefore identifies the pulled original generator with scalar
multiplication by the actual pulled top-open coefficient.
\end{proof}

\begin{theorem}[These true coefficient opens cover the same original scheme]
\label{thm:fc-original-generator-coefficient-cover}
\leanok
\lean{EnvelopeProperty.SchemeGeneratorCoefficientOpens.exists_mem_basicOpen, EnvelopeProperty.SchemeGeneratorCoefficientOpens.iSup_basicOpen_eq_top, EnvelopeProperty.SchemeGeneratorCoefficientOpens.span_coefficients_eq_top, EnvelopeProperty.SchemeGeneratorCoefficientOpens.generatorFrame, EnvelopeProperty.SchemeGeneratorCoefficientOpens.generatorFrame_section}
\uses{def:fc-original-generator-coefficient-opens, thm:fc-original-section-basic-open-frame}
The actual original basic opens $D(c_i)$ cover the entire same
original scheme $X$, with no finiteness requirement on $G$. If $X$ is
affine, the actual entire original coefficient ideal $(c_i)_i$ is the
unit ideal. Each original generator is a genuine whole frame on its
actual original coefficient open, with the same pulled section
exactly one in the inverse frame.
\end{theorem}
\begin{proof}
At any original point $x$, pull the original generating family to the
spectrum of the same original local stalk and use the genuine
structure-line comparison. A generating family of the local-spectrum
unit line has an actual unit coefficient, derived by pulling to its
actual residue field. The native original stalk-spectrum coefficient
square identifies this coefficient with the original germ of one
$c_i$. Thus $x\in D(c_i)$, proving the whole cover. On an affine
scheme the genuine affine basic-open cover criterion identifies this
whole cover with generation of the unit ideal by the same original
coefficients. The actual section basic-open producer gives the
claimed canonical frame and its whole coefficient-one identity.
\end{proof}
