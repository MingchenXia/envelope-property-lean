\section{The actual original closed-curve nef cone}
\label{sec:native-numerical-nef-cone}

\begin{theorem}[Genuine closed-curve inequalities in the same numerical quotient {\cite[\S1.2]{BJ22}}]
\label{thm:native-numerical-nef-cone}
\lean{EnvelopeProperty.NativeRealNumericalClasses.nefCone, EnvelopeProperty.NativeRealNumericalClasses.mem_nefCone, EnvelopeProperty.NativeRealNumericalClasses.nefCone_pointed, EnvelopeProperty.NativeRealNumericalClasses.nefCone_salient, EnvelopeProperty.NativeRealNumericalClasses.nefCone_smul_nonneg, EnvelopeProperty.NativeRealNumericalClasses.lineClass_mem_nefCone_iff, EnvelopeProperty.NativeRealNumericalClasses.lineFamilyMap_mem_nefCone_iff}
\leanok
\uses{thm:native-real-numerical-classes, thm:native-numerical-line-family-maps}
In the same genuine original real numerical quotient, the classes
with nonnegative true degree on every actual original closed
integral curve form a convex cone containing zero. This cone
contains no nonzero class together with its negative. Its
membership test on every original invertible line is exactly
nonnegativity of the full original Euler degree of that same line
pulled back to every actual original closed integral curve. Its
inverse image on the entire real coefficient space of any actual
finite original line family is exactly the simultaneous true
curve-degree inequalities for that same family.
\end{theorem}

\begin{proof}
Define the cone by the simultaneous inequalities for the actual
descended degree functionals. Each true functional is real-linear,
so the inequalities are preserved under addition and nonnegative
real multiplication, and hold at zero. If a class and its negative
both satisfy them, each true degree is both nonnegative and
nonpositive and therefore zero. The actual joint equality
detection by all original closed-curve degree functionals then
makes the class zero in the same numerical quotient. Invertible
line membership follows by the already proved equality between
its true descended degree and the full original Euler degree of
its whole original curve pullback. Apply the proved whole
finite-line-family degree formula to obtain the exact simultaneous
inequalities on coefficients. No arbitrary curve-map comparison,
finite dimensionality, topological closedness, ample-cone
comparison, or generation of this cone is assumed or concluded
here.
\end{proof}
