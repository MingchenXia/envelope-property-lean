\section{One genuine source-convex family for the entire original component}

Retain the actual proper dominant integral $f:Y\to\operatorname{Spec}k[t]$,
the actual integral closed immersion $i:C\hookrightarrow Y$, and the
actual vertical $\eta=i(\eta_C)$. One original Noetherian stalk with a
genuine prime component equation and actual stalk-map kernel is given.
Use the prescribed paper radius $r=\exp(-1)$ and the SAME original native
space $\mathcal Y_r$ of points over this Gauss valuation.
Let $u:\mathcal Y_r\to\overline{\mathbb R}$ and let
\(h_u:\operatorname{IsConvexPLOn}(U,u)\) be the literal original
regular-unit source definition.

\begin{theorem}[One original source presentation and one actual active set for all points]
\label{thm:gauss-common-original-convex-family}
\uses{thm:gauss-common-one-original-vertical-point,scheme:native-regular-unit-local-psh,lem:gauss-native-original-unit-profiles,lem:gauss-native-original-stalk-point-sequence,analysis:actual-finite-affine-active-max}
\lean{EnvelopeProperty.GaussCommonConvexProfiles.exists_common_convex_profiles}
\leanok
There is an INTERNALLY chosen original native point $q_C$, with true
center $\eta$ and original generic support, such that the honest original
applicability condition $q_C\in U$ gives the following data chosen ONCE:
an actual open native neighborhood $W\subseteq U$ of $q_C$, an original
Zariski open $V$, a finite family of original regular units
\(a_1,\ldots,a_n\in\Gamma(Y,V)^\times\), and a nonempty finite set
\(I\subseteq\mathbb Q^n\times\mathbb Q\). Every original point of $W$
is supported in $V$, and the unchanged original function satisfies
\[
 u(q)=\max_{j\in I}\left(\sum_{\ell=1}^n
       j_\ell\log|a_\ell(q)|+j_{\rm const}\right)
 \quad(q\in W).
\]
The values of the maximum are interpreted in the original extended real
co\-domain. Put
\[
 \beta_j=\sum_\ell j_\ell\log|a_\ell(q_C)|+j_{\rm const},\qquad
 M=\max_{j\in I}\beta_j,\qquad
 I_0=\{j\in I:\beta_j=M\}.
\]
This SAME actual $I_0$ is nonempty and is chosen before varying the
original point $x\in C$. In particular $u(q_C)=M$ is finite.

For EVERY original $x\in C$ with actual Noetherian stalk
$S=\mathcal O_{Y,i(x)}$, actual regular parameters
$\mathfrak m_S=(\pi,z)$, $\pi$ prime, $\pi\nmid z$, and the TRUE
component equation $\ker(i_x^\#)=(\pi)$, internally derive the original
parameter conditions $t_x\ne0$ and $\pi\mid t_x$.
There are internally produced $e>0,c\in\mathbb N$,
$A_\ell,B_\ell\in\mathbb Z$, and actual units
$v_\ell\in S_{(\pi)}^\times$ as follows. The integer $e$ is the true
original vertical order of $t_x$; the SAME original global rational
function represented by $a_\ell$ is, in the SAME original
$\operatorname{Frac}S$, exactly $v_\ell\pi^{A_\ell}$.
Its native vertical order is $A_\ell$, and the native order of the
canonical leading function of $v_\ell$ in
$\operatorname{Frac}(S/(\pi))$ is $B_\ell$.
No order pair or leading coefficient is supplied.

Let $q_{x,m}$ be the SAME existing native weighted point with $N=m+1$,
let $d_{x,m}$ be the true original weighted order of $t_x$, and put
\[
 \varepsilon_{x,m}=\frac{-\log r}{d_{x,m}},\quad
 \gamma_{\ell,x}=B_\ell-\frac{A_\ell}{e}c,\quad
 s_{j,x}=-\sum_\ell j_\ell\gamma_{\ell,x},\quad
 D_x=\max_{j\in I_0}s_{j,x}.
\]
For all sufficiently large $m$, the ORIGINAL parameter and function obey
\[
 \begin{gathered}
 d_{x,m}=e(m+1)+c,\qquad
 u(q_{x,m})=M+D_x\varepsilon_{x,m},\\
 \frac{u(q_{x,m})^{\rm real}-u(q_C)^{\rm real}}
      {\varepsilon_{x,m}}=D_x.
 \end{gathered}
\]
The last actual quotient tends to $D_x$. Both asserted function values
are the true finite values of the original extended-real function.
All original units, rational indices, intercepts and active indices are
the SAME for every $x$. Only the internally derived native local orders
and resulting slopes depend on $x$.
\end{theorem}
\begin{proof}
Use the already frozen actual common-point producer once. It internally
gives $q_C$, its original generic support and true center, and for every
original component point the original parameter facts and the literal
whole equality $q_{\mathrm{vert},x}=q_C$.
Retain $q_C\in U$ as the original applicability condition; if this point
does not belong to $U$, no source-convex conclusion there is asserted.
Apply the ORIGINAL $h_u$ exactly ONCE at this actual $q_C$. Its definition
gives the actual $W,V,a,I$ and the displayed original-function equality.
Evaluate it at $q_C$ to get $u(q_C)=M$. Attainment of a nonempty finite
maximum gives the nonempty actual $I_0$. These choices precede all local
point or parameter choices.

Now fix ANY original $x$ and its genuine stated local geometric data.
The common-point theorem derives $t_x\ne0$, $\pi\mid t_x$ and
$q_{\mathrm{vert},x}=q_C$ internally. The latter equality places the
unchanged vertical point in the SAME $V$.
Apply the OLD arbitrary-given-unit-family profile producer to this SAME
family $a$, rather than extracting another presentation from $h_u$.
It internally produces the actual $e,c,A_\ell,B_\ell,v_\ell$, all exact
native factorization and order identities, and, eventually,
\[
 \log|a_\ell(q_{x,m})|
 =\log|a_\ell(q_{\mathrm{vert},x})|
   -\varepsilon_{x,m}\gamma_{\ell,x}.
\]
Whole native-point equality changes the baseline on the right to the
SAME $q_C$, retaining every original section and its actual value.
The existing original-point convergence theorem and that same point
equality imply $q_{x,m}\to q_C$ in the actual native topology. Consequently
these points eventually belong to the SAME original open $W$.

Distribute the finite rational linear combination of the genuine unit-log
identities. Every original affine term on those same native points is
exactly $\beta_j+s_{j,x}\varepsilon_{x,m}$, with the SAME global intercepts
$\beta_j$. Apply the existing actual finite-affine maximum theorem for this
local finite slope family and these SAME $I,\beta$. It derives a positive
threshold below which the whole maximum equals
$M+\max_{j\in I_0}s_{j,x}\varepsilon$.
The actual positive original scales tend to zero, so the threshold,
the unit profiles and membership in $W$ hold simultaneously eventually.
Substitution in the unchanged original source formula gives the exact
extended-real equality $u(q_{x,m})=M+D_x\varepsilon_{x,m}$, together with
the true parameter-order identity from the old unit profile theorem.
Both sides are finite; apply the actual real-part map, subtract the true
$u(q_C)=M$, and divide by the strictly positive actual scale to get the
displayed exact quotient. Eventual equality to the constant $D_x$ proves
its limit. The argument did not change the once-chosen $W,V,a,I,\beta,I_0$
when $x$ was fixed.
\end{proof}

No common presentation, active-set certificate, local profile, order pair,
field isomorphism, or native-point matching is an input. This theorem does
not identify local leading functions with global functions on $C$, derive
their two principal balances, or assert weighted degree nonnegativity.
Those genuine remaining geometric and numerical producers are separate.
