\section{Genuine original Cartier-ideal degrees on arbitrary integral projective curves}

\begin{theorem}[Original Cartier equations derive proper support and true finiteness]
\label{thm:fc-curve-cartier-ideal-finite}
\leanok
\lean{EnvelopeProperty.CurveCartierIdealDegrees.support_ne_top, EnvelopeProperty.CurveCartierIdealDegrees.subscheme_comp_isFinite}
\uses{thm:fc-curve-finite-closed-subschemes}
On any original integral scheme, actual Cartier regular local equations
exclude the original generic point from the original ideal support.
Consequently, on an actual original proper integral curve over any field,
the SAME original Cartier ideal gives a genuinely finite original closed
structure morphism, with no support or finite-divisor premise supplied.
\end{theorem}
\begin{proof}
Choose the actual Cartier equation on an original affine neighborhood of
the same original generic point. The original integral section ring makes
that nonzerodivisor nonzero. Original integral germ injectivity makes its
actual generic germ nonzero, hence a unit in the actual original function
field. Thus the generic point lies in the original basic open of that
original equation, contradicting membership in its actual ideal zero locus.
The support is therefore proper. Apply the actual preceding proper curve
finiteness producer to that same original ideal and closed immersion.
\end{proof}

\begin{theorem}[True original curve tensor and ratio degrees without finite certificates]
\label{thm:fc-curve-cartier-ideal-degrees}
\leanok
\lean{EnvelopeProperty.CurveCartierIdealDegrees.normalizedEulerCharacteristic_toModules, EnvelopeProperty.CurveCartierIdealDegrees.normalizedEulerCharacteristic_tensor_toModules, EnvelopeProperty.CurveCartierIdealDegrees.normalizedEulerCharacteristic_ratioModule, EnvelopeProperty.CurveCartierIdealDegrees.normalizedEulerCharacteristic_ratioModule_eq_weighted_difference}
\uses{thm:fc-curve-cartier-ideal-finite, thm:fc-geometric-ideal-euler-degree}
On ANY actual original integral projective curve of dimension at most one,
the SAME original geometric Cartier ideal has normalized full Euler degree
minus its true original closed degree. Tensoring it with ANY actual original
line adds their true full Euler degrees. The SAME original geometric
Cartier ratio line has the difference of its original ideal degrees, or
equivalently its denominator's true residue-weighted local degree sum minus
its numerator's. These sums retain the original closed-scheme points,
actual original stalk lengths and ORIGINAL ambient residue fields over the
same original field. No support, finite-divisor, compactness, separatedness,
normality, smoothness or degree-comparison certificate is assumed.
\end{theorem}
\begin{proof}
The actual original projective factorization gives properness. Genuine
quasi-compactness over the actual field spectrum derives compactness; the
original proper morphism followed by the separated field structure derives
separatedness. The preceding Cartier support and actual curve finiteness
producer internally give each original finite closed structure morphism.
Apply the genuine original geometric ideal, tensor, dual and ratio degree
formulas to these SAME original objects. Every auxiliary geometric premise
is derived from the actual curve, actual projective morphism and ordinary
original Cartier local equations.
\end{proof}
