\section{Every original projective line bundle is a genuine Cartier ratio}

\begin{theorem}[Whole original dual evaluation produces the actual section ratio]
\label{thm:fc-original-line-section-ratio-iso}
\leanok
\lean{EnvelopeProperty.ProjectiveLineCartierRatio.doubleDualLineIso, EnvelopeProperty.ProjectiveLineCartierRatio.sectionRatioIso}
\uses{thm:fc-original-line-zero-ideal-module}
An original invertible module is isomorphic to its actual double dual,
derived from the two genuine evaluation tensor-inverse pairs. If the
SAME original invertible modules $L,T$ have actual original nonzero
sections $s:\mathcal O_X\to L\otimes T$ and
$t:\mathcal O_X\to T$, then the actual original zero ideals give
\[
 Z(t)^{\sim}\otimes (Z(s)^{\sim})^\vee\simeq L
\]
on the SAME original integral scheme, as a WHOLE original module
isomorphism.
\end{theorem}
\begin{proof}
Tensoring by the original dual line is genuinely fully faithful. The
actual evaluations $L\otimes L^\vee\simeq\mathcal O_X$ and
$L^{\vee\vee}\otimes L^\vee\simeq\mathcal O_X$ therefore produce
the whole original double-dual isomorphism. No supplied bidual map is
needed for this existence statement.

The actual single-section theorem gives
$Z(t)^{\sim}\simeq T^\vee$ and
$Z(s)^{\sim}\simeq(L\otimes T)^\vee$. Actual contravariant duality
and the preceding true double-dual isomorphism consequently identify
the asserted actual ratio with $T^\vee\otimes(L\otimes T)$.
The genuine original symmetry, associativity and evaluation
$T\otimes T^\vee\simeq\mathcal O_X$ give the stated WHOLE original
line isomorphism.
\end{proof}

\begin{theorem}[An original projective line has an internally produced Cartier ratio]
\label{thm:fc-original-projective-line-cartier-ratio}
\leanok
\lean{EnvelopeProperty.ProjectiveLineCartierRatio.exists_cartier_ratio_of_embedding, EnvelopeProperty.ProjectiveLineCartierRatio.exists_cartier_ratio}
\uses{thm:fc-original-line-section-ratio-iso, thm:fc-original-line-eventual-nonzero-sections, thm:line-section-zero-ideal-cartier}
For ANY original projective morphism from an original integral scheme
and ANY SAME original invertible module $L$, there are actual effective
Cartier ideals $I,J$ on the SAME original scheme and a WHOLE original
isomorphism
\[
 L\simeq I^{\sim}\otimes(J^{\sim})^\vee.
\]
No normality, curve-dimension bound, chosen embedding, meromorphic frame,
rational section, divisor, Cartier pair, numerical datum or comparison
isomorphism is supplied.
\end{theorem}
\begin{proof}
The actual projective factorization supplies an actual original closed
immersion into finite polynomial projective space. Genuine eventual
projective generation internally produces a degree $d$ and an original
nonzero section of $L\otimes T$ for the SAME actual pulled-back $O(d)$
line $T$. Actual coordinate generation supplies an original nonzero
section of that SAME $T$, including degree zero. The original integral
scheme is nonempty, so the true nonzero-generator theorem applies.
The existing genuine nonzero-section theorem makes both actual original
zero ideals effective Cartier. The preceding whole original section-ratio
isomorphism yields $L$ as the SAME ratio of those actual ideals. Every
section, degree bound, Cartier fact and whole comparison is constructed
from the stated original projective geometry.
\end{proof}
