\section{Canonical original generator frames near every original point}

\begin{theorem}[Actual local coefficients give genuine original section frames]
\label{thm:fc-generator-section-unit-neighborhood}
\leanok
\lean{EnvelopeProperty.SchemeGeneratorFrameNeighborhoods.homOfLE_topIso, EnvelopeProperty.SchemeGeneratorFrameNeighborhoods.basicOpen_localCoefficient_isUnit, EnvelopeProperty.SchemeGeneratorFrameNeighborhoods.section_isIso_on_basicOpen, EnvelopeProperty.SchemeGeneratorFrameNeighborhoods.generatorFrame, EnvelopeProperty.SchemeGeneratorFrameNeighborhoods.generatorFrame_section, EnvelopeProperty.SchemeGeneratorFrameNeighborhoods.localCoefficient_generatorFrame}
For a genuine original line frame over an original open $U$, let
$c$ be the actual coefficient of an original whole section. On the
actual original basic open $D(c)\subset U$, that same original
section is an isomorphism from the structure line to the original
pulled line. Its inverse is a canonical frame taking this same
section to one.
\end{theorem}
\begin{proof}
The original restriction map carries $c$ to a unit on its genuine
basic open. The entire native section/frame scalar identity pulls
back through the literal inclusion $D(c)\to U\to X$. Multiplication
by this actual unit is an isomorphism, so the actual section is an
isomorphism too. Its inverse has the asserted coefficient-one
identity by the actual inverse identities.
\end{proof}

\begin{theorem}[Actual generators internally produce a whole affine section-frame cover]
\label{thm:fc-generator-section-frame-cover}
\leanok
\lean{EnvelopeProperty.SchemeGeneratorFrameNeighborhoods.exists_affine_generator_frame}
\uses{thm:fc-generator-section-unit-neighborhood}
Every actual generating family of an original invertible line on
an original scheme gives an original affine neighborhood of every
original point on which one SAME original global generator is an
isomorphism. No generating-family finiteness or supplied cover is
needed.
\end{theorem}
\begin{proof}
Choose a genuine original affine frame around the original point.
Its actual original generator coefficients generate the whole
structure line, and their original basic opens cover this affine
scheme. Choose one containing the original point. Its image in the
original scheme is the genuine original coefficient basic open,
which is affine. The preceding actual coefficient-unit argument
proves that this SAME generator is an isomorphism there.
\end{proof}
