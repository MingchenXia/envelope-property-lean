\section{The actual original Rees DVR is centered at the actual local maximal ideal}
\begin{theorem}[Exact center for an actual original maximal-primary ideal]
\label{thm:actual-rees-local-center}
Let $B$ be an actual local domain, $K$ its actual fraction field, and
$x$ an ACTUAL original Rees index of the original generator family $g$,
with actual Noetherian normalized selected chart. If
$\sqrt{(g_i)}=\mathfrak m_B$, then the contraction of the maximal ideal
of the SAME original Rees DVR along the original $B\to V_x$ is EXACTLY
$\mathfrak m_B$. No center or generator-nonunit certificate is supplied.
\lean{EnvelopeProperty.reesValuationRing_maximalIdeal_comap_eq}
\leanok
\end{theorem}
\begin{proof}
The actual selected original generator belongs to the actual selected
center prime by the definition of an original Rees index. Localization
therefore makes it a nonunit in the SAME original DVR. It divides EVERY
original generator there, so the image of the entire original ideal
lies in the actual maximal ideal. Its contracted prime contains the
radical, hence contains $\mathfrak m_B$. It is proper because the target
maximal ideal is proper. Maximality of $\mathfrak m_B$ forces equality.
\end{proof}
