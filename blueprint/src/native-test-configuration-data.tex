\section{Literal original test configurations and their derived model geometry}
\label{sec:native-test-configuration-data}

\begin{definition}[The original test-configuration data]
\label{def:native-test-configuration-data}
\lean{EnvelopeProperty.NativeTestConfiguration.pointOne, EnvelopeProperty.NativeTestConfiguration.pointOne_left, EnvelopeProperty.NativeTestConfiguration.totalOver, EnvelopeProperty.NativeTestConfiguration.structureOver, EnvelopeProperty.NativeTestConfiguration.fibreOneOver, EnvelopeProperty.NativeTestConfiguration.TestConfiguration}
\leanok
\uses{thm:native-parameter-line-monoid}
\source{bj22-trivval:sec:tc}
For an original scheme $X$ over an arbitrary original field $k$,
a test configuration consists precisely of an original total
scheme $\mathcal X$, an original flat projective morphism
$\pi:\mathcal X\to\operatorname{Spec}k[t]$, a genuine action
of the actual Laurent multiplicative group on $\mathcal X$
lifting the standard action on this same parameter line,
and an isomorphism $\mathcal X_1\simeq X$ over $k$.
The fibre $\mathcal X_1$ is the actual native Cartesian fibre
along the \emph{original polynomial evaluation map at one}.
Reducedness, irreducibility, normality, a desired noncentral
trivialization, and any common-model certificate are not data.
\end{definition}

The formal definition uses the genuine geometric projective
morphism predicate: a closed immersion into an actual finite
quasi-coherent projective bundle on the original parameter
scheme. Finite polynomial projective factorization over
$k[t]$ is subsequently derived. The genuine group action is
the existing full action structure, including its whole unit
and multiplication laws; equivariance is the entire original
structure-morphism equation. The parameter-one point is the
unit of the previously constructed actual line monoid and is
proved literally equal to the original evaluation-at-one
spectrum map. Thus this description is exactly source
conditions (i)--(iii), on the original schemes and coefficients.

\begin{lemma}[Derived geometry of every original test configuration]
\label{lem:native-test-configuration-model-geometry}
\lean{EnvelopeProperty.NativeTestConfiguration.TestConfiguration.projection_isProjectiveFactorization, EnvelopeProperty.NativeTestConfiguration.TestConfiguration.projection_isProper, EnvelopeProperty.NativeTestConfiguration.TestConfiguration.total_isLocallyNoetherian, EnvelopeProperty.NativeTestConfiguration.TestConfiguration.total_isNoetherian, EnvelopeProperty.NativeTestConfiguration.TestConfiguration.unitOpen, EnvelopeProperty.NativeTestConfiguration.TestConfiguration.unitOpen_dense, EnvelopeProperty.NativeTestConfiguration.TestConfiguration.unitOpen_isSchemeTheoreticallyDominant, EnvelopeProperty.NativeTestConfiguration.TestConfiguration.unitOpen_quasiCompact}
\leanok
\uses{def:native-test-configuration-data, thm:flat-parameter-open}
\source{bj22-trivval:sec:tc}
Every original test configuration has a genuine finite polynomial
projective factorization of its same original parameter projection.
That projection is proper; the original total scheme is
Noetherian. Its whole original noncentral open
$\mathcal X\setminus\mathcal X_0=\pi^{-1}D(t)$ is quasi-compact,
dense and schematically dense in the same original total scheme.
No reducedness or irreducibility is required for these assertions.
\end{lemma}
\begin{proof}
The actual projective morphism to the original affine spectrum
has a finite polynomial closed factorization over that same
original ring, by the genuine affine projective-bundle
comparison and original-ring isomorphism transport. Such a
factorization proves properness of the same map. Since
$k[t]$ is Noetherian, finite type gives local Noetherianity
of the entire original model. Properness over the compact
original affine base gives compactness, hence the total
scheme is Noetherian. Its prescribed original open is
therefore quasi-compact.
The actual original projection is flat. Polynomial $t$ is a
nonzero nonzerodivisor in the domain $k[t]$; finite type over
this Noetherian base also gives local finite presentation.
The actual flat parameter-open theorem proves schematic
density and topological density of precisely this entire
original $\pi^{-1}D(t)$. All properties are thus derived
from the literal original data, with no additional model
or trivialization hypotheses. The genuine full unit-open
trivialization from the original fibre-one datum is the
subsequent geometric construction.
\end{proof}
