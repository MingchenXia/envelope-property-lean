\subsection{True local frames under original generic residue pullback}

\begin{lemma}[The original generic local factor commutes with the actual residue map]
\label{berkovich:actual-generic-local-factor-residue-pullback}
\lean{EnvelopeProperty.Berkovich.RelativeSchemeValuedPoint.localGenericFactor_map_overBase}
\leanok
Consider actual proper models over coefficient rings with bounded valuations,
a literal compatible coefficient map, and an actual scheme map preserving the
whole base square. At every original source native point, any original open
containing the target's true valuative center has actual source preimage
containing the true source center. The original generic map into this preimage
followed by the actual restricted scheme map equals the actual residue-field
map followed by the target's original generic factor into the SAME original open.
\end{lemma}
\begin{proof}
The genuine center-naturality theorem derives the source-center membership
from the stated actual target-center membership. Cancel the actual open
immersion into the target scheme. Its monomorphism reduces the desired whole
factor identity to the native generic triangles on each model and the actual
scheme residue-field square. Those are established actual scheme-morphism
identities; no local-factor-preservation condition is assumed.
\end{proof}

\begin{theorem}[The whole true generic local frame is preserved]
\label{berkovich:actual-generic-local-frame-residue-pullback}
\lean{EnvelopeProperty.Berkovich.RelativeSchemeValuedPoint.residueModulePullbackIso_localFrame}
\leanok
\uses{berkovich:actual-generic-local-factor-residue-pullback,berkovich:actual-residue-module-pullback-frame,alggeom:actual-original-frame-pullback-composition}
In the same situation, for every actual original target local line frame at
the true center, the whole native residue-module comparison followed by the
TRUE generic frame of its actual pulled-back local frame is precisely the
actual residue-field pullback of the original target generic frame, with the
true structure-unit comparison. No frame or metric preservation premise is data.
\end{theorem}
\begin{proof}
First apply actual frame transport/pullback-composition coherence to the
source generic factor and the actual restricted model map. Genuine whole
frame-factor composition then identifies that frame with the actual frame
transport through the composed source generic factor into the target open.
The preceding whole local-factor identity identifies this composed map with
the actual residue-field map followed by the original target generic factor.
Apply whole frame-factor composition on the target side in reverse. This
identifies the source's true local generic frame with the native pullback
composition comparison followed by transport of the target's original generic
frame through the true residue-field square. The established residue-module
frame-pairing identity cancels the genuine composition comparisons, leaving
exactly the asserted whole original frame equality. Each factor and every
coherence equation is derived from actual original scheme maps.
\end{proof}
