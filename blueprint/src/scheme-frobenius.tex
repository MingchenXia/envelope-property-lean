\section{Actual absolute Frobenius of the same entire original scheme}
\label{sec:scheme-frobenius}

Let $k$ be the original field of prime characteristic $p$ and let
$f:X\to\operatorname{Spec}k$ be any original scheme structure morphism.

\begin{theorem}[Whole original ringed-space map and actual stalk locality]
\label{lem:cartier-original-frobenius-stalks}
\lean{EnvelopeProperty.Cartier.SchemeFrobenius.presheafedSpaceMap,EnvelopeProperty.Cartier.SchemeFrobenius.stalkMap_apply,EnvelopeProperty.Cartier.SchemeFrobenius.stalkMap_isLocalHom}
\leanok
The identity on the whole original topological space together with
the constructed actual original structure-presheaf
$p$th-power map defines a genuine whole original presheafed-space
endomorphism. On every original stalk its value at every original
$a$ is exactly $a^p$. Every such actual stalk map is local, without
a stalk-value, local-ring or characteristic certificate on its target.
\end{theorem}
\begin{proof}
The genuine structure-presheaf power map already has its entire
naturality square on every original open restriction, including
empty opens. With the identity on the actual original topological
space, it is therefore an actual presheafed-space morphism.
Every original stalk element is the germ of an actual section on
an original neighborhood. The actual stalk-map germ formula takes
this germ to the germ of its same original section's $p$th power.
The original germ ring homomorphism preserves this actual power,
proving the stated formula for every original stalk element.

If the stalk-map image of an original element is a unit, its same
original $p$th power is a unit. The genuine original element is
therefore a unit. This is precisely locality of the actual stalk
ring homomorphism; it is derived from the whole original power
formula, rather than supplied separately.
\uses{lem:cartier-entire-scheme-frobenius-coefficients}
\end{proof}

\begin{theorem}[The genuine absolute scheme Frobenius]
\label{thm:cartier-original-entire-scheme-frobenius}
\lean{EnvelopeProperty.Cartier.SchemeFrobenius.map,EnvelopeProperty.Cartier.SchemeFrobenius.map_apply,EnvelopeProperty.Cartier.SchemeFrobenius.map_app}
\leanok
These actual maps define a genuine endomorphism of the same entire
original scheme $X$. Every original point is unchanged, and every
original regular function on every original open is mapped to its
same $p$th power. All zero section rings of empty opens are included
internally. No affine cover, smoothness, perfectness, nonempty or
Frobenius-comparison premise is supplied.
\end{theorem}
\begin{proof}
The preceding true locality on every original stalk makes the same
whole original presheafed-space morphism a morphism of actual
locally ringed spaces, hence an actual scheme morphism between the
original schemes. Its point map is the same original identity by
construction. Its entire original open-section map is the genuine
previous structure-presheaf endomorphism, whose all-element value
was already proved to be $a^p$. No change of the original scheme,
its coefficient rings or its structure morphisms enters this
construction.
\uses{lem:cartier-original-frobenius-stalks}
\end{proof}

\begin{theorem}[Actual affine Frobenius and whole geometric module pushforward]
\label{thm:cartier-original-frobenius-affine-pushforward}
\lean{EnvelopeProperty.Cartier.SchemeFrobenius.preimage_eq,EnvelopeProperty.Cartier.SchemeFrobenius.isAffineHom_map,EnvelopeProperty.Cartier.SchemeFrobenius.pushforwardIso}
\leanok
The actual Frobenius preimage of every original open is that same
open. Thus this entire original scheme morphism is affine. The
constructed genuine Frobenius scalar-restriction functor
on all actual original module sheaves is genuinely isomorphic to
geometric pushforward along this same actual scheme Frobenius.
No affine-cover, finite-generation or module-comparison certificate
is supplied.
\end{theorem}
\begin{proof}
The entire original point map is the identity, so preimage retains
every actual original open. In particular the preimage of an actual
affine open is that same affine open, which is precisely the native
affine-morphism property. Native geometric module pushforward uses
the original module sections on those actual preimages, with scalar
action from the same actual morphism's structure-sheaf map. Both
are exactly the sections and power action in the preceding actual
scalar-restriction functor. The native definitions retain the same
entire objects, restrictions and morphisms, giving the genuine
whole identity-component functor isomorphism.
\uses{thm:cartier-original-entire-scheme-frobenius,
      thm:cartier-entire-scheme-frobenius-modules}
\end{proof}

\begin{theorem}[Whole absolute Frobenius is natural]
\label{thm:cartier-original-entire-scheme-frobenius-naturality}
\lean{EnvelopeProperty.Cartier.SchemeFrobenius.naturality}
\leanok
For every original morphism between such original schemes, the entire
actual absolute Frobenius square commutes. Compatibility of that
morphism with the two original $k$-structures is not required.
\end{theorem}
\begin{proof}
Both actual composites have the same entire original point map.
For each original target open, the first composite takes the actual
pullback of every original section to its $p$th power. The second
pulls back that same section's actual $p$th power. The actual original
pullback ring homomorphism preserves that entire power, hence the
whole open-section maps agree on every original section. True whole
presheafed-space and locally ringed-space morphism extensionality
then identifies the entire original scheme morphisms, not just
their point functions or coordinate charts.
\uses{thm:cartier-original-entire-scheme-frobenius}
\end{proof}

This is absolute Frobenius, with the original $p$th-power action on
base constants. Relative Frobenius over the original field still
requires the actual base Frobenius square and geometric pullback
factorization. The actual global de Rham differential, sheaf
Cartier isomorphism and Deligne--Illusie splitting remain further
obligations. No vanishing conclusion is asserted here.
