\section{The original differential of an actual open immersion}

\begin{lemma}\label{sc0-open-differential:cotangent-raw}
\lean{EnvelopeProperty.CanonicalGeometry.cotangentOpenImmersionSemilinear_morphism}
\leanok
\uses{sc0-cotangent-functoriality:functions}
For an actual open immersion $g:Y\to X$ over a field and every original open $U\subseteq X$, the SAME actual forward raw cotangent differential, followed by the ORIGINAL inverse coefficient isomorphism, is the ORIGINAL restriction from $U$ to $g(g^{-1}U)$ on EVERY original cotangent vector.
\end{lemma}
\begin{proof}
The original universal differentials span the whole original cotangent module. On a differential of an original function, the actual forward map differentiates its original pullback, and the inverse coefficient map differentiates its actual inverse coefficient image. The native original structure-ring identity identifies the composite coefficient map with the original restriction. Naturality of the original universal derivation gives equality on each original differential. Both paths preserve addition and scalar multiplication; their scalar coefficients agree by that SAME native ring identity. Actual span induction proves the full original-vector equality.
\end{proof}

\begin{lemma}\label{sc0-open-differential:exterior-raw}
\lean{EnvelopeProperty.CanonicalGeometry.exteriorCotangentOpenImmersionComponent_morphism}
\leanok
\uses{sc0-open-differential:cotangent-raw}
The analogous identity holds in EVERY exterior degree on EVERY original raw exterior vector: the actual inverse coefficient isomorphism after the SAME original forward exterior differential equals the ORIGINAL restriction to $g(g^{-1}U)$.
\end{lemma}
\begin{proof}
The original pure exterior products span the entire original exterior module. Both actual coefficient maps send each such product to the product of their original cotangent images, which agree with the original restricted cotangent vectors by the preceding result. The original exterior restriction has the SAME product formula. Both paths preserve addition and the SAME restricted scalar coefficients by the native original ring identity. Actual span induction proves equality on every original exterior vector, including degree zero.
\end{proof}

\begin{lemma}\label{sc0-open-differential:sheaf-unit}
\lean{EnvelopeProperty.CanonicalGeometry.exteriorCotangentSheafMorphism_openImmersion_inv}
\leanok
\uses{sc0-open-differential:exterior-raw,sc0-open-immersion-sheaf-units:exterior}
The ENTIRE actual exterior cotangent sheaf differential, followed by pushforward of the inverse ORIGINAL open-immersion isomorphism, equals the native restriction-adjunction unit in every degree.
\end{lemma}
\begin{proof}
Use the actual sheafification adjunction to detect equality of the entire original maps after their SAME original source unit. The actual forward sheaf differential retains the entire raw component. The ORIGINAL inverse open-immersion isomorphism commutes with BOTH original units, so the preceding full raw-vector identity identifies the composite with the target unit applied to the original restriction. Naturality of the SAME original source unit makes this exactly restriction of the original unit image. The actual native restriction-adjunction unit is that SAME restriction on original sections. Adjunction injectivity proves equality of the entire original sheaf maps.
\end{proof}

\begin{theorem}\label{sc0-open-differential:pullback-isomorphism}
\lean{EnvelopeProperty.CanonicalGeometry.exteriorCotangentSheafPullbackMap_openImmersion,EnvelopeProperty.CanonicalGeometry.isIso_exteriorCotangentSheafPullbackMap_openImmersion}
\leanok
\uses{sc0-open-differential:sheaf-unit}
The SAME original pullback exterior differential equals the ORIGINAL open-immersion isomorphism composed with the genuine native restriction/pullback comparison. In particular this actual differential is an isomorphism in EVERY exterior degree. No smoothness, affine coordinates, freeness, finite rank or map-matching premise is imposed.
\end{theorem}
\begin{proof}
The native restriction and pullback functors are left adjoints to the SAME original pushforward. The genuine native uniqueness isomorphism of these left adjoints takes the pullback-adjunction unit to the restriction-adjunction unit. Apply the actual pullback/pushforward Hom equivalence to the proposed entire-map equality. Functoriality and that unit identity reduce the right side to the restriction unit followed by pushforward of the ORIGINAL open-immersion isomorphism. The preceding whole-map identity, cancelled against the inverse of this genuine isomorphism, is precisely the same equality. The resulting whole differential is a composite of two actual isomorphisms, so is itself an isomorphism.
\end{proof}
