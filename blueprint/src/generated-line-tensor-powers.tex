\begin{lemma}[Every actual power of an original finite generated line is finite generated]
\label{lem:fc-original-generated-line-tensor-powers}
\lean{EnvelopeProperty.GeneratedLineTensorPowers.exists_generatingSections_tensorPower}
\leanok
\uses{thm:fc-generated-line-projective-twist-iso}
Let $X$ be an original integral scheme over $R$, and let $B$ be an
original invertible line with an actual finite global generating family.
Every natural actual tensor power $B^{\otimes r}$ has an internally
constructed finite global generating family.
\end{lemma}
\begin{proof}
The actual original finite generators internally give a whole morphism
$f:X\to\mathbf P^n_R$ and a whole original isomorphism
$f^*\mathcal O(1)\simeq B$. Original coordinate powers finitely generate
the actual $\mathcal O(r)$, including $r=0$. Pull these generators back
along the same actual $f$. The canonical original twist-power
isomorphism, the genuine native tensor-power pullback isomorphism, and
the actual $r$th power of the given whole line isomorphism identify
$f^*\mathcal O(r)$ with the actual $B^{\otimes r}$. Transport the same
original finite family along this whole isomorphism. Its evaluation is
epic and its unchanged index set is finite, proving the assertion.
\end{proof}
