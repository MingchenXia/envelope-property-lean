\section{Actual original ample-line finite FS families in the same native model}
\label{sec:native-ample-model-fubini-study}

\begin{definition}[Independent original line FS data and actual finite rational functions]
\label{def:native-line-whole-section-fs}
\lean{EnvelopeProperty.NativeLineFubiniStudy.FSData,EnvelopeProperty.NativeLineFubiniStudy.FSData.eval,EnvelopeProperty.NativeLineFubiniStudy.FSData.IsRational,EnvelopeProperty.NativeLineFubiniStudy.IsFinFS}
\leanok
\uses{thm:scheme-global-section-weighted-norm-isometry}
For any actual original line $L$, finite FS data consist of an original
positive integer $m$, a nonnegative original exponent $d=ma$, and a finite
weighted family of actual entire original sections of $L^{\otimes d}$.
Evaluate it by $m^{-1}\max_s(\log\lVert s\rVert+\lambda_s)$ using the true
original proper-model norms. Actual finite rational FS functions use rational
original weights and require these same true section norms to have no common
zero on the entire original native point space. These definitions use no model
comparison or chosen homogeneous-polynomial realization.
\end{definition}

\begin{theorem}[Every original weighted family has the same genuine model evaluation]
\label{thm:native-ample-model-fs-evaluation}
\lean{EnvelopeProperty.NativeAmpleModelFubiniStudy.toModelData,EnvelopeProperty.NativeAmpleModelFubiniStudy.eval_eq_modelEval}
\leanok
\uses{def:native-line-whole-section-fs,thm:native-ample-model-powered-section-lognorm,def:gl-fs}
Assume throughout this statement that the original scheme $X$ is integral.
Fix actual original positive-power embedding data with $L^{\otimes r}$ the
first original pulled twist and $r>0$. Take the actual $r$th power of every
entire original section, give it weight $r\lambda_s$, and replace the original
denominator $m$ by $mr$. This gives genuine FS data of class $a/r$ on the same
one full native function-field model. Its whole evaluation under the same
native analytic homeomorphism is exactly the original weighted function.
Zero sections, zero norms and empty original families are included.
\end{theorem}
\begin{proof}
Each actual powered original section has genuine model degree $d$. The exact
original degree equation is $d=(mr)(a/r)$. Its actual logarithmic model norm
is $r\log\lVert s\rVert$, by the genuine section-power norm theorem. Thus each
weighted term is multiplied by the positive real integer $r$. A positive
finite scalar commutes with the finite extended-real supremum, including the
empty supremum. Multiplication by $(mr)^{-1}$ cancels this factor exactly.
All original weights and whole sections are retained through this explicit
power construction; no desired FS comparison is assumed.
\end{proof}

\begin{theorem}[Actual rationality and no-common-zero finite FS transport]
\label{thm:native-ample-model-finite-fs-transport}
\lean{EnvelopeProperty.NativeAmpleModelFubiniStudy.toModelData_isRational,EnvelopeProperty.NativeAmpleModelFubiniStudy.toModelData_noCommonZero_iff,EnvelopeProperty.NativeAmpleModelFubiniStudy.isFinFS_transport}
\leanok
\uses{thm:native-ample-model-fs-evaluation,thm:native-ample-model-powered-section-lognorm,def:gl-fs}
Assume throughout this statement that the original scheme $X$ is integral.
Actual original rational weights remain rational. The genuine powered model
family has no common zero on its entire point space exactly when the original
whole-section family has no common zero in true norms on its entire native
space. Every actual original finite rational FS function of $L$ consequently
transports to a genuine finite model FS function of class $a/r$.
\end{theorem}
\begin{proof}
Multiply each rational weight by the actual integer $r$. Positive powers have
nonzero norm exactly when the original norm is nonzero. Apply this fact to each
actual member of the finite image. The entire original native homeomorphism
is surjective, so this pointwise equivalence holds over both entire point
spaces. Combine rationality, this equivalence and the proved whole function
identity to obtain the actual finite FS predicate. This theorem concerns
finite rational FS and its literal data; it does not assert intrinsic numerical
representative independence or the complete psh comparison.
\end{proof}
