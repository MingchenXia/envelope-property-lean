\section{Global original exceptional-line generators and positivity}

The affine relative very-ampleness result does not identify a polarization
on a blowup of a projective base. The following route keeps the actual
exceptional ideal module and the actual original projective polarization.
The global positivity and numerical nef-and-big obligations are kept
separate from the elementary generator transport proved first.

\label{lem:kn-nadel-nef-big-comap-tensor-generators}

$f:Y\to X$ any actual morphism. Construct the actual morphism
\[
 f^*(D\otimes B)\longrightarrow (D\mathcal O_Y)\otimes f^*B
\]
from the genuine tensor pullback comparison and the actual canonical
ideal-comap epimorphism. It is epic without a flatness hypothesis. Every
actual original generating family of $D\otimes B$ gives an actual generating
family on the right, with exactly the same indices. Its original basis
section is exactly the actual pulled original basis section followed by
this same actual morphism. Finite families remain finite.
\end{lemma}
\begin{proof}
The native strong-monoidal pullback comparison first identifies the source
with $f^*D\otimes f^*B$. Tensor the canonical ideal-module comap epimorphism
with the identity of the same actual $f^*B$. The latter line is invertible,
so tensoring by it is an equivalence and preserves epimorphisms. The
composite is therefore epic. Pull back the original free evaluation map
and then compose this actual epimorphism. This gives a generating family.
The native free basis formula for pullback and the native basis formula
for an epimorphic image prove the asserted whole section equality; no
section or image matching condition is supplied. The index is unchanged,
so its original finiteness proves finiteness of the transported family.
\end{proof}

\begin{lemma}[The actual affine generator values span the whole original module]
\leanok
\label{lem:kn-nadel-nef-big-affine-generator-span}
\lean{EnvelopeProperty.Vanishing.NadelNefBigAffineGeneratorSpan.generatorValue,

the actual whole global values of any original generating family span its
entire original global module over the same original ring $A$. No finite
family, finite-type module, domain or flatness hypothesis is needed.
\end{lemma}
\begin{proof}
Let $S$ be the actual span of the original basis values inside the original
global module and $Q=\Gamma(M)/S$ its actual quotient. The native
quasicoherent tilde--global-sections counit is an isomorphism for this
same $M$. Its inverse followed by the tilde of the actual quotient map
gives an actual map $M\to\widetilde Q$. The original adjunction's triangle
identity and unit naturality say that its entire global-section map is
the original quotient map followed by the actual tilde unit.

Every original basis value maps to zero by the definition of $S$. A
structure-module section morphism is determined by its actual value at
one on the original top open, using restriction naturality and linearity.
Thus every original basis morphism followed by this actual sheaf map is
zero. The original free evaluation is epic, so the whole sheaf map is
zero. Compose back with the same counit to obtain that the tilde of the
original quotient map is zero. Native faithfulness of tilde implies that
the original quotient map itself is zero. Therefore every original global
section lies in the same $S$, proving the whole original span equality.
\end{proof}
