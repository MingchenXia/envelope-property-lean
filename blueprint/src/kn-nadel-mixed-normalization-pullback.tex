\section{The native canonical input of the original whole mixed counit}

\begin{lemma}
\label{lem:kn-nadel-mixed-original-native-canonical-input}
\lean{EnvelopeProperty.Vanishing.NadelGlobalCanonicalTrace.mixedNativeCanonicalPullback,EnvelopeProperty.Vanishing.NadelGlobalCanonicalTrace.mixedNativeCanonicalPullback_coordinate}
\leanok
\uses{lem:kn-global-trace-native-coordinate-wedge,lem:kn-global-trace-actual-base-unit-sections,lem:kn-global-trace-native-mixed-sections}
Let $A/k$ have the original etale coordinates $x_1,\ldots,x_n$ and
let $B$ be the entire original mixed quotient, with all original root
factors. The original finite-map algebra homomorphism $A\to B$
produces the genuine native canonical differential
\[
 \delta_{B/A}:\Gamma(\omega_A)\longrightarrow\Gamma(\omega_B),
\]
with the original $A$ action. It sends the native section represented
by $dx_1\wedge\cdots\wedge dx_n$ to the native section represented
by the ordered differentials of their actual images in $B$.
\end{lemma}
\begin{proof}
The original etale coordinates give the original base smoothness of
relative dimension $n$. Apply the actual affine algebra-map canonical
differential to the original coefficient homomorphism $A\to B$.
The original mixed structural morphism is literally the original
field structural morphism of the same $B$, so its target is the same
original mixed canonical module. The existing native coordinate-wedge
formula gives its value on the original ordered coordinate tuple.
Neither a target differential frame nor a normalization identity is
an input.
\end{proof}
