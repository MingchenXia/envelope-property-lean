# Generic freeness under the existing EP pin

Four unmodified source modules (569 lines) from TauCetiProject/TauCeti at commit 15198c5caca3d2ccadc8d5b4e98cbef1a50b4a4c, Apache-2.0. Upstream targets Lean4.35.0-rc3; these exact sources kernel-compile without compatibility edits under Lean4.33.1 and Mathlib0df444a360eaa60ab8c11dca51a86af692955474. Exact hashes and actual isolated compiler environment are recorded. Three terminal/support theorem transitive audits use only propext, Classical.choice and Quot.sound.

The producer gives freeness of localized modules on an open neighbourhood of each minimal prime of a reduced Noetherian base for finite modules over finite-type algebras, and density of the interior of that free locus. This is a genuine proved local-freeness result. It does not claim a chosen global basis after one localization, nor finish spreading/reduction, resolution, envelope or alteration arguments. Ordinary parent registration is a separate consuming checkpoint.
