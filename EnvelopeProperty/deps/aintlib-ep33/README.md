# AINTLIB compatibility source for native EnvelopeProperty

The exact 185 selected generic/projective modules come from CBirkbeck/AINTLIB at commit `6fc322756d32a30e9bc660aadb317221fb07c73a` (Apache-2.0), with two explicit source selections described below. Lean 4.33.1 and the parent Mathlib pin `0df444a360eaa60ab8c11dca51a86af692955474` remain unchanged. The ordinary path package supplies projective factorizations, finite ordered Cech cohomology, genuine sheaf tensor/dual/pullback infrastructure, and projective-space twist calculations. Some generic sources retain their upstream `EllipticCurve` directory; the elliptic arithmetic/Weierstrass umbrella is not selected.

`AintlibEp33.lean` imports every selected module. `PROJECTIVE-MODULES.json` lists their build order; `UPSTREAM.json` hashes every actual ported source; `UPSTREAM-SOURCES.json` records the 183 complete original AINTLIB modules. `SectionFiberPoint-selection.json` records one verbatim genuine fibre-section declaration selected from upstream EllipticCurve/Basic independently from unrelated arithmetic. `Mathlib-compatibility-selection.json` records the proved missing generic exact-sequence support from a precise newer Mathlib source, renamed under ModularCurves rather than shadowing Mathlib. The historical original source is preserved in the stop snapshot and isolated port provenance; `COMPATIBILITY.patch` records all complete-source compatibility edits.

Compatibility changes adapt namespaces, argument order, coercion proofs, categorical Pi projections, and explicit universe/typeclass data. The AINTLIB multiplicativity theorem is named `comap_mul_aintlib` to coexist with the independently proved Hironaka `comap_mul`; its statement and proof are preserved. The first 44 registered sources retain their previously checked style adjustments; the full selection also adapts proof-local proposition bindings and removes obsolete simp arguments under the same proof checker. A weak private-in-public compatibility diagnostic option preserves upstream conventions; it changes no proof checking. No axiom, sorry, admit, target-shaped hypothesis, compiler artifact, or dependency-pin change is introduced.

The isolated full port has passed source compilation and a core collectAxioms audit of all 184 actual imported modules (5503 constants, including private/generated declarations). The ordinary combined native build passed 10836 jobs without warnings, and the joint native import/core audit confirmed the same 5503 constants with zero nonstandard axioms. Evidence is recorded under `audit/continuation-20261016` and `audit/continuation-20261018`. This infrastructure does not by itself prove proper formal H0, geometric connectedness, LocalPositivity, or whole-paper completion.
